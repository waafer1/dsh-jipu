# 文风基准（本书自己的靶）

> 这份文件**每本书一份**，由 `开项目.py` 从 `assets/文风基准_模板.md` 铺进 `00_底座_语文能力/文风基准.md`。
> **没填完 = 不许写第一章正文。** 判据：`文风靶.py --baseline` 会拒；`开项目.py` 的底座自检会把它算进未完成项。
> 为什么必须有这份东西：通用口径（`references/02-正文口径.md`）说的是所有书共有的下限；这本书**往哪儿写**、**长什么样**、**哪些词是它的**，通用口径一个字都答不了。没有靶，写手只能按"不出错"写——不出错的另一面就是"都一样"。

## 一、基准段落（2—3 段，每段 500—800 字）

> 从**已经过了读者关**的成品里抄，或由作者手写。**不是示例，是标尺**：写手落笔前读这一段，读的是节奏、句长、密度、语气。
> 三段各管一件事，缺一段就写"待补：缺 X 段"，别拿同一种段落凑三份。
>
> **这三段必须是「人写的」，不许拿 AI 稿、也不许拿你没把握的旧稿凑数。** 1.37.0 起 `文风靶.py --calibrate` 会拿这三段实测反推本书九项靶值——**你拿什么当基准，靶值就把什么定成标准**。用 AI 稿当基准，等于把"句短、均匀、四字多"锁成这本书的合法区间，之后所有 CHECK 都会放过它。宁可先只填一段真喜欢的段落，也别填三段将就的。
>
> **这件事现在有机器挡**（1.37.1 起）：`--calibrate` 会先量这三段自己，踩中两项及以上 AI 判据（句长 CV <0.40／≥30 字长句 <5%／≤10 字短句 >45%／四字整段 >22%）就直接 **exit 1 拒绝校准**，并逐段告诉你踩了哪条。确认真是人写才加 `--force`，加了会在 `style_source` 里标 `forced`——留痕，不隐身。

### 段一 · 日常／铺陈段（管节奏与信息密度）

```text
（在此粘 500—800 字。要求：有物件、有动作、有一个人在场的判断；不写天气开场。）
```

### 段二 · 冲突／爆点段（管推进速度与力度）

```text
（在此粘 500—800 字。要求：一拍一动作，读者一口气读完；不靠形容词加码。）
```

### 段三 · 收束／钩子段（管章末留手）

```text
（在此粘 500—800 字。要求：最后三句有一句不该说的话或一件不该在的物。）
```

**这三段的用法**：写手在 A3 与落笔前各读一遍；评审拿它做**成对比较**的锚（`成对盲评.py --anchor`）。**不许把别书的段落粘进来**——粘了就是把上一本的声音带进这本。

## 二、可测靶值（与 `项目配置.json` 的 `style` 段一一对应）

> 这里是**人读的说明**，机器读的是 `项目配置.json`。两边必须同步；不同步时以配置为准，并改本表。
> 每个值都给"为什么是这个数"，不许只写数。默认值来自 2026-11-24 对两本旧书与人工范例句的实测（`jipu正文质量_深度研究报告.md` §1）。

| 键 | 含义 | 本书靶值 | 为什么 |
|---|---|---|---|
| `sentence_cv_min` | 句长变异系数下限（节奏起伏） | `<待填 0.42>` | 低于它＝全章句子一样长（念稿感）；人类参考 0.449、AI 0.376，人工范例 0.66 |
| `long_sent_ratio_min` | ≥30 字长句占比下限（按档：T0 0.06／T1 0.10／T2 0.15） | `<待填 0.10>` | 全短句＝没有肉；旧书第 1 章只有 0.024—0.075，人工范例 0.39 |
| `short_sent_ratio_max` | ≤10 字短句占比上限 | `<待填 0.30>` | 短句是节奏，但不能一直短——AI 缺的是长句，人缺的是短句 |
| `p90_len_min` | 句长 p90 下限（右尾） | `<待填 30>` | 病不在均值在右尾：两句长句能把整章撑起来，没有就是平 |
| `four_char_seg_max` | 四字落点段占比上限 | `<待填 0.16>` | 超过它＝满篇四字句，腻；人工范例 0.10，旧书 0.17—0.24 |
| `connective_per_k_min` | 显性连接词每千字下限 | `<待填 1.2>` | 连接词全删＝读者自己补因果（作者 2026-11-06 令：因果要说破） |
| `metaphor_per_k_min` | 比喻每千字下限 | `<待填 1.5>` | 零比喻＝干瘪；但上限也别过 9，过 9 是修辞堆 |
| `metaphor_per_k_max` | 比喻每千字上限 | `<待填 9.0>` | 同上 |
| `paragraph_cv_min` | 段长变异系数下限 | `<待填 0.45>` | 段段一样长＝版式平；人工范例 1.30 |
| `mid_len_ratio_max` | 8—20 字句占比上限 | `<只报数 0.42>` | 这一项**不进 PASS／FAIL**（切句口径一变它就动，当硬项会误伤）；超过它说明句子被剁成等长小段 |
| `style_source` | 靶值来源 | `<待填：calibrated 或 手填>` | 空着＝靶值是通用默认值，`--baseline` 会打 NOTE。跑过 `--calibrate` 应为「calibrated：…」 |

**对白占比永远只报数**（作者 2026-11-06 令）：`文风靶.py` 会打印"本书前 3 章均值 vs 本章"，**不进任何 PASS／FAIL**。看到连续多章掉一半，是人该说话的时候，不是脚本该拦的时候。

```bash
cd <项目根>
```

四条全过才算填完：

1. 三段基准段落都 ≥500 字，且各自类型不同；
2. 第二节九项靶值在 `项目配置.json` 里都有数值，没有 `<待填>`；填完跑 `python 08_工具_脚本/文风靶.py --calibrate`，让它按这三段反推本书靶值（`style_source` 应变成「calibrated：…」）；

4. 第四节至少填了"专名""禁用度量词"两行。

**没填完就写正文**，等于又回到"门禁全绿、读者全跑"的老路——这是本工序最贵的一次事故，别再犯。

# 07 · 类目模板库与剧情模板库（怎么用）

> 位置（项目内）：`07_模板_复用件/类目模板库/`（13 份）、`07_模板_复用件/剧情模板库/`（10 份）。
> **包里也自带一份**：`skills/jipu-manuscript/assets/`（同名两份，内容一致）。项目里没有这两库时（新用户、没跑过 `开项目.py`），从 `assets/` 复制到项目的 `07_模板_复用件/` 下再用——这是系统层通用件，任何项目都该有。
> 性质：**跨书通用**，属于系统层，`开项目.py` 会整目录复制到新项目。
> 定位：**它们给下限，不给上限**。任何与项目自身铁律冲突处，一律以项目文件为准（唯一出处原则）。

## 一、两份库各管什么

| 库 | 管什么 | 什么时候必查 |
|---|---|---|
| 类目模板库 | 这个类目卖什么、开篇三章怎么排、金手指怎么给、节奏多快、毒点有哪些、数据基准 | **开新书定题材前**、`02_设定/题材定位.md` 动笔前、写第 1 章前 |
| 剧情模板库 | 具体桥段的拍点（五拍）、兑现物、变体、冷却、滥用信号、反套路 | **每一段排章目时**、细纲阶段定"这章用哪个桥段"时 |

## 二、类目模板库怎么用（三步）

1. **对号**：`类目模板库/00-索引与用法.md` 第二节的类目地图，找本书的类目编号（01—12）。
2. **先读毒点**：打开该类目文件，先看「六、毒点清单」，再看「一、读者承诺」「二、开篇三章」。
3. **改三处**（铁律 T1）：钱怎么来、力怎么长、人怎么聚——全部换成本书的实物。改完自查：把三个词替回类目原词，还读得通 → 改得不够。

## 三、剧情模板库怎么用（四步）

1. **查账本**：`06_追踪_状态账本/桥段账本.md`——这个模板上次第几章用的、哪个变体。
2. **对前置条件**：缺一条，要么补铺垫（3—8 章），要么换模板。**不许硬上**。
3. **选变体**：上次 A，这次 B 或 C；三个都用过 → 本段停用。
4. **落进细纲**：五拍映射到 `07_模板_复用件/细纲模板.md` 的八拍，每拍填**具体物**（谁、多少钱、几天内）。

## 四、硬规则（从两份库里抽出来的四条）

| # | 规则 | 判据 |
|---|---|---|
| G1 | 一段只许一个**核心大模板**（P-101／P-301／P-701 级） | 查 `剧情模板库/00` 第三节冷却表 |
| G2 | 同一模板：核心 60 章／常用 12 章／气氛 6 章内不许重复 | 同上 |
| G3 | 两个模板不许同型爽点，中间必须夹一个不同型的 | 见 `剧情模板库/00` §四 C2 |
| G4 | 用完一个模板，主角的「钱／力／名」至少一项要变 | 不变 = 填充物，删 |

**模板的第三次使用必须是被"反着用"的那次。** 正着用三次＝套路，读者会在评论区提前报出下一拍。

## 五、细纲阶段必答的五个问题（来自 `剧情模板库/00` §七）

1. 这一段用了几个模板？>3 → 太挤。
2. 有没有两个同型？有 → 违反 C2。
3. 五拍里有没有空拍（填不出具体物）？有 → 删这一拍。
4. 读者能不能提前说出下一拍？能 → 换变体或反着用。
5. 用完这些模板，位移是什么（一句说清）？说不清 → 这段是填充。

## 六、爽点型的统一口径

类目库里用的是**通用八型**（①算死你 ②打脸 ③跳档 ④收账 ⑤起势 ⑥身份反转 ⑦获得 ⑧掌控）。
本项目《爽点宪法》的六型是它的**投影**（前六型一一对应），⑦⑧是本库新增的两型，专供种田／末世／宫斗／职场这类"拿到"与"说了算"的爽点。
**不许自创第九型**。写细纲时只用这八型，且同一型连用 ≤2 章。

## 七、维护

- 库里数字凡标「经验值」的，是可调参数；凡从正文实测来的，标来源。
- 改动用文件头 `> 修订：YYYY-MM-DD` 留痕。
- 新增类目：编号接排（13 起），同步更新类目库索引第二节与剧情库索引的"适用类目"。

## 六、主题灵感库（2026-11 新增）

`assets/主题灵感库/` 是第三份库，回答的不是“怎么排”，而是“这本书为什么值得写、从哪句开始”。

| 库 | 回答 |
|---|---|
| 类目模板库 | 这类书通常怎么排 |
| 剧情模板库 | 这一段用什么结构 |
| **主题灵感库** | **母题是什么、从哪一句钩子开局、这类书的通病是什么** |
| **对白层库** | **这句对白干什么、话底下是什么、谁在说** |

用法：开新书选母题进卷纲；排段用灵感种子（钩子→冲突→代价）；审计拿“误区”当打回理由。索引见 `assets/主题灵感库/00-索引与用法.md`。

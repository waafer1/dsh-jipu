# 04 · 器物与场所词表

> 画面不靠形容词，靠**一件带三个信息的物**：多少钱、干什么用、留下了什么痕。

## 一、器物七类

| 类 | 例 | 带什么信息 |
|---|---|---|
| 居住 | 门板、门闩、窗纸、草席、灶 | 穷富、防卫、冷暖 |
| 饮食 | 碗、壶、干粮、咸菜、酒 | 生活线、待客、欠情 |
| 交通 | 板车、担子、船、驴、驿马 | 脚程、本钱、身份 |
| 工具 | 秤、算盘、锤、镰、网 | 行当、手艺、磨损 |
| 武器 | 刀、棍、弩、甲 | 谁准拥有、敢不敢用 |
| 货币 | 铜板、银锭、票、赊账牌 | 购买力、信任范围 |
| 文书 | 契、册、牌、印、状 | 权利、凭证、把柄 |

## 二、场所十型

| 型 | 戏能干什么 | 必备细节 |
|---|---|---|
| 街 | 相遇、跟踪、看热闹 | 车辙、摊位、气味 |
| 市 | 交易、比价、打听 | 叫卖、秤、争执 |
| 栈 | 存货、抵押、谈判 | 账房、后门、伙计 |
| 铺 | 买卖、赊账、行话 | 柜台、货架、算盘 |
| 坊 | 做工、手艺、收徒 | 炉火、水缸、半成品 |
| 庙 | 求人、许愿、藏身 | 香火、功德箱、偏殿 |
| 衙 | 告状、审判、打点 | 鼓、刑具、排号 |
| 渡 | 过渡、离别、追兵 | 船、潮、艄公 |
| 驿 | 传信、换马、消息 | 马厩、驿卒、火印 |
| 矿 | 苦力、塌方、欠薪 | 井口、筐、灯 |

## 三、一件物写三个信息（范式）

> 例：**门闩是活的，一推就开，门板上三道旧划痕。**
> ——穷（活闩）、不安全（一推就开）、被人闯过（划痕）。

写法：

1. **价**：这东西值多少，或值不值钱。
2. **用**：谁在用、怎么用、用多久了。
3. **痕**：磨损、修补、缺失——痕里藏故事。

## 四、场所写法

- 进场只写 **两样**：一个声音、一个气味；不写全景。
- 场所要有**边界**：门在哪、谁能进、进了往哪退。
- 同一个场所第二次出现，必须**变了一点**（更破、更挤、换了人）。

## 五、自检

- 这段有没有一件能摸到的物？
- 这件物有没有价、用、痕？
- 场所能不能说出“从哪进、往哪退”？

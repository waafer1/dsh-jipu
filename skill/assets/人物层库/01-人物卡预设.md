# 01 · 人物卡预设（C-101—1xx）

> 三档卡：A 卡全字段（主角＋核心圈 6—9 人）、B 卡 6 项（卷级配角每卷 8—12）、C 卡不建卡（一次性角色写章纲一行）。
> 卡的作用是**提问**：填不出来的字段，等于这个人还没想清楚。
> 证据等级：字段结构为［检索级］（写作教练通行的人物问卷）＋［实测级］改编（本库只留能落到正文的字段，砍掉"星座／MBTI／喜恶清单"这类写完用不上的）。

---

### C-101 A 卡·十二字段（主角与核心圈）

按顺序填，前五项是硬字段（缺一不许出场）。

| # | 字段 | 填法（反例→正例） |
|---|---|---|
| 1 | **一句话** | 谁＋现在要什么，≤20 字。反例："一个穿越者"→正例："一个被身体原主拖累的外乡人，想凑够一副药钱" |
| 2 | **在故事里干的活** ★硬 | 六选一：对手／镜子（照出主角是什么人）／助力／阻碍／信息源／氛围。**一项都填不出→这人删掉**。填两项以上→拆成两个人 |
| 3 | **他想要的具体物** ★硬 | 必须是能拿出来给人看的东西：钱、位子、人、一张纸、一口气。反例："想要变强"→正例："想要镇东那间铺子的地契" |
| 4 | **他怕什么** ★硬 | 怕＝把柄＝别人能拿捏他的方式。反例："怕失去"→正例："怕人知道他弟弟是逃兵" |
| 5 | **他和主角的账** ★硬 | 欠／被欠／交易／血仇，四选一，**账目要能结算**（多少钱、几条命、几次人情）。没账＝没戏 |
| 6 | 他坚信但错的一件事 | 人物弧的发动机。反例："他有点固执"→正例："他坚信只要规矩守得够死，就没人能动他——所以他会为了规矩放走仇人" |
| 7 | 他的说话方式 | 一句台词样例＋句长／称谓习惯。反例："说话高冷"→正例："短句，从不用'请'，管所有人都叫'喂'" |
| 8 | 他的可见件 | 一件物／一处身体特征／一个动作习惯，**重戏独一份**。反例："长相英俊"→正例："左手小指少半截，数钱时用指节顶" |
| 9 | 他的位置 | 现在在哪、归谁管、能调动什么。写"大概在城里"等于没写 |
| 10 | 出场章 | 第一次露脸在第几章、做什么。没写＝这人不该出现 |
| 11 | 结局预定 | 死／退／倒戈／成长，四选一，可改但必须有。没结局的配角会赖在书里不走 |
| 12 | 名字由来 | 名字凭什么这么起（出身／职务／外号）。防"张长老""李师兄"——那是编号不是人 |

**A 卡填空模板**（复制这一段用）：

```
### 姓名（第 N 章出场 · A 卡 · 建于 20XX-XX-XX）
一句话：
在故事里干的活：
他想要：            他怕：            他和主角的账：
他坚信但错的：
说话方式：
可见件：
位置／归属：
结局预定：
名字由来：
```

### C-102 B 卡·六项（卷级配角／对手）

一卷 8—12 张，卷末归档。只填六项，多了不填——B 卡写满就成 A 卡，A 卡超过 9 张就管不住。

```
姓名（第 N 章出场 · B 卡 · 本卷用）
① 干的活：          ② 想要：
③ 和主角的账：      ④ 可见件：
⑤ 立场（哪一拍站哪边）：
⑥ 结局／退场方式：
```

**B 卡唯一容易漏的是 ⑤**：卷级配角的用处常在"某一刻他站哪边"——比如那个平时和主角不对付、关键时候递了一把刀的人。不预设立场，写到那一拍他就会凭空消失或凭空帮忙。

### C-103 C 卡·不建卡（一次性功能角色）

跑堂的、守门的、告状的、被救的。**只在章纲行里写一行**，写完即弃：

```
【C】卖炭的老周｜要：把炭钱讨回来｜件：担子一头用铁丝捆了三道
```

一行三样：**要什么／一个可见件／一句会说的话（可省）**。三样之外一个字都不写——写多了就开始给路人编身世，一章塞三个有故事的路人，主角被挤没影（这是本书开头最容易犯的错）。

---

### C-104 硬字段门禁（写完卡自己过一遍）

1. **功能栏空着** → 删人，或合并到已有角色身上。读者不需要第三个"帮主角说话的人"。
2. **欲望写成"想变强／想过好日子"** → 重填。抽象欲望＝没有欲望，写出来就是一段独白。
3. **账目算不清** → 重填。写不出"欠多少"，后面对峙就没筹码。
4. **可见件写成形容词** → 重填。形容词是判断，可见件是画面。
5. **十二项里有 4 项以上空着** → 这人不是 A 卡，降成 B 卡。

---

### C-105 出场梯度（防"200 个名字读者记不住"）

- **一段戏有名角色 ≤4**，**一章新名字 ≤3**。超了：合并、延后、或者直接不给名字（"守门的"比"王老三"好使）。
- **新角色出场三件套**：可见件＋具体动作＋一句立场话。三件齐活，读者一次记住；只报名字的，等于没出场。
- **先给活干，后给名字**：让他在戏里做一件怪事，读者记住这件怪事，再补名字。反着来（先报十分钟履历）读者就划走了。
- **群像只写两级**：带头的给个特征（"为首的络腮胡"），跟班的报数（"跟来的人"）。群像挨个写脸＝糊成一片。

---

### C-106 命名规范与校验

- 名字 ≤3 字，**同章不同首字**，**音同字不同一律改**（"副院主"写成"副院住"这类事故，最砸可信度）。
- 一个名字只有一个称呼：定了叫"尖耳朵的"，全书不许再出现第二个叫法，除非是**别人改口**（改口本身是情节）。
- 职务／外号当名字用的人，全书称谓固定（"掌柜"就是掌柜，别一会儿老板一会儿东家）。
- 写完全书搜一遍：同名、同音、首字撞车、称谓漂移。四条查完再交稿。

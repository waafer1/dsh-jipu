# 03 · 门禁手册（脚本怎么跑、数怎么读）

> 出处：`01_法则_章法节奏爽点/流水线.md` 门禁章、`00_底座_语文能力/句法基准.md` §九「谁能查」、`项目配置.json`。所有命令在**项目根目录**下跑。

## 一、一条命令的活

```bash
python 08_工具_脚本/章体检.py NNN
```

实际输出（示例，数字按项目实测替换）：

```
== 第012章《试丹》体检
  字数 2400｜段 70｜对白 0.28｜最长纯叙 170
  PASS   章检（句检＋宾语＋审计）       通过
  PASS   对白归属 孤岛              0 处
  PASS   数字体检 待核              0 处
  PASS   章名落地                 "试丹"在正文里
  PASS   章首 10% 交底            有数＋赌注
  PASS   章末钩子                 末段有未结的事
  PASS   禁词 / 元信息词 / 占位符 / 视角情绪词   无
  CHECK  段首重复                 <主角名>×5、<称呼>×5
  CHECK  句长单调                 最长连续相近 5 句
  PASS   感官平衡                 视2／听4／嗅1／触17
  PASS   破折号密度                1.5 处/千字（4 处）
  PASS   与上一章重复句              无
  人工：
   [ ] 细纲拍点逐拍勾（条数＝玩法卡 beats；拍点是否落到正文）
   [ ] 物理四查：物件状态／人物位置／时间单向／话与数
   [ ] 存兑：这一章存了什么、兑在哪一章
  结论：通过（硬项 9 项，过 9）
```

**读法**：`PASS` 是硬项，`CHECK` 是提示（人判），`人工` 三项脚本不判、必须人填。`结论` 只看硬项。

**1.36.0 起，CHECK 区多了两组**（都不进硬项，一条也不许无视）：

```
CHECK（不进合门，命中即改）：
  CHECK  8—20 字句占比        ≤0.42   0.667   ← 句子被剁成等长小段——最刺眼的 AI 味
  CHECK  ≥30 字长句占比        ≥0.06   0.0     ← 没有铺陈，全章短促，缺肉
  CHECK  比喻每千字            1.5—9.0 0.0     ← 零比喻干瘪／过密是修辞堆
  CHECK  缺成对盲评记录（这份是单稿…）           ← 评审只能盖章
```

前者来自 `文风靶.py`（九项密度对本书靶值），后者来自 `06_追踪_状态记录/偏好对.jsonl`。
**为什么故意不设成硬项**：这些是密度读数，阈值是软的；一设硬项就有人为了过门禁去凑数字，
凑三轮之后整套门禁就成了摆设（这条已经是踩过的坑）。**命中就改那一类句子，别改情节。**

**不过的样子**（第 004 章草稿，2026-11-01 实跑）：

```
== 第004章《挂着》体检
  字数 1950｜段 58｜对白 0.1554｜最长纯叙 325
  FAIL   章检（句检＋宾语＋审计）           不通过
  ...（其余 8 项 PASS）
  结论：不通过（硬项 9 项，过 8）
```

读法：字数 1950 与对白 0.1554 **不进硬项**（本项目不设字数线；对白低要靠豁免或重排），真正卡住的是"章检"这一项——它连带三项：句检 4 处 blocking、审计文件还没写、宾语盘点得重跑。**最长纯叙 325 > 200**，是报警线，审计里要指明变化落点，指不出就删或并。

## 二、单件工具的用途与判读（表内命令全部实装，随包 tools/ 走）

> 口径一条：**表里没有的脚本就是没有**。要加命令先写脚本，再改这张表——反着来会写出一堆跑不起来的命令。
>
> 口径二条：**一律在项目根目录下运行**（表里 `08_工具_脚本/xxx.py` 是相对项目根写的）。`选型体检.py`／`能力自测.py`／`状态体检.py` 不带参数，靠当前目录向上找 `项目配置.json`；在别处跑会报"0 行""找不到"，那不是稿子的问题。要么先 `cd` 到项目根，要么显式给路径（`选型体检.py --file 02_设定_世界与角色/题材定位.md`、`能力自测.py --root .`）。

## 三、计量：章级三个数，段级一次全量

> 读者不验算。他记的是三样：**他手上那件事到了哪一步、离死线还差多少、这条路走完了几成**。逐笔细账读者不看，攒到段末算一次就够。
> 这三个数由**书自己定**，写在 `项目配置.json` 的 `metrics` 里：默认是「现金／死线缺口／主目标进度」；代价长在身上的书换成体温、记忆段数、名分、重量——**不默认成钱**。
> 判据：项目里 `01_法则_章法节奏爽点/读者注意力.md`；阈值在 `项目配置.json` 的 `reconciliation`。

| 层 | 是什么 | 什么时候验 |
|---|---|---|
| **L1 可感数** | `metrics.l1` 里那三个数（默认：现金／死线缺口／主目标进度） | **每章**：`状态体检.py NNN` |
| **L2 半感数** | 单价、折耗、工钱；本书不用钱就换成对应的量（一服药、一道符、一天体温） | **首次出现**时登记进 `facts.prices_used`；之后只查"同物两价有无交代" |
| **L3 不感数** | 逐笔算式、总量闭合 | **每 5 章**一次，段末章（015／030／045…）必做 → `05_质检_审计评审节奏/审计/状态校验_段N.md` |

**这四种情况不等段末，当章全量回代**：单项变动 ≥ L1 当前值 50%／本章新立价位或新规矩／段末卷末章／上一章未验净。

**不许省的一条**：定稿前整章通读一遍。通读抓的不是数字，是说话人标反、同句重复、倒叙回述、指代不清——脚本判不出，一读就见。

## 五、审计报告骨架

照 `05_质检_审计评审节奏/审计/第NNN章_审计.md`：

```
# 第NNN章《标题》· 审计

> 跑数时间 …｜全部读数取自同一次运行｜正文 …（N 字／M 段）
> 口径：字数＝去标题、去空白；段＝非空非标题行；句＝按。！？切。

## 一、门禁读数        项｜阈值｜实测｜判（句检 blocking/advisory、宾语盘点、孤岛串、章检）
## 二、章级指标        字数、段数、对白占比、对白段占比、段长、叙述句长、段首"他"、最长纯叙、问号、章首交底
## 三、计量（三个数）    三个 L1 读数（章首→章末）｜离最近死线｜主目标进度；另记本章新增价位条数、是否触发全量回代
## 四、时间线与章首交底
## 五、逐项处置
   1. 宾语盘点：N 条，逐条看过，改 M 处（表格：行｜词｜判｜依据）
   2. 环境读数（只报数，不进判分）
   3. 禁词与口径
```

### 五·二、合页版（T1 标准档，一份抵三份）

## 六、改了正文之后必做（按回路走，不按心情走）

| 回路 | 触发 | 重跑什么 |
|---|---|---|
| **1 句级** | 改一句、删一个词、错字 | **只重跑该项**（句检那条／画面检那一处），其余不重跑 |
| **2 场景级** | 改场景、增删段、换顺序、修物理四查 | `句检`＋`句病检`＋`对白归属`＋`画面检`＋`章体检` **全部重跑**（字数、占比、条数都变了） |
| **3 细纲级** | 回改细纲、重写本章 | 全部重跑＋审计整份重写＋`数字登记.md` 重登记＋桥段记录改记 |

三条回路跑完，停 3 之前一律再过一次 `合门检查.py NNN`——它专门抓"改完没重跑"（审计比正文旧）与"拿豁免当通行证"（豁免没写理由）。**读数不是改完那一刻的读数，就不算读数。**

三条都要做两件：

1. 更新审计里的读数与「与细纲的偏差」，末尾写返工记录一行：`回改：句级 N／场景级 M／细纲级 K`。

## 种子登记（排段前跑）

```bash
python 08_工具_脚本/种子登记.py --list --genre 01 --role 主线
python 08_工具_脚本/种子登记.py --check "试丹"
python 08_工具_脚本/种子登记.py --seed "他靠替人试丹活着" --chapter 012 --role 主线
```

- `--list`：按类目和主线/副线列种子，挑这一段的种子。
- `--check`：这个种子用没用过（查桥段记录，也查正文）。
- `--seed`：记进 `06_追踪_状态记录/桥段记录.md` 的「种子使用记录」；重复会拒写并返回 1。
- 一个种子全书只用一次；要用“同型不同种”，换一条，不要换皮。

# 05 · 都市日常 / 职场 / 娱乐

> **一句话公式**：一个普通人想把日子过好一点，被现实按住三次，第四次他用一个别人不肯用的法子翻了过去。
> **读者买的是"我也可能过上"的可复制感**——所以每个赢法都必须看起来像读者明天能模仿的。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①真实的职业细节（流程、行话、坑）②小人物对抗结构（公司、行业、流量规则）③赢了以后生活**具体变好**（换房、还清、科室换到好的） |
| 核心循环（一段 15 章） | 定目标 → 撞墙（规则/人） → 找一个别人不用的法子 → 兑现 → 目标升级 |
| 周期 | 小循环 2—3 章（一个项目/一次考核），中循环 15 章（一个季度/一部戏） |
| 硬约束 | **对手必须是结构，不是坏人**。这类目的敌人是"制度性的不公"，写成一两个坏人就是降级 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①他的职业与一天流程（写得像内行）②一个具体的 deadline 或考核 ③一次当众的否定（领导/客户/评委） | 大段背景交代、主角吐槽式独白三页 | 他发现规则里有一条没人用的缝 |
| **第 2 章** | ①他用这条缝做了第一次尝试，成本自付 ②有一个人看见并质疑 ③结果半成半败 | 一举成名、老板当场赏识 | 副作用来了（得罪人/超预算/违规边缘） |
| **第 3 章** | ①小胜一次，收益具体（奖金/名额/一个客户）②他欠了一个人情 ③有人开始借他的手做事 | 全网爆火、行业震动 | 有个更大的坑在等（他被人当成棋子） |

## 三、职业细节库（写这类目的命根）

| 行业 | 必须写清的三个实物 | 常见误写 |
|---|---|---|
| 公司/职场 | 汇报链、考核表、跨部门审批 | 老板一句话就升职 |
| 医疗 | 值班表、耗材、医患沟通流程 | 手术奇迹般成功 |
| 律师/法务 | 立案流程、证据清单、开庭排期 | 庭上一段话翻案 |
| 娱乐/剧组 | 通告单、番位、资方关系 | 一夜爆红无代价 |
| 餐饮/门店 | 进货价、翻台率、房租占比 | 开张就排队 |
| 电商/直播 | 坑位费、退货率、投流成本 | 播一场卖爆 |

**用法**：每章至少一个"内行才知道的细节"。这是这类目唯一不可替代的竞争力。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—3 | 立职业、立困境、第一次小胜 | 他在单位站住一点 |
| 4—8 | 一个真实项目/一部戏/一场官司；他被当枪使 | 有了第一个盟友与第一个敌人 |
| 9—15 | 反击一次（用规则，不是用拳头）；段末换平台（跳槽/升职/换赛道） | 他有了自己的名字 |

## 五、爽点配方

**主力型**：⑤起势（有人肯跟他）、⑦获得（钱/名/资格）、⑧掌控（他定了规矩）。辅助：②打脸（克制使用）。

**这类目的打脸要"轻"**：不能靠拳头，靠**专业事实**。构造：对方当众否定他的判断 → 他拿出数据/流程/客户反馈 → 对方只能改口 → 收益落地（这一单归他）。

**⑦获得必须"可见"**：还清一笔债、搬进一间有窗的房、科室从夜班调到门诊。**不许用"他感觉自己被认可了"代替**。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 没有对手（一路顺风） | 每段设一个结构性阻力（编制、预算、资质） |
| 2 | 对手是纯坏人 | 把对手写成"按规章办事的人"，他能赢靠规则细节 |
| 3 | 职业细节靠想象 | 至少查三份行业资料，落到三个实物上 |
| 4 | 贵人无偿提携 | 提携要换东西（时间、忠诚、背锅） |
| 5 | 收益只写"他很高兴" | 换成可数变化：工资、房租、通勤、病历 |
| 6 | 感情线抢主线 | 感情只解决"他为什么撑下去"，不解决"他怎么赢" |
| 7 | 一章三个新人物 | 章 ≤2 个新名字，且各带一个职能 |
| 8 | 靠巧合拿到资源 | 资源必须换、借、赌来 |
| 9 | 主角道德无瑕疵 | 给他一次自私的选择，并付代价 |
| 10 | 行业黑话堆砌 | 每章 ≤3 个术语，且第一次出现要"用人话解释一句" |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2400—3000 |
| 对白占比 | 0.40—0.60 |
| 最长纯叙述 | ≤160 字 |
| 内行细节 | 章 ≥1 个 |
| 可数变化 | 段 ≥3 次（钱、职位、住处、客户数） |
| 新专名 | 章 ≤2 |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）一天的流程：几点起、干什么、被谁催
拍2（20—40%）一个 deadline 压下来，且明显不可能完成
拍3（40—60%）当众被否定，理由听起来很正当
拍4（60—80%）他翻规章/翻流程，发现一条没人用的口子
拍5（80—100%）他决定用，但要自己先垫成本
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《大江大河》 | 时代结构 + 个人选择，细节扎实 | 节奏偏慢 |
| 《我在他乡挺好的》 | 都市真实困境，情绪准确 | 爽点密度低 |
| 行业文（医疗/律政） | 专业细节带来的信任感 | 案例堆砌，主线散 |

## 十、改写清单

1. **钱**：工资/奖金/抽成 → 三个固定数字（月入、房租、一笔大支出）。
2. **力**：专业能力 → 他的"独门手艺"是什么，别人为什么学不会（要具体）。
3. **人**：同事/领导/客户 → 写清"谁能决定他的去留"。

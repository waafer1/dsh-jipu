# 01 · 对白三类与写法

> 台词只做三件事：**劝、损、絮叨**。信息不靠台词——靠物件、动作、账面。

## 一、三类

| 类 | 目的 | 怎么写 | 例（中性） |
|---|---|---|---|
| **劝** | 让对方改主意（含威胁、哀求、开价） | 给条件或给后果，一句一个动作 | “你把这担炭赊我，三天后连本带利。” |
| **损** | 贬低、戳痛处、压价 | 短句，抓对方最在意的一点 | “就你这手，还想验货？” |
| **絮叨** | 反复念、抱怨、家常 | 重复一个词或一件事，带生活细节 | “又下雨，又下雨，这月第三回了。” |

三样都不占 → 删。一场戏里三类可以混，但每一句都要能归类。

## 二、信息怎么给（不进台词）

| 信息 | 交给什么 |
|---|---|
| 价钱、行情 | 物件＋账面：秤、铜板、价牌、找零 |
| 规矩、禁忌 | 动作：有人做了，被拦下；或一张贴在墙上的纸 |
| 身份、关系 | 称呼＋站位＋谁给谁让路 |
| 计划、前情 | 动作顺序：他先做什么、后做什么 |
| 时间、期限 | 天光、更鼓、账上的日期 |

写台词时先问：**这条信息能不能落到一件物或一个动作上？** 能 → 别用嘴说。

## 三、删句测试（改版）

删掉这句：

- 信息少了 → 说明信息没落到物件动作，**去改叙述**，不是留台词。
- 关系或态度少了 → 留，这句是劝/损/絮叨。
- 什么都不少 → 删。

## 四、常见病

- **报设定**：两个人互相介绍读者已知的世界。
- **报计划**：把下一步行动用嘴说一遍，然后照做。
- **互相告知**：把对方早就知道的事再说一次。
- **解释动机**：“我这么做是因为……”——让动作说，或让对手说。
- **人人一个腔**：所有角色说话一样长、一样客气。

## 五、自检

- 这段每句台词，是劝、损、还是絮叨？归不了类 → 删。
- 删掉台词，信息少了吗？少了 → 信息该挪到物件/动作。
- 遮住说话人，能猜出是谁吗？猜不出 → 身份没落地。

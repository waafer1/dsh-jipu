## 〇、总判据（压倒其他一切）

**一段话，读者一看，眼前就是一幅画面——什么样的两个人、什么样的环境、在做什么，都表现出来了。**

检验法：写完一段，合上，问脑子里剩什么。必须同时验两关：

**第一关·成不成像**：
- 剩的是**图**（位置＋动作＋光，看得见）→ 过。
- 剩的是**状态**（"他在痛""气氛紧张""很神秘"）→ 不成。
- 状态不是画面。情绪、评价、氛围词，读者脑子里都不成像。

**第二关·全不全（四要素验收单）**：
1. **什么样的人**——不是名字，是样子：每人至少两三个视觉点；
2. **什么样的环境**——空间轮廓，带一个异常点；
3. **在做什么**——正在发生的明确动作；
4. **都表现出来了**——一个要素都不许靠上下文或读者脑补。

一段话＝一部电影的开场：环境、人物、动作三镜头全给。信息密度不够，图再干净也不及格。

**宣布＋证据法则**：「容颜无双」是宣布（给强度），「黑发如瀑」是证据（给图），连用才成立。只有宣布没有证据＝空洞；只有证据没有宣布＝扫读的读者感受不到强度。

画面是唯一不要求读者动脑的接口——图直接成像，情绪要经验，机锋要转脑子。

## 一、画面的来源（四条机制）

**演示场景（自造，通俗玄幻）**：一座石殿悬在头顶，人站在殿下的广场上，殿里正往外抽什么东西。

1. **位置异常**：石殿悬在半空——东西不在它该在的地方。反常的先被看见。
2. **光的动线**：一道细光从人的眉心溢出，流进殿顶。画面不只有静物，还有一条看得见的流向。
3. **构图**：殿在上、人在下、另一侧站着一个人——谁高谁低、谁近谁远，几句话摆完一个镜头。
4. **分镜**：全景→人→切另一侧→拉回。读者在读分格，不用自己搭场景。

**速度是画面的一部分**：「缓缓」升上去和「猛地」冲上去是两张图，删速度等于拆图。

## 二、动线句的零件（正例拆件）

> 一道凉气从他眉心溢出，缓缓融入头顶的石殿。

- **溢出**：满而外流，有量感。（强于"出来"）
- **缓缓**：速度在画面里。
- **融入**：渗进去、化进去——**殿在吸收**，带吞噬感。（强于"没入"：那只是物体沉底，殿是死的）

一句完成：源头（眉心）→速度（缓缓）→去向（石殿）。全句只有标签词是虚的（"神秘的"），骨架全是实的。

**修法：标签删掉，骨架留着。** 虚词删，动词留——动词是句子里最贵的零件。

## 三、尺子：通俗直给（快消网文）

**默认尺（2026-11-03 定）：读者喜欢通俗。**本库只认这一把尺，判据全按它裁。

| 条目 | 规矩 |
|---|---|
| 情绪 | 直给：痛就说痛，"我很痛……非常痛……" |
| 重复 | **递进重复是强调**（苍白→惨白＝加码），原地重复才是病 |
| 对白 | 意思说全，"你难道想要前功尽弃？" |
| **对白占比** | **不是标准。开局章可低到 0.08 以下**（整章对白不足 8%，全是要害钉子：下令／定价／设问），中后期冲突戏再抬。**功能密度才是标准：每句对白必须是不可替代的钉子；送信息用讲述，碰冲突用对白** |
| **句子自足** | **每句话把意思表达清楚，读者看了就明白**：①主语不省略、全称复现（"黑色蛇蛟"不缩成"它"）②因果说破（"因为……所以……"一长句闭环）③动作句自带结果 ④情绪先命名再给证据 ⑤对白单拎出来也完整。**句子零成本，画面才零成本** |
| 留白 | 不许——读者扫读，每段独立可懂 |
| 画面件 | 通用件可用（黑发如瀑、银月为冠）：即时成像 |

## 四、尸检（AI 生成病，逐条带防法）

1. **工整腔**：为对仗编因果、为节奏造句。例：「每退一步，心口沉一分」——一步对一分是凑的，且"退→心沉"的传导是编的。
   防法：问一句——**这个因果是画面里看得见的，还是我凑的？**
2. **整句否定**：看到标签词（"神秘的"）就把整句当病句扔，重写时把准动词（溢出/融入）一起丢了。
   防法：**逐词修。** 标签删，骨架留，动词最贵。
3. **拿错尺子**：拿文学腔的手感去改通俗文（单字回答、藏后手、"没有风"式留白、机锋对白）。
   防法：动笔前认准通俗直给，看 §三 的表。
4. **状态不成像**：全段在写"越来越痛"，读者脑子里没有一张图。
   防法：§〇 检验法。每个新场景第一行先给一张图：位置异常＋光源＋谁高谁低，图立住再进动作。
5. **情绪命名零证据兜底**：全章"更加激动／颇为激动／顿时动容／吃惊／疑惑／恼怒"十几次全命名、全无证据拍，人物成纸片。通俗尺允许"痛就说痛"，但**隔几处必须给一次证据拍兜底**（一两个身体反应），否则情绪词通货膨胀，读者对谁的激动都不激动。（高频反例）
6. **说话动词复读**："甲说道……众人纷纷大声回道……乙说道……"每句对白都被说道／回道拆开，读感是会议纪要。防法照旧口径：落身份并进已有动作句，或干脆省——对白自己带语气时，动词是赘肉。（高频反例）
7. **情绪递进不隔证据拍**："顿时预感到不对劲→心里隐隐不安→不安更强烈"三连命名零证据。通俗尺递进重复是强调，合法，但**递进的是程度词，中间必须垫一个证据拍**（身体反应／物／动作），隔行连着命名就是原地通胀。
8. **程度虚标**："脸色要多难看就有多难看""目光充满了火热"——程度词空转，一个图都不给，读者照旧看不到那张脸。防法二选一：**给一张具体的难看**（谁、哪个动作、哪件物），要么删掉让前后的证据拍顶上。这类病机器查不出（不含词表词），必须人工过。

## 五、同族知识点（同属场景层）

### 五·一 运镜：远景立空间，中景给互动，特写给信息

镜头是流动的，不是记者式"先全景再人走进去"：

> 远处，大殿的鎏金屋顶刺破晨雾（远景·建立空间）。主角挤过人流，肩膀撞到一个香炉，铜灰簌簌落在衣襟上（中景·人与环境发生关系）。他的目光落在一个老僧的手上——念珠转了半圈，停住了（特写·关键信息）。

**顺序有轨道（滑轨原则）**：要么远→近，要么近→远。上一句烟灰快掉了、下一句跳到窗外的鸟、再下一句服务员端菜——镜头乱跳＝散装拼图，读者晕。

古文同法：《江雪》四句就是一条运镜轨迹——千山鸟飞绝（仰视远景）→ 万径人踪灭（俯瞰远景）→ 孤舟蓑笠翁（近景）→ 独钓寒江雪（特写或拉远）。

### 五·二 五感联动：视觉只占一半，但严禁报菜名

只写视觉，读者只能"远观"；五感齐发，读者"进入"：

> 雨点击打铁皮棚顶，声音密得像爆炒黄豆（听）。空气里是咸腥的锈味（嗅）。裤脚吸饱了泥水，每走一步都拖着两条铅袋（触）。

- 感官有接力顺序：先闻到油条香，才看见油条翻金边——按真实感知的先后写。
- **比例参考**：视觉为主，听觉触觉各给一刀，心理收尾。比例不死，但全视觉＝不及格。
- **严禁五感报菜名**：五种全写一遍又臭又长。**只挑一两个最扎心的感官，往死里写。**

### 五·三 微观特写：一个细节胜过一百个形容词

> 不写"战争惨烈"——写"半截发卡扎在冻土里，齿缝还缠着几根栗色长发"。
> 不写"他很紧张"——写"喉结上下滚了一下，锁骨窝里聚了一小汪汗"。

这条是「宣布＋证据法则」的极端形态：干脆不要宣布，全是证据。量级——三流写状态，二流写动作，一流写**选得出那一个细节**。

### 五·四 反常规的身体反应

写悲伤就流泪、写紧张就冒汗＝模板，读者看腻了。换反直觉的物理反应：

> 愤怒时不摔杯子——手指轻轻摩挲杯子边缘，像在安抚它。
> 害怕时不尖叫——肩膀猛地缩起来，像被看不见的冰水浇了后颈。

陌生＋真实，因为跳出了读者预期的模板。通俗尺平时直给（"我很痛"）没问题，但关键拍子用反常规照样加分。

### 五·五 情绪不许贴标签——撕成矛盾碎片

"愧疚→低下头""愤怒→握紧拳头"是木偶戏说明书。愧疚的人会：突然易怒（安慰他就吼"别管我"）；撒谎（没加班偏说"今晚开会"）；自厌（烟头摁灭在掌心，盯着烫红的皮肤发呆）。**别告诉读者他愧疚，让读者看他怎么折磨自己。**

### 五·六 滤镜词＝隔一层玻璃（接视角铁律）

"她看见花园荒了""他听到身后有脚步"——"看见""听到""注意到""感觉到""意识到"这些词把读者隔在角色外面。删掉滤镜，直接给事件：

> ✗ 她看见花园荒了。 → ✓ 花园荒了。
> ✗ 他听到身后有脚步声。 → ✓ 身后有脚步声。

读者自动知道"他听见了"——你描述门摔上，听见就发生了。**这条是视角铁律在句法层的执行细则**：铁律管"谁的眼睛"，滤镜词管"玻璃擦不擦"。

### 五·七 人注意什么，人就是什么（描写即塑造）

同一间屋：建筑师看结构，小偷看值钱的，焦虑者看出口，丧偶的人看每样让她想起亡者的东西。**人物注意到什么，就是人物塑造本身。**没写出来的同样说话：只盯着手枪的人，看不见家具。

推论：环境描写不许中立——一切摆设都要过"此刻这个人会注意什么"的过滤。酒馆里，多疑的小偷注意到出口被堵，饿孤儿注意到桌上的面包皮，贵族注意到脏杯子。**同一个房间，三种描写，三个人。**

### 五·八 选择大于堆积；具体大于抽象

一个完美细节胜过三个及格细节。"带烟烫疤的旧躺椅"胜过"一把旧躺椅"。写完问：这个细节删了图少什么？不少就删。

### 五·九 冰山：信任读者，留缝

给读者留参与空间——读者参与搭出来的世界，他会更在乎。与通俗尺的"不许留白"不冲突：留白的是**情绪**（痛可以直说），不留的是**画面**（图必须给全）。

### 五·十 交代段＝给画面做讲解

**交代段不是与场景并列的另一种文体，它是画面的注脚。**场景是正文，交代是讲解：画面管读者**看见**，交代管读者**在乎**。没有背景，"痛也要忍着"只是一张疼的图；有了身世与天赋的落差，这张图才有分量。

通俗网文标准节奏：**钩子场景 → 一个词引爆 → 交代 → 钩回现场**。交代段三条规矩：

1. **只讲解画面里的那个动作**：交代必须回答"图里这个人为什么这么做、赌的是什么"。扯到与画面无关的设定＝资料卡，删。
2. **被关键词拽出来**：背景由场景里的一个词引爆（"废物……"三个字拽出全部身世），说明文全程围着这个词转。读者记住的不是设定，是这个词扎在哪。
3. **一段一事实，末行钩回现场**：一行一段，每行新信息零描写（身份→天赋→落差→契机→代价）；交代必须以钩子落地（"本以为撑不过三天"——他显然撑过了），把读者送回场景，不许平着结束。

交代段里**不许**：作者替读者拆表里（"表面不在意，心里却难受"——表里让动作去拆）；转折词连用（奈何×2）。

**视角注**：交代段允许短暂全知跳（进配角脑子当钩子用）——通俗尺容忍，可放心用。

### 五·十一 讲述的镜头化：一行一镜

**讲述不是画面的反面，讲得好的讲述本身就是剪辑。**整个文类只有两种镜头，交替使用：

| | 场景段 | 讲述段 |
|---|---|---|
| 镜头 | **长镜头**：运镜（远→中→特写），跟到底 | **蒙太奇**：一行一镜，快切 |
| 读感 | 在场，跟着走 | 回忆杀、情报图 |
| 检验 | §〇 四要素验收单 | **每行读完，脑子里有没有那一帧** |

一段身世快切就是六个镜头：宅院全景 → 锦衣下人 → 演武场垫底 → 背后指点 → 街市议论 → 殿门开。读者不是在读说明文，是在翻分镜。

**检验法（狠）**：讲述段任何一行，读完后脑子不出图——它就不是镜头，是解说词。**解说词连着超过两行，读者就从电影院里被请出去了。**修法：给解说词挂帧（"生活过得不错"→挂一个具体画面），或者删。

### 五·十二 冲突戏＝对白戏；打脸的六拍与信息差（通用范式）

**两章合看闭环**：开局章送信息用讲述（对白当钉子）；冲突章对白占九成——每一句都是攻击或防御，省一句就泄一分火。

**信息差＝爽点储蓄罐（最值钱的机制）**：金手指先给读者，再让所有人贬低主角——对手骂的每句话都在往爽点账户存钱，后面的巴掌全是提现。**这就是金手指必须放在第一章的原因**：没有时间差，打脸只是吵架。

**打脸六拍**：①欺（辱辱抬到位：踩碎令牌、当面退婚）→ ②忍（己方压着不能动手，蓄压）→ ③错估（所有人以为主角来求——给反转上膛）→ ④反转（主角抢定义权——一字不谈感情，只谈名分）→ ⑤加码（用对方自己的逻辑反杀：既然认为享用资源理所当然，那就把吃进去的吐出来）→ ⑥见证（旁观者的反应拍：憋着的闷气消了——放大器）。

**对白兼交代**：背景账（救命、成婚、两年供养、榜上名次的来源）由第三方在冲突对白里算出来——每个事实都是炮弹。"给画面做讲解"在冲突戏里升级为"给冲突装弹药"。

**关键词贯穿**：一个词三章三次引爆，每次加一档火力：自嘲背景 → 变成攻击 → 被更脏的词反杀。**用词的交换就是地位的交换。**

### 五·十三 收账章三拍＋阶梯感＋恩人限额（通用范式）

打脸六拍打完之后怎么收——**收比打更见功力**：

1. **压舱拍**：更高力量一击立威，然后**不打**。"要么赔偿，要么战"——威慑的价值在亮出来，不在用出去。一击＝标价，对方自己算账就会退。打脸的终点是对方认账，不是尸体。
2. **挂账拍**：反派退场带走的不是消失，是一个未来还的仇；且她退场时的内心继续误判（把隐瞒当不真心）——信息差储蓄罐在反派身上持续生息。
3. **回流拍**：赔偿实物递回主角手——**她带走骂名，他收回实物**，表面她赢实质他赢，账面无人吃亏。

**主角忍手**：压下灭门的爽点诱惑，理由全是账（底蕴、会死人、以后有的是机会）——**主角不被爽点绑架**。同一根钩子两头各挂：主角"账我亲自上门要"＋反派心里"有来无回"，方向相反，远期债挂好。

**阶梯感**：一场仗打完必须点亮天梯下一格（"那个境界曾是奢望，现在不再是奢望"）。读者追的不是这一战，是下一格。

**恩人限额钩**：金手指的源头第一次露出代价（源头那道虚影开始变淡）——金手指不是无限的，代价问题一挂，后面几卷的债都有了。钩子要包着情感（"前辈你怎么了"），不是任务提示。

**对白密度跟着回合数走，不跟章节走**：对峙回合多则密，一锤定音后立刻稀；独处消化段（痛没有对手、没有回合）全程用讲述蒙太奇。

### 五·十四 句层三招（通用范式，表现方法层）

剧情层的东西（金手指教学、报复规则、竞价结构）在 `剧情拆解库.md`，这里只收**文字怎么成像**。

**一、抽象之力给可见形状。**"数百点微光不断汇聚，凝成一团人形的雾，轮廓和他差不多，却薄得能看见背后的墙。"——力量是看不见的，给它一个形状（人形的雾）、一个参照（和他差不多）、一个量感（数百点）。**薄到透明＝弱的可视化**：读者不用被告知"还很弱"，看厚薄就知道了。同类：写"护罩还剩三层"不如写"护罩薄得能看见对面的脸"。

**二、到场用光的动线预告。**"殿门那边亮起了光"→"光很盛，来的人不少"→"一道人影掠了出来"。三镜头：殿亮了（有东西要来）→光的强度（规格）→人掠出（"掠"字带速度和贴面感）。**到场之前先给光，光的强弱就是来客的排场**——不加一个形容词，规格报完了。

**三、大场面由看客报数。**"出来的人越来越多"，接着是对白："这得有几万人吧。""怎么还有带兵器来的？"——**规模不由叙述者报数，由看的人报数**，报数本身就是反应拍。叙述者报"约数万人"是资料；旁人瞪着眼说"几万"是画面。量感在动词里同理："人**涌**了出来"——人像水，规模在动词里，不用数。

**四、微观特写选点（全章只给一处，给在赢家的赢拍上）。**"她先四下看了一眼，确认没别人，才笑到脸都皱了。"动作串：先观望（确认独占）→再笑到脸皱（贪相）。**"笑到脸都皱了"给的是图，"她很高兴"给的是结论**——且这一拍正落在"她赢定了"的那个瞬间，特写当奖励发。

### 五·十五 群像与心理的三笔（通用范式）

1. **群像心理用对视落地。**"几个老者对视了一眼"——一群人的怀疑不用挨个写，一个对视就够；群像里再给一个锚点（"为首的"），人群就有了焦点。**写一群人的心理，挑一个动作代替全部内心。**
2. **心理自由直出。**"难道真就让他们错过了？"——心里话不挂"他想""他心里闪过"，直接成句。少一层玻璃，读者直接进脑子；问句还自带不安的语速。
3. **口不对心三明治。**对白说场面话（"晚了就晚了吧，我们不过是来看看"），叙述紧贴一句心里真话（"话是这么说，可他心里的不安更重了"）——**两句一组，嘴上一层、心里一层**，通俗尺心理直给的标准件。注意：三明治里的心里话只贴一次，别对着同一种情绪连贴三张（见尸检 7）。
4. **脸色是群像的证据拍。**"为首的老者面色紧绷，跟来的几个年轻人脸色也变了"——上一段三连命名零证据，这一段用两张脸补上；群像两级分色（老者紧绷、年轻人变色），一拍写两群人。**同一情绪在相邻段落里：前段命名，后段给脸——证据拍隔段补位是合法节奏**（对照尸检 7：不合法的是同段连命三张）。

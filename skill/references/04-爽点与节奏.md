# 04 · 爽点与节奏（爽不爽、慢不慢）

> 出处：`01_法则_章法节奏爽点/爽点宪法.md`（爽）、`01_法则_章法节奏爽点/节奏铁律.md`（快）。**两份都过才算合格。**

## 一、爽点宪法 · 五条不可变

| # | 原则 | 违反的样子 |
|---|---|---|
| P1 | 每章必有一爽，且是**可指认、可复述**的一件具体事 | 一章读完只有铺垫、赶路、心里活动 |
| P2 | 爽来自"**算＋强**"双重兑现：早埋的东西 + 这一段新跳的一档力 | 靠巧合；敌人突然变蠢；"突然想起"一个办法 |
| P3 | 他可以弱，但**章末必须拿回一样东西**：钱／情报／一个人／面子／更强的 | 章末一无所有，只剩"我还会回来的" |
| P4 | **代价永远在赢之后付**，且不许抵掉本场胜利 | 赢了紧跟"可他心里空落落的" |
| P5 | **憋屈不过二**：连续两章未翻盘 ＝ 违宪 | 三章被追杀、被压制、被冤枉 |

**P0**：世界"同盟是租的、纸不约束人"不是憋屈的理由，是"算赢"的燃料。

**钱和力的次序**：赚钱是发展，变强是辅助。钱只在他换成力的那一刻才算兑现。**连着两段只挣钱不换力 ＝ 经商文，重排。**

## 二、爽点六型（触发条件写之前必须具备）

| 型 | 爽在哪 | 触发条件 |
|---|---|---|
| ① 算死你 | 对方以为在坑他，其实一直在他账上 | 提前露过一手示弱；读者看见过他埋东西 |
| ② 打脸 | 瞧不起"没姓的学徒"的人回头来求他 | 有一个当众轻视的场面，第三者在场 |
| ③ 跳档 | 借力跃升，一击翻盘 | 押了什么、代价是什么，事先写清 |
| ④ 收账 | 赖账的人被清算，连本带息 | 有一笔明确欠账，读者算得出 |
| ⑤ 起势 | 队友替他挡下致命一击，或当场变强 | 队友的成长曲线前面写过 |
| ⑥ 身份反转 | 没姓的人让别人排队来签字 | 前面有人因为"没姓"羞辱过他 |

**轮换**：同一型连用不超过 2 章；一段至少覆盖 4 型。

## 三、密度表（可核，不是感觉）

| 尺度 | 下限 |
|---|---|
| 章 | 1 个可指认爽点 |
| 3 章 | 1 个中等爽点（有回合、有反转、有代价） |
| 10 章 | 1 个大爽点（翻盘、当众打脸、敌方势力被打掉一个） |
| 一段（15 章） | 2 个名场面 |
| 一卷（5 段） | 10 个段级名场面 + 3 次跳一大档 |
| 全书 | ≈180 次结账＝180 个兑现（0.2/章） |

**代价不占爽点额度**：第二个爽点算收账／变强／打脸，不算"他付出了什么"。

## 四、七拍公式

```
① 弱 → ② 压 → ③ 亮账 → ④ 亮力 → ⑤ 翻 → ⑥ 收 → ⑦ 账
```

- 缺③：赢得像运气。缺⑥：赢了但读者不知道赢了什么。**七拍缺一拍，这场戏重写。**
- ⑦ 放在最后一句或下一章开头，不许抵掉⑥。

## 五、违宪清单（见到就删/改）

1. 连续两章没有可指认的爽点。
2. 连续三章主角没拿回任何东西。
3. 赢了之后紧跟"可他心里空落落的"。
4. 敌人降智：说不清他为什么输。
5. 靠"突然想起来"解决问题。
6. 代价在胜利之前或之中收走。
7. 连着三章同一型。
8. 一章只有钩子没有兑现。
9. 大段解释设定挤掉爽点。
10. 用"他很冷静、他很专业"代替具体动作。

## 六、节奏铁律 · 六条不可变

| # | 规则 |
|---|---|
| R1 | 没有铺垫章：每章都得有东西落地（交手／成交／翻盘都算）；交手以剧情需要出现，出现就必分输赢 |
| R2 | 一段三回合，章数按三等分（13＝4/4/5，15＝5/5/5，17＝6/6/5） |
| R3 | 前十章必须赢一次（第 9 章前没翻盘，这一段重排） |
| R4 | 世界只当行情：地理、历史、种族、阵营只通过价格、传闻、难民、军需单出现 |
| R5 | 一章只推一件主事，但必须给出"下一件更贵"的理由 |
| R6 | 读者没耐心（五条细则见下） |

### R6 五条

| # | 条款 | 怎么量 | 越界怎么办 |
|---|---|---|---|
| R6.1 | 章首 10% 内交底（输什么、赌注多大） | 全章字数 ×10% 内有没有"输／赔／欠／拿不到" | 提不动就是这场戏没赌注，重排 |
| R6.2 | 叙述射程 ≤200 字（200 字内必须有一次变化：数对不上／一句拒绝／新事实／一次开价） | `章指标.py`「最长连续纯叙述」 | 报警线不是判决：超了要在审计指明变化落点，指不出就删或并 |
| R6.3 | 欠字加转折，不加描写 | 段落涨了而事件没涨 ＝ 加水 | 加价／拒绝／新事实／断供威胁 |
| R6.4 | 同一动作连写 ≤3 句 | 通读 | 换成另一个人的口径（同一件事换人报数） |
| R6.5 | 不解释刚演过的事 | 找"也就是说""这意味着" | 删；字数不够按 R6.3 补转折 |

> R6.2 不能拿短句化去糊：把长段切成十个四字段，读数变好，读者一样在跳。判的是**信息变化**，不是段落形态。
> R6 不降低 R1—R5：快不等于空。

## 七、十种慢章（见到就删或并）

赶路章／设定章／准备章／回忆章（>640 字砍）／群像介绍章（一章两个以上新角色）／多线并行章（一章三个地点）／"三个月后"式过渡／同一对手的第三次谈判／反派视角章（>1/3）／章末总结章。

## 七·五、战斗（`01_法则_章法节奏爽点/战斗节奏表.md`）

**一句话**：这本书的战斗不是"打赢"，是"**量出来**"——每一场打完，读者必须能量出：这一次，他比上一次多付得起多少。变强的外化是一句话：**从"他被人追着跑"，到"别人被他吓跑"**。

**七条猥琐纪律**（作者令 2026-10-31，正文每场仗都过）：

| # | 纪律 | 要点 |
|---|---|---|
| 1 | 永远不站在原地 | 开打前已让半步、站下风口、背靠出口；**禁写"他站定、摆开架势"** |
| 2 | 先手即胜负 | 九成胜仗是"对方还不知道开打了"；**出手前不说话** |
| 3 | 不打脸，打下三路 | 泥、灯油、炭灰、钉子、蜂群、冰面——废人的脚和眼 |
| 4 | 跑是战术，不是败 | 败走跑得最果断；把追的人引进狗堆、泥塘、别人家的棚子 |
| 5 | 示弱是武器 | 让人一直以为他是个"跑腿的外乡人"——⑥身份反转的根 |
| 6 | 赢了立刻收尾 | 拿钥匙、拿名册、封口、转身走；不留话头 |
| 7 | 先花钱与体面，不轻易花命 | 三铜一副的引子能解决就不烧池子；能挨一身泥不挨一刀 |

**他能打谁**：人（打手、收尸队、守卡的、别的术士学徒、逃兵、抢匪）＋低档（野狗、饿狼、刚坐起来的死人）。**孤的（稀有精英）与大的（野外首领）一次都不进**（`canon/13` §五第 3 条）；卷三起他仍不打，但能**站在场边不跑**。法术只有恐惧、诅咒、眼睛、召唤——**写他放火、放雷、放光，一律废稿**。

**战斗标尺**（示例刻度，按本书金手指替换）：把能力分 5—7 档，每档写清**能控几个**、**能打谁**，代价可选（写了就一起写清）；档与档之间不许跳。**读者不看面板，只看"烧几成、控几个、付什么"。**

**密度与口径**：每段四场（速胜 1／苦战 2／败走 1），全书约八十场，**同一个对手要有第二次交手**。`项目配置.json` 明确：**交手不设每章下限，以剧情需要出现**；出现了就必须分输赢，赢不了要写明输了什么。可报的五样：**烧几成／剩几成／几副引子／碎片来源／身体代价**。苦战里挨的刀必须是他**算漏了**，不是硬扛。

## 四·五、拒绝苦逼文（作者 2026-11-06 令）

**苦是成本，不是生活。** 读者可以看主角付代价，不能看主角一直惨。

### 三条硬律

> 对白另有一条总纲：**对白是为了把事讲清楚**（`assets/对白层库/00`）。讲不清楚的、为秀而秀的，一律改成描述。

1. **每处苦，当场换到东西**：信息、钱、人情、经验、机会，任选其一；换不到就删。
2. **每章至少一个可指认的得**：哪怕很小（省下一铜、套出一句话、少挨一刀）。
3. **连续两章没有“得”** → 节奏师打回；不许用“后面会好”拖。

### 苦逼文三特征（命中两条即改）

- 主角长期**被动挨打**，没有一次主动出招。
- 苦难**没有出口**：读者看不到翻身路径。
- 苦**只涨不兑**：欠的债、受的气、挨的打，从不见回头钱。

### 改法

| 苦逼写法 | 改成 |
|---|---|
| 他被欺负，忍了 | 他当场用一条规矩挡回去，哪怕只挡一半 |
| 他穷得吃不上饭 | 他用四铜做成一笔小买卖，赚回一顿 |
| 他被人看不起 | 他做成一件事，让一个人改口 |
| 他反复回忆惨事 | 删回忆，换成当下的一次交易或试探 |

### 唯一例外

**开局第一章可以苦**，但必须同时给一个“可能性”：一个机会、一个人、一条规矩、一件东西。只苦不给路，读者第一章就走。

# 11 · 女频古言（宫斗 / 宅斗 / 权谋）

> **一句话公式**：在一个她不能明着赢的地方，她借别人的手、别人的嘴、别人的规矩，一步一步把位置拿回来。
> **读者买的是"在不能出手的地方出手"的技术**——所以赢法必须"合规"，靠嘴硬赢是死路。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①礼法与位分是真的硬（说错一句话要跪、要罚、要死）②她的每一步都借力（父兄、嬷嬷、丫鬟、外人）③赢要赢得"挑不出错" |
| 核心循环（一段 12 章） | 受压（位分/婚约/名声） → 找缝隙（礼法、人情、账目） → 布局（借第三人的手） → 翻盘 → 位分上升，新敌人出现 |
| 周期 | 小局 2—3 章（一次交锋），中局 12 章（一场婚事/一桩旧案） |
| 硬约束 | **她不掌握暴力与财权**（古代女子的真实处境），所以她必须靠信息、人情与规矩 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①她的位置（庶女/继室/失宠/待嫁）与一个具体威胁（要她嫁谁、要夺她什么）②她做一件"懂事"的事，实则记录信息 ③一个可信的盟友（丫鬟/嬷嬷） | 现代价值观宣言、穿越三章适应期 | 她发现有人在账上动手 |
| **第 2 章** | ①第一次小交锋，她退一步（退得有心机）②拿到一个证据（账、信、物证）③被对手试探 | 一次扳倒主母、父亲突然疼爱 | 对手换了打法：从明面转暗处 |
| **第 3 章** | ①借第三人的嘴把事说出去（不是她自己告状）②对手吃一次小亏 ③她被记恨，且父兄开始注意她 | 皇帝/王爷一见倾心 | 更上面的人插手了 |

## 三、她的资源（写清四样，缺一必假）

| 资源 | 内容 | 限制 |
|---|---|---|
| **信息** | 谁和谁有旧、谁欠谁、哪笔账不对 | 拿到要靠人，传出去要靠时机 |
| **人情** | 谁欠她一次、谁怕她说出去 | 用一次少一次，不可复用 |
| **规矩** | 礼法、家法、宫规里对她有利的条款 | 用规矩的人必须自己站得住 |
| **身体/名声** | 婚事、贞静、贤名 | 一旦损，几乎无法挽回 |

**铁律**：她每次赢，只能用这四样中的一两样，且必须消耗掉一点。赢完不消耗＝爽点虚。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—3 | 立位置、立威胁、第一次小胜 | 她在家里/宫里立住一点 |
| 4—8 | 一场大事（婚、丧、宴、案），她被当棋子 | 她有了第一个盟友与第一份把柄 |
| 9—12 | 反击：借长辈/外人之手清算；段末位分或处境改变 | 她换了房间（位置的隐喻） |

## 五、爽点配方

**主力型**：⑧掌控（她定了一件事的走向）、②打脸（当众、合规）。辅助：①算死你、⑥身份反转。

**⑧掌控的女频版**：不是发号施令，是**让某件事按她的意思发生，而所有人以为是别人的意思**。构造：她抛一个话头 → 有人替她说 → 长辈拍板 → 结果对她有利 → 她一句不认。

**②打脸的合规版**：她不能骂人，只能让对手**在自己设的局里失礼**。对手失礼 → 礼法罚他 → 她一句"不敢当"。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 反派降智（当面挑衅、留把柄） | 反派也守规矩，且更懂规矩 |
| 2 | 靠嘴赢（骂赢、说赢） | 换成借第三人的嘴 + 一个物证 |
| 3 | 男主无条件护她 | 护要换东西（她的秘密、她的顺从、她的婚事） |
| 4 | 位分跳太快 | 一段只升一级，且要有后果 |
| 5 | 现代思维直接碾压 | 她可以有现代判断，但手段必须用古代工具 |
| 6 | 丫鬟只是工具人 | 丫鬟有自己的家人与怕处，会背叛 |
| 7 | 宅斗写成吵架 | 每场交锋必须有一个"物"（账、首饰、信、药） |
| 8 | 所有人都爱她 | 至少两人真心不喜她，且有正当理由 |
| 9 | 宫斗无生死 | 写清罚则（杖、逐、赐死），且真执行过 |
| 10 | 结局靠男人救 | 最后一击要她自己完成 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2500—3200 |
| 对白占比（参考，不卡门） | 0.45—0.65（交锋戏靠对白） |
| 最长纯叙述 | ≤160 字 |
| 交锋 | 章 ≥1 次（小），3 章 1 次中 |
| 位分变化 | 一段 1 次 |
| 新专名 | 章 ≤3（人物多，必须带身份标签） |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）她的处境（住哪、吃什么、谁能进她的屋）
拍2（20—40%）一个具体威胁落地（要她嫁/要她让/要她认）
拍3（40—60%）她做一件"懂事"的事（送汤、抄经、替人挡话），实为探消息
拍4（60—80%）她拿到一条信息（账不对/有人来过/东西少了）
拍5（80—100%）她不动，只说了一句让某人不安的话
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《知否》 | 规矩细节、借力打力、婚事即政治 | 节奏慢，前期密 |
| 《甄嬛传》 | 群体博弈、话术的多层意思 | 反派后期降智 |
| 《庶女攻略》 | 位分与资源的具体换算 | 篇幅长 |

## 十、改写清单

1. **钱**：嫁妆/月例/田产 → 三个数字，写清"她能自由支配多少"。
2. **力**：位分 → 分几等，每等能做什么、不能做什么。
3. **人**：父兄—婆母—丫鬟 → 写清"谁有权处置她"。

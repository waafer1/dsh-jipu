# 10 · 游戏竞技 / 无限流

> **一句话公式**：进入一个有明文的规则场，别人靠强，他靠读懂了规则里没人注意的那一行，赢下结算。
> **读者买的是"公平的胜负"**——规则必须硬到作者自己也不能改。规则一软，这书立刻死。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①规则可查、胜负可复算 ②弱者有活路（靠脑子/靠配合）③每场结算有明确奖励与代价 |
| 核心循环（一段 15 章） | 进副本/进赛事 → 摸规则 → 试错（死过人） → 找到缝 → 结算 → 用奖励换下一场门票 |
| 周期 | 单副本/单场 3—5 章；一段 15 章＝三场（难度递增） |
| 硬约束 | **规则必须先公布再使用**。作者中途加的规则只能当"隐藏规则"，且必须在前文有伏笔 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①他怎么进来的（死/签约/被选中）②规则公布（具体到条数）③第一次见到死亡（有人违规当场死） | 系统长篇介绍、无限流设定讲义 | 他发现规则里有一处矛盾或空白 |
| **第 2 章** | ①第一次试错，付代价 ②结成一个临时同盟，各有算盘 ③用一个漏洞拿到第一步优势 | 一进场就无敌、全队听他的 | 有人先动手，破坏了他的方案 |
| **第 3 章** | ①第一场结算，奖励具体（积分/道具/寿命）②他活下来但没赢 ③结算提示下一场难度上升 | 完美通关、全员敬佩 | 下一场的规则里有一条对他的死局 |

## 三、规则设计（这类目的命门）

**五条要求**：
1. **可复述**：读者能用自己的话讲清（"天黑后不能出屋，出门即死"）。
2. **有边界**：什么算违规，写清判定方式。
3. **有矛盾**：至少一条规则与另一条冲突，冲突处就是主角的机会。
4. **可试错**：错了不死最好，错了会死更紧张但这章要收得住。
5. **不许作者中途改**：作者想改规则时，只能让**NPC/系统**改，且要付"世界代价"（难度上升、奖励减少）。

**"缝"的四种合法来源**：字面解释（规则写的是"人"，他是别的）、时间差（规则在某个时刻失效）、归属（规则管这块地，不管那块）、程序（要先申诉才能执行）。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—5 | 第一副本：教规则、死两个人、惨活 | 有一套自己的打法 |
| 6—10 | 第二副本：同盟背叛，他用联盟反制 | 有了一队固定的人 |
| 11—15 | 第三副本：死局，用前两场的积累破；段末结算并升层 | 他成了"老人"，开始带新人 |

## 五、爽点配方

**主力型**：①算死你、③跳档。辅助：⑦获得、⑤起势。

**①算死你的无限流版**：构造必须是——规则 A 明摆着，规则 B 藏在细节里，两者合起来构成一条路。他走过去，别人还在争论 A。**读者必须能在结算时回头验证**。

**③跳档**：不是战力爆发，是**"用规则赢规则"**——让系统/裁判按它自己的条款判他赢。事后必须有官方复述（播报/公告/解说）。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 规则随作者需要改 | 只让系统改，且付世界代价 |
| 2 | 靠隐藏信息赢（读者不知道） | 关键规则必须先公布 |
| 3 | 主角团全员聪明，别人全员蠢 | 对手至少有一个也看懂了缝 |
| 4 | 奖励只是数字，不换东西 | 每次结算写"换成了什么"（能力/道具/情报） |
| 5 | 副本与主线无关 | 每 3 个副本推进一条主线（他是谁、谁在设局） |
| 6 | 死亡无痛感 | 有名有姓的人死，且有人记得 |
| 7 | 解说腔（作者跳出来讲规则） | 用 NPC 播报/队友争论替代 |
| 8 | 无限流无终点 | 全书给一个明确目标（通关/揭穿/救人） |
| 9 | 竞技场写成擂台连胜 | 写训练、战术、对手研究、伤病 |
| 10 | 数值膨胀 | 上限先定死（积分最高能换什么），别越写越大 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2200—2800 |
| 对白占比 | 0.35—0.55 |
| 最长纯叙述 | ≤150 字（规则说明必须切成对白） |
| 副本长度 | 3—5 章/场；一段 3 场 |
| 规则条数 | 单场 4—7 条（多了记不住，少了没缝） |
| 死亡 | 单场 1—3 人 |
| 新专名 | 章 ≤3 |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）他死/他被选中，睁眼在一个陌生的屋
拍2（20—40%）规则公布（4—7 条，条条具体）
拍3（40—60%）有人不信，当场违规，死法明确
拍4（60—80%）众人开始算，他注意到一条与别的冲突
拍5（80—100%）他不动声色，先去验证最便宜的一条
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《无限恐怖》 | 规则紧张感、团队分工 | 中后期战力膨胀 |
| 《惊悚乐园》 | 副本创意与规则玩笑 | 主角过于无痛 |
| 电竞文（如《全职高手》） | 战术细节、对手研究、解说镜头 | 配角易工具化 |

## 十、改写清单

1. **钱**：积分/点券 → 你的结算货币，给"一张门票、一次治疗、一件装备"三个价。
2. **力**：能力来源 → 换来的、借来的、还是规则给的（三者差别巨大）。
3. **人**：队友/对手/系统 → 写清"谁能改规则""谁能判违规"。

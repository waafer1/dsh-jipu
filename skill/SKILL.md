# 计谱 · 书稿工序

这是**工序手册**，不是创作理论。它只说：一章从"要写"到"算写完"，过哪几道门、跑哪几条命令、产出哪几个文件、在哪一步必须停。

判据的**唯一出处是项目自己的规范文件**。本技能 references 是索引与摘要；两者打架，以项目文件为准，并指出本技能哪一条过期了。

## 〇、第一原则：读者优先

**读者读不读得下去，高于一切。** 序位：读者体验 ＞ 作者口味与红线 ＞ 项目规则 ＞ 工序效率。

- **规则和读者打架 → 读者赢**。规则标"待修"写进审计，不许悄悄绕过。
- **作者要求与读者打架 → 不擅自改**。说清读者会在第几段掉，给二选一，交作者定。
- **脚本 PASS 但读者会跳 → 没过**。脚本是下限，不是上限。
- **每章交付必须能答**：这一章读者会在哪一句停下来。

这条已经改过一条具体口径：章末钩子两个脚本判得不一样时，不再"以 `章体检` 为准"，改为**以 `读者判定` 的 WARN 为准**——它对读者更保守。

它也已经改过一条账的口径：账不再每章逐笔回代，章级只守读者会记的三个数（`references/03-门禁手册.md` §三）。**判据该跟着读者走，不该让读者迁就判据。**

## 〇·五、三条来路：我们只能借鉴，不能发明

作者 2026-11-04 定的方向，写在这儿当总纲：**通俗写法、剧情糅合、搜索可用素材代入。**

这三条合起来的意思很明确——**计谱不造体系，只做搬运、组合、代入**。凡是要"发明一套新理论"的冲动，一律按住。

执行细则见 `references/00-定位与边界.md`：三个不做（不发明世界观/桥段/文风）、四步流程（问设定→建检索→糅合→风格填充）、三换三不换、双源规则、三条验收。

| 来路 | 做什么 | 不做什么 | 对应资产 |
|---|---|---|---|
| **通俗写法** | 表达层做减法：主语不省、因果说破、情绪直给、画面先于修辞 | 不追求文学性，不为深刻加心理长段，不跟读者打哑谜 | `assets/画面例句库.md`、`assets/表情图.md`、`00_底座/文风基准.md` |
| **剧情糅合** | 桥段从库里取，靠**变体＋冷却**组合出新意；跨类目借件（把 A 类目的拍点挪到 B 类目） | 不发明新桥段，不宣称"原创剧情模型"；库里没有就拆书补，不硬造 | `assets/剧情模板库/`（P）、`assets/类目桥段库/`（Q）、`assets/结构层库/`（S） |
| **素材代入** | 真实细节**查来搬进正文**：一件物、一个动作、一句行话 | 不编专业知识，不靠形容词假装懂行；查不到就写模糊 | `assets/素材层库/`（M） |

**三条的验收方式都一样：拿现成的东西验，不拿自己的说法验。**

- 通俗写法 → 读者不划走（`读者判定` ＋ 柳直读）
- 剧情糅合 → 查冷却账，同一模板第二次必须换变体（`桥段账本`）
- 素材代入 → 硬细节有［实测］卡，查不到处已降级（审计一条"素材待核"）

**判断自己是不是在"发明体系"**：说得出这套东西是从哪本书、哪条行业做法、哪次拆书来的 → 借鉴；说不出，只能说"我觉得应该这样" → 停，别写进库。

## 一、先定位项目根

```
计谱不预设项目路径。按下面顺序判定项目根，判定到就停：

```
① 对话里用户给的路径
② 环境变量 JIPU_ROOT
③ 当前工作区根：有 项目配置.json 且并列 00_…—08_… 九层目录


| 文件 | 读什么 |

## 三、工序

### 总图：四阶段 · 三停点 · 两抽样

写一章只有四个阶段，**必停的只有三处**——其余都是动作，不是门。**三十个检查点等于没有检查点**（人一定跳），力要压在能拦住废章的地方。

| 阶段 | 干什么 | 停点 | 不过怎么办 |
|---|---|---|---|
| **A 备料**（5 分钟） | 召回 → 三问定章 → 四层取材 →（按需）素材采购 | **停 1：这章站得住吗** | 回 A 重定。带着"不知道这章要干什么"不许下笔 |
| **B 出图**（细纲） | 章名 → 七行 → 人物 → 冷却 | （停 1 的第二半，出图完成才算过） | 回 B 改细纲 |
| **C 落笔**（正文） | 写前协议 → 分段写 → 物理四查 | **停 2：句子立得住吗** | 回路 1／2 |
| **D 验收** | 机器全跑 → 人工按档 | **停 3：数字对得上吗** | 回 C 改，改完重跑 D1 |

**两抽样**（不是每章都做，但必须有）：
- **抽 1 · 每 5 章抽一章**跑全套报告——标准档走久了会松，抽一章紧回来。
- **抽 2 · 每卷首尾各一章**跑 T2 精修——卷首立调、卷尾收口，这两处松了整卷白写。

**机器每章全跑，人工按档抽样。** 机器零成本所以不省；人工高成本所以要选地方花。

### 三档：按章节重要性选，不按心情选

| 档 | 用在哪 | 跑什么 | 产出 |
|---|---|---|---|
| **T0 试写档** | 过渡章、日常章、练笔 | 停 1（简版：章名＋七行）＋正文＋句检＋画面检 | **章记 200 字**（不留报告） |
| **T1 标准档**（默认，约八成章） | 普通推进章 | 停 1＋停 2＋停 3；D1 全跑＋读者判定＋**合页审计** | 一份合页（审计／节奏／评审三节，各 5—8 行） |
| **T2 精修档** | 开篇 1—3 章、卷首卷尾、大转折、上架前 5 章 | 全套＋朗读一遍＋逐段画面核＋三份报告拆开 | 三份报告＋朗读标记 |

**选档写进细纲第一行**：`档：T1`。没写＝T1。**卷首卷尾自动 T2，不用问。**

**角色按档投入**（六角色不是每章全上——全员上阵的流程跑不动）：

| 档 | 上谁 |
|---|---|
| T0 | 沈落笔（写）＋主理人（跑机器） |
| T1 | ＋查无漏（审计，兼写节奏／评审各 3 行） |
| T2 | 六人全上：陆见微（设定核）／沈落笔／查无漏／钟有拍（节奏）／柳直读（评审）／纪长存（提交） |

**一条排座规矩（2026-11-04 首测得出）**：**纪长存不上评审席，只在提交环节出声。** 他的全部内容来自账本，空项目／首章评审时他只有"无账可记"一句——硬排进去，三个月后他就成摆设。同理，**钟有拍／柳直读在稿子有明显硬伤时不排**：这时候七人只会一致投反对票，跑两个多余的席位等于空转；先过停 2，再上这两个人判取舍。

### 三条回路：改完从哪一步重来

改稿最贵的不是改，是不知道该重跑哪些门。三条回路各自定死：

| 回路 | 触发 | 从哪重来 | 重跑什么 |
|---|---|---|---|
| **1 句级** | 句检某句 blocking、画面检某段不成像、错字病句 | 就地改那一段 | **只重跑该项**，其余门不重跑。审计记"局部回改 N 处" |
| **2 场景级** | 物理四查断（物件／位置／时间／话与账）、画面四要素缺 | 回 C 重写该场景 | **D1 全部重跑**（字数、对白占比、宾语条数都变了），审计里那个数同步改 |
| **3 细纲级** | 写完发现"这章没有位移"（钱／力／路／名四轴不动）／"输的东西不成立"／主角整章没做决定 | **停笔**，回 B 改细纲 | 本章正文**废弃重写**，不许在正文里加一句圆回来 |

**回路 3 的触发要狠**：整章废话的代价是十万字白写（002 那次就是），宁可废一章重来。判据：`01_法则_章法节奏爽点/主线推进铁律.md`。

### 返工账（每章一行，写进审计末尾）

```
回改：句级 N／场景级 M／细纲级 K
```

**每五章翻一次**：哪一类最多，说明那一层的判据没进流程——流程靠账改，不靠感觉改。

### A 备料（5 分钟，不可跳）

**A1 召回**

```bash
cd <项目根>
python 08_工具_脚本/召回.py NNN --write     # 旧账注射包 → 06_追踪_状态账本/召回_第NNN章.md
```

脚本不在或报错时的降级（照跑，不停工）：手读 `06_追踪_状态账本/上下文.md`、`伏笔.md`、上一章末 500—800 字——三样读完再动笔。

**A2 三问定章**（答完写进细纲头三行，答不出不许出图）

1. 这章读者带走**哪一张图**？（一个能画出来的场景）
2. 这章读者带走**哪一句话**？（一句台词或一句叙述）
3. 这章结束时**四轴哪一轴动了**？（钱／力／路／名，动哪条、动多少）

第 3 问答不出 → 这章八成是废话章，回章纲改任务，别写。第 1、2 问全答不出 → 这章没有记忆点，也回 B。

**A3 四层取材**（各查一处就停，别翻全套。四层都是"编"的，查真的素材另走 A4，不混进来）

- **S 卷级**：本卷山头是什么、这章离山头近还是远（`assets/结构层库/`）
- **Q 类目**：本书类目卷挑 0—1 条地皮桥段（`assets/类目桥段库/`）
- **P 拍点**：本章主拍用哪个模板、查冷却（`07_模板_复用件/剧情模板库/`＋`06_追踪_状态账本/桥段账本.md`）
- **C 人物**：谁上场、有没有新脸（`references/10-人物层.md`）

再读：`00_底座_语文能力/文风基准.md`、`画面例句库.md`（或本技能 `assets/画面例句库.md` 母本——**默认通俗直给尺**，作者 2026-11-03 定）、本章章纲行。

**A4 按需采购素材（只在触发时做，≤3 条／≤15 分钟）**

**触发**：细纲里出现正文必须说清楚的具体物／工艺／专业判断／行话／地域物产。
**不触发**：纯情绪戏、对峙戏、赶路戏、回忆戏（硬塞素材是拖节奏）。

做法：列清单（≤3 条）→ 只抓"可用细节 3 条＋不能写错的点"→ 落卡进 `02_设定_世界与角色/素材/` 与索引。
**超时或查不到 → 降级**：正文改模糊写法（视角遮挡／行家免谈／比附），卡上标［待补］；**不许编**。
硬细节必须是［实测］等级；`素材/` 与 `canon/` 不混。判据：`references/11-素材层.md`。

### B 出图（细纲 → `jipu-worldbuilder`）

产出 `03_图纸_大纲与细纲/细纲_第NNN章.md`。**先起章名再写剧情**（四步见 `01_法则_章法节奏爽点/章名规范.md` §〇）。

**停 1 卡门**（六条，一条不过就回 B）：
1. 头三行有三问的答案（图／话／哪一轴）——空一行即打回。
2. 七行施工表无空行。
3. 有"这章输了什么"。
4. 有存／兑（这章埋什么、兑什么）。
5. 人物：新人有 A/B 卡（五项硬字段：一句话／干的活／想要的具体物／怕什么／和主角的账）；一次性角色在章纲行一行三样（要什么／一个可见件／一句会说的话），不建卡。一段戏有名角色 ≤4、一章新名 ≤3、音同字不同一律改。
6. 桥段不在冷却期内，或在冷却期但换了变体；命中 `节奏铁律.md` §九 一票否决 → 打回。

**用完必须回写桥段账本**（模板号＋章号＋变体），不写下一段没法查。

### C 落笔（正文 → `jipu-writer`）

产出 `04_正文_成品/第NNN章_<章名>.md`。

**落笔协议（写之前先做三件，不做就别写）**：
- 每个新场景**第一行先给图**：位置异常＋光源＋谁高谁低，图立住再进动作。
- 每段问一句"读者脑子里剩图还是剩状态"，剩状态就重写。
- 情绪每命名一次，隔几处补一个证据拍（脸／手／身体／物），见 `assets/表情图.md`。

**停 2 卡门**：
- **物理四查**：物件状态／人物位置／时间单向／话与账，有断 → 回路 2。
- **画面抽查**：每个新场景抽一段过两关——①成像关（剩图不剩状态）②四要素关（什么样的人／环境／在做什么／都表现出来）。不过 → 回路 2。
- 细纲红线与通畅打架 → **以通畅为主**，改正文并在审计"偏差"里写清（`流水线.md` 步骤 2b）。

判据与例句：`assets/画面例句库.md`（摘要 `references/09-画面与文风.md`）。**默认通俗直给尺；句子自足（主语不省略、因果说破、对白单拎完整）按尺执行。**

### D 验收

**D1 机器必跑（零成本，每章，一档都不许省）**

```bash
cd <项目根>
python 08_工具_脚本/句检.py 04_正文_成品/第NNN章_*.md        # blocking 必须 0；warn 只报数
python 08_工具_脚本/句病检.py 04_正文_成品/第NNN章_*.md      # 宾语盘点：逐条列，末尾出「N 条」
python 08_工具_脚本/对白归属.py 04_正文_成品/第NNN章_*.md    # 连续纯引号≥3，每串判"改/过"
python 08_工具_脚本/画面检.py 04_正文_成品/第NNN章_*.md      # 滤镜/宣布/氛围/段首他她：只报数
python 08_工具_脚本/数字体检.py 04_正文_成品/第NNN章_*.md    # 每个"数＋单位"要在账上；0 处待核
python 08_工具_脚本/章体检.py NNN        # 九硬项一条命令跑完（含上述＋剧情四查）
```

**脚本在项目 `08_工具_脚本/`，新项目由 `开项目.py` 自动铺入 14 个；缺了就从本技能 `tools/` 复制。** 命令跑不起来的流程等于没流程——这是本工序的硬纪律：**手册里点名的每个脚本都必须真实存在，否则改手册，不许留死链。**

画面检四类：滤镜词（看见／听到／感到——删滤镜直接给事件）、宣布词（神秘／诡异／美丽——必须连着证据）、氛围状态词（气氛／氛围／显得）、段首他她占比（>20% 先查段首）。**情绪直给（"我很痛"）是通俗尺的合法动作，不算病。**

**D2 人工按档**

- **T1 起**：
  ```bash
  python 08_工具_脚本/读者判定.py NNN
  ```
  七条 WARN（开篇不知在哪／章末停决心／对白近零／最长纯叙过长／段首单调／对白悬空／没有心跳）＋五项打分——**第五项"爽点兑现"机器不填，柳直读自己写**。WARN 回改。
  然后出**合页审计** `05_质检_审计评审节奏/审计/第NNN章_审计.md`，三节写完一章：
  - **审计节**（`jipu-auditor`）：必含一行 `- **宾语盘点**：N 条，逐条看过，改 M 处。`——N 必须等于句病检条数，否则章检不给过。末尾加返工账一行。
  - **节奏节**（`jipu-pacer`，3 行）：本章节拍（哪几拍）／读者会在哪句停／下一章承接。
  - **评审节**（`jipu-reader`，3 行）：打分／弃读点／一章最值得留的一句。
- **T2**：三节拆成三份独立文件（`审计/`、`节奏/`、`评审/`），另加**朗读一遍**（读出声，卡的地方标出来）＋逐段画面核。

> 合页不是降标准，是同一批数据别写三遍。**T1 的合页三节，节节有数；T2 才拆开写长。**

**D3 停 3 合门（主理人，不外派）**

```bash
python 08_工具_脚本/章检.py NNN
```

三项全 PASS 才算写完：句检 blocking 0 ／句病检有盘点条数 ／审计里那个数与之相等。**数字对不上就是没写完。**

### −1 摸意图（开新书／每卷开头才有这一步，不属于写章工序）

**先问，再翻模板。** 没有选型卡不许出细纲。

| 情形 | 判定 | 问几问 |
|---|---|---|
| 开新书 | `02_设定_世界与角色/题材定位.md` 里没有 `## 选型卡` | 快 3 ／标准 9 ／深 15 |
| 每卷开头 | `卷纲_第N卷_*.md` 头部没有「本卷意图」三行 | 3 问（R1—R3） |
| 作者改主意 | 换类目／欲望／爽点主型；或卡与嘴上说的不一致 | 只问被改的项，然后重出卡 |

规矩：**一轮最多 3 问；问人话不问术语；每轮末尾复述已确认三项让他纠错；答不上来给默认值＋「不同意就说」。** 卡固定 12 行，落进 `题材定位.md`（阈值类进 `项目配置.json`）。

**卡门**：先跑 `python 08_工具_脚本/选型体检.py`（exit 1 → 停，不许出细纲）；再核四条——没卡 → 停；类目指不到 `类目模板库/0N` → 回问；「一章最爽那一下」归不进通用八型 → 回问，不许自创第九型；「不许出现」没进细纲卡门 → 补上。

**每卷开头另加一件**：查关系账——本卷结算谁的账、断哪根老线（`references/10-人物层.md` §五）。

**开新书另加一件（素材底座，一次建好）**：定"本书哪些细节必须查真、哪些可以编、哪些碰不得"，建 `02_设定_世界与角色/素材/` 六类分区（草药／矿石金属／器物工具／吃食市井／行话称谓／地域气候），先攒 10—30 条撑前 30 章。**换地图的卷再补一次**（新地域／新行当＋三句行话／一条当地规矩／一样吃食）。判据：`references/11-素材层.md`。

建底座前先分清三样，别乱查：**真实锚＝查**（物／工艺／器物／市井／气候）｜**类型惯例＝选**（魔法体系形态、学院制、种族格局、魔物生态——去 Q 库与拆书，不查）｜**自造规则＝定**（本书独有的法则与代价，进 `canon/`）。类目样板：`assets/素材层库/02-类目素材底座样例-魔法世界.md`（24 条清单＋三条独有规矩＋降级写法＋自检四条）。

细则：`references/08-引导式选型.md`；判据（三档问卷、升降档、卡格式）：`07_模板_复用件/00-引导式选型.md`。

## 四、派活契约（谁给谁什么、交什么、不许做什么）

> 光有"上谁"不够——不写接口，主理人就会把活揽在自己身上，成员退化成他的一张工牌。
> 七份 agent 文件里各写了一份更细的；这张表是**调度用的总表**。

| 角色 | 什么时候上 | 给他什么（输入） | 他交什么（输出） | 不许他做 |
|---|---|---|---|---|
| **程知序** 主理人 | 每章 | 作者指令、档位、state | 召回包、门禁读数汇总、**两条路给作者选** | 不代写、不自评、不替作者定剧情 |
| **陆见微** 架构 | 停 1 之前（出图） | 章纲行、召回包、S／Q／P／C 四库 | 细纲：头部四行（档／图／话／轴）＋七行施工表 | 不出没有"这章输了什么"的细纲；不现造设定 |
| **沈落笔** 作家 | 停 1 过后（落笔） | 细纲、文风基准、例句库、上一章末 800 字 | 正文 | 不改章名、不自己加戏、不自评"已通过" |
| **查无漏** 审计 | 停 3 | 正文、细纲、state、脚本读数 | 审计节，必含 `宾语盘点：N 条` 那一行 | 不判好坏、**不给改写方案**、不改数 |
| **钟有拍** 节奏 | T2，或两种改法都成立时 | 正文、章纲、上章节奏 | 节奏 3 行（节拍／哪句会停／下章承接） | 不为爽破逻辑；不把"打一场"当万能药 |
| **柳直读** 评审 | T1 起 | 正文、`题材定位.md` 的读者画像 | 评审 3 行（打分／弃读点／最值得留的一句） | 不替作者改稿；不给空分 |
| **纪长存** 记忆 | **只在提交环节** | state、本章改动、审计读数 | 新 rev＋五份派生视图 | 不创作、不判断好坏、旧账只标状态不删 |

**两条硬规矩：**

1. **不越级派活。** 主理人不直接把"写正文"派给查无漏，也不让审计去改句子——越级一次，七个角色就退化成一个人。
2. **排座按需，不按齐整。** 稿子有明显硬伤时只排查无漏（其余人只会一致投反对票）；两种改法都成立时才排钟有拍与柳直读（这才是对立图该出场的时候）。纪长存永远不在评审席上——空项目里他只有一句"无账可记"。

## 五、七道不可动的规矩

> **序位：读者 ＞ 作者 ＞ 规则 ＞ 效率。** 下面七条都在这个序位之下；任何一条与读者体验冲突，先改规矩，再办事，并在审计里留一句。

0. **没有选型卡不动笔。** 开新书、每卷开头先问出意图，卡片落进文件；卡不在文件里，等于没问过。写某一章时意图已定，直接干，不要拿引导当拖延。
1. **作者给点才写正文。** 用户没点名写哪一章，只出细纲。
2. **一章没落地不开下一章。** `章检.py` 三项没全 PASS，不许开新章。
3. **数出来的才算数。** "通过"必须带读数：句检几条、宾语几处、对白占比多少、最长纯叙几字、数字待核 0。不许写"读起来挺顺"。
4. **改稿走文件。** 改动落在 `04_正文_成品/`、`03_图纸_大纲与细纲/`、`05_质检_审计评审节奏/` 的文件里，不拿对话记录当交付。
5. **一句不通，整章不算完。** 章长随戏，句顺是底线；不设单章字数线，也不设离群线。
6. **档位先定，回路照走。** 每章开工先写档（`档：T0/T1/T2`，不写＝T1，卷首卷尾强制 T2）；改稿按三条回路重来——句级只重跑该项，场景级重跑 D1 全部，细纲级废弃重写、**不许在正文里加一句圆回来**。省检查可以，省回路不行。

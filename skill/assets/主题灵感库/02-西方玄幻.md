# 西方玄幻 · 主题灵感

## 母题

1. **契约与代价**——魔法、神恩、领主效忠，本质都是合同。主角每签一次，就把自己的一部分押出去。
2. **文明边缘**——帝国、教会、蛮族、商团各有一套“谁算人”的标准。主角站在缝上，得选一边，或者自己立一套。
3. **神在不在**——神迹是真的，但神不管人。主角要么替神管事，要么告诉别人神死了。

## 灵感种子

| 一句钩子 | 核心冲突 | 主角要付的代价 |
|---|---|---|
| 他是个“契约公证人”，专替人解约，直到接到一份解不掉的约 | 违约的代价是记忆 | 解一份，忘一个人 |
| 领主的粮仓着火了，他是唯一知道火是自己人放的会计 | 饥荒与真相 | 说出去，全镇恨他；不说，饿死人 |
| 教会要封他为圣徒，因为他“显了神迹”——那是他偷的药 | 造假与信仰 | 当圣徒，一辈子演；拆穿，被烧 |
| 他养了一头被判定为“灾兽”的幼龙，龙会学人说话 | 龙说出的第一句话是秘密 | 留龙，城毁；交龙，心死 |
| 边境小镇每年交一个孩子给“山里的东西”，今年轮到他妹妹 | 传统与活人 | 换人，妹妹活；不换，镇亡 |

## 误区

- 把“西方”当皮肤：城堡、法师袍、酒馆，骨子里还是东方宗门。
- 神与教会只做反派背景板，没有自己的逻辑和利益。
- 契约设定只用来发金手指，从来不让主角真的违约一次。

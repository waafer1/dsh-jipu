# 星际机甲 · 主题灵感

## 母题

1. **人机边界**——机甲越强，人越像零件。主角每次升级，都要回答“是我在开机甲，还是机甲在开我”。
2. **战争机器里的个体**——舰队、军团、编制，把人变成编号。主角要在“服从”和“保人”之间选。
3. **谁在打仗**——前线的血，后方的账。主角迟早要看见“战争是谁的生意”。

## 灵感种子

| 一句钩子 | 核心冲突 | 主角要付的代价 |
|---|---|---|
| 他是全军唯一能和机甲“说话”的驾驶员，机甲在骗他 | 信任 | 信一次，违一次军令 |
| 他驾驶的是退役机，机舱里留着上一个驾驶员的日记 | 继承与真相 | 查下去，军方盯上他 |
| 军校毕业分配，他被塞进“必死”的先锋队 | 体制 | 去，九死；闹，前程尽毁 |
| 敌方王牌机师的信号，和他失踪的哥哥一模一样 | 血缘与立场 | 认，通敌；不认，杀亲 |
| 战争结束，他成了英雄，却发现胜利是卖出来的 | 真相与荣誉 | 说，身败名裂；不说，一辈子演 |

## 误区

- 机甲只写参数和爆炸：没有“人机互相改造”的代价，就是换皮打怪。
- 军队只做背景：没有军令、军法、补给、派系，战争就没有重量。
- 主角永远正确：不会怕、不会算错、不会为了活命丢下队友。

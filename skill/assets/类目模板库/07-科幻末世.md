# 07 · 科幻末世

> **一句话公式**：世界崩了，规矩也崩了，谁能在三十天内立起一条别人肯守的规矩，谁就活到下一段。
> **读者买的是"秩序重建"的过程**，不是丧尸。所以末世文真正的货币是**规矩与据点**，不是子弹。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①灾难有硬规则（会怎样、多久、怎么防）②物资永远不够，每份消耗都要算 ③人性在分配点上暴露 |
| 核心循环（一段 15 章） | 危机 → 立规矩/划界 → 收人 → 分配冲突 → 打退一次外部威胁 → 据点升级 |
| 周期 | 小循环 2—4 章（一次搜寻/一次夜袭），中循环 15 章（一个据点/一次迁徙） |
| 硬约束 | **必须有据点**（哪怕是一辆车、一间便利店）。没有据点的末世文＝公路逃亡，撑不过 30 章 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①灾难发生的那一小时，他在做什么（具体到手里拿着什么）②他得到一个**别人没有的小优势**（一条信息/一个位置/一件工具）③第一次见到死亡 | 灾难成因讲两页、政府公告念一遍 | 他必须在天黑前到某个地方 |
| **第 2 章** | ①路上一次具体抉择（救不救、带不带、给不给）②他和一个人结伴，分工明确 ③物资账第一次出现 | 白捡满配装备、遇到全好人小队 | 结伴的人有隐瞒 |
| **第 3 章** | ①找到一个可守的点（门、窗、水、视野）②立第一条规矩（谁值夜、谁管水）③第一次外部威胁被打退 | 一夜建成堡垒 | 有更强的队伍看上这个地方 |

**三章铁律**：第 3 章必须让读者看见**一条规矩被立起来**。末世文的爽点是"我这儿有秩序"，不是"我杀得多"。

## 三、三本账（这类目必须逐章更新）

| 账 | 内容 | 写法 |
|---|---|---|
| **物资账** | 水、食、药、燃料、弹药 | 每章报一次余量（几天），消耗写清 |
| **人力账** | 谁能干什么、伤了几人、死了几人 | 有名有姓，死了要写葬礼或沉默 |
| **规矩账** | 现有几条规矩、谁违反过、怎么处置的 | 违反必须处置，处置后果必须写 |

**这三本账就是末世文的骨架。** 账乱了，读者立刻觉得"作者在瞎写"。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—4 | 灾难、逃亡、占据一个点 | 有门、有水、有两个人 |
| 5—9 | 收人、立规矩、第一次内部冲突 | 有分工，也有第一个不服的人 |
| 10—15 | 一次大威胁（尸潮/掠夺队/断水）；段末迁徙或升级 | 从"躲"变成"守" |

## 五、爽点配方

**主力型**：⑧掌控（他定规矩）、④收账（清掉掠夺者）。辅助：⑦获得、⑤起势。

**⑧掌控的写法**：不是喊口号，是**一件具体的分配**——他决定水给谁、谁出夜班、伤员占不占药。每次分配必须有人不满，且他要付代价（人心、威信、一个人离开）。

**④收账的写法**：掠夺队**必须先抢过他一次**（读者记住了），再被清算。清算要有具体物：抢回来的东西、对方的车、对方的头目。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 设定讲义（病毒来源、变异原理写三页） | 一句带过，只写"怎么防、多久发病" |
| 2 | 物资无成本 | 每章报余量，消耗写清，缺一次就出事 |
| 3 | 无据点，一路跑 | 给一个可守的点，写清门窗水电 |
| 4 | 全员好人或全员恶人 | 至少一个"合理的恶"（为了孩子抢药） |
| 5 | 丧尸/怪物无限刷 | 设密度与规律（夜间多、雨天少、声音吸引） |
| 6 | 主角武力无敌 | 限制体力、伤、弹药；打一次必须养两天 |
| 7 | 政府/军队永远消失 | 至少写一次残存秩序（哨卡、广播、救援队） |
| 8 | 规矩立了没人违反 | 必须有违反者，且处置要见血 |
| 9 | 收人不设门槛 | 收人要有条件（能干什么、带什么来） |
| 10 | 情感戏在废墟里谈恋爱 | 感情只在"分最后一口水"这种事上体现 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2200—2800 |
| 对白占比 | 0.30—0.50 |
| 最长纯叙述 | ≤160 字 |
| 物资报数 | 章 ≥1 次余量 |
| 死亡 | 段 2—4 人（有名有姓≥1） |
| 时间 | 全书给一个明确天数（第 1 天到第 N 天），章首标 |
| 新专名 | 章 ≤3 |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—15%）他在干什么（超市/地铁/工地），手里有什么
拍2（15—30%）异常出现：一个人不对、一片声音停了
拍3（30—50%）第一次近距离死亡，他做了选择（跑/救/躲）
拍4（50—75%）他意识到"今晚不能在外面"，定了一个目的地
拍5（75—100%）路上得到一个小优势（钥匙/车/一条消息），天黑倒计时
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《全球高武》类 | 规则清晰、进度可见 | 后期数值膨胀 |
| 《行尸走肉》（剧） | 人性冲突、据点政治 | 节奏拖、主角反复犯蠢 |
| 《末日爱国者》 | 物资与技能的真实感 | 说教味重 |

## 十、改写清单

1. **钱**：货币作废 → 换成"硬通货"（水、药、燃料、子弹），给兑换比。
2. **力**：安全 → 门、水、药、人，四项写清。
3. **人**：小队 → 分工表（谁值夜、谁医护、谁谈判），写清"谁第一个想走"。

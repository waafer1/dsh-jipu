# 08 · 星际 / 机甲

> **一句话公式**：一个人在一台比自己大一百倍的机器里，靠比别人更懂这台机器，赢下一场本该输的战斗。
> **读者买的是"个体在大机器里的位置"**——所以机甲/战舰必须有**具体的操作细节**，不能只是特效。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①机器的真实感（重量、过载、维修、油耗/能耗）②军阶与命令体系（他必须服从，除非有理由不服从）③每场战斗有明确的胜负条件 |
| 核心循环（一段 15 章） | 接令 → 整备（修、换、练） → 出击 → 惨胜 → 换装/升阶 → 更大的战场 |
| 周期 | 小循环 3—4 章（一次任务），中循环 15 章（一场战役） |
| 硬约束 | **每场战斗必须有"整备段"**。没有整备，机器就没有重量 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①他在机库/舰上干什么（擦甲、搬弹、看仪表）②一次真实的失误或事故（有人受伤）③他看出别人没看出的一个原因 | 星际政治格局、种族战争史、机体参数表 | 他的判断被一个军官听见 |
| **第 2 章** | ①他被临时派上一个位置（缺人）②第一次操作，笨拙但有效 ③被老兵排挤 | 一战封神、全队敬佩 | 上级给他一个不可能完成的任务 |
| **第 3 章** | ①一次小规模实战，靠"懂机器"赢 ②击落/击败一个有名字的对手 ③机体损伤，维修费/责任落到他头上 | 单机拆舰队 | 敌军中有人记住他的机体编号 |

## 三、机器写法（这类目的命）

| 维度 | 必须写到 | 写法示例（不用真数据，用感觉锚） |
|---|---|---|
| 重量 | 起步、急停、落地 | "落地时膝盖压到最低，机舱里的水壶跳了一下" |
| 能耗 | 一次满功率能撑多久 | "满推三分钟，之后就是活靶" |
| 损伤 | 哪个部位坏了会怎样 | "左臂伺服卡死，只能直线冲" |
| 维修 | 谁修、多久、多少钱 | "换一根液压杆，两天，从下月配给里扣" |
| 声音 | 什么情况下会响 | "过载报警像指甲刮铁" |

**铁律**：一场战斗只允许一个"主角光环式的操作"，且通常伴随机体损耗（报废、被记过、赔钱）。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—4 | 立位置、立机器、第一次小胜 | 他是个"有用的新人" |
| 5—9 | 一次正式任务，队伍死人，他被质疑 | 他有了自己的操作习惯 |
| 10—15 | 战役级战斗，惨胜；段末换舰/换战线 | 他升了一阶，也有了仇人 |

## 五、爽点配方

**主力型**：③跳档（一次超出预期的操作）、⑤起势（队友掩护）。辅助：①算死你、⑦获得。

**③跳档的机甲版**：不是"力量爆发"，是**用别人不敢用的方式用机器**——过载、拆除限速、用敌方武器、拿机体当掩体。事前必须让读者知道"这么干会怎样"（第三章讲过后果），他仍然干。

**⑤起势**：僚机替他挡一次，且这个僚机前面写过成长。这类目最动人的爽点是"有人愿意为他去死"，不是"他杀了多少"。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 参数表代替场面 | 一场战斗只写三个数字，其余写感觉锚 |
| 2 | 单机无敌 | 每场给一个"必须靠别人"的环节 |
| 3 | 军阶制度不存在 | 写清谁能下令、违令后果 |
| 4 | 维修免费、补给无限 | 每次出击写一行消耗与赔偿 |
| 5 | 敌国全员工具人 | 给敌方一个有名有姓的对手，且他也在成长 |
| 6 | 战斗只有输赢没有战术 | 每场写一个具体战术点（诱饵、地形、通讯干扰） |
| 7 | 主角从不犯错 | 每段至少一次因他失误死人 |
| 8 | 机甲像人一样灵活 | 设限：转身慢、视野窄、过热 |
| 9 | 舰桥政治写成办公室 | 军令有生死，写清"这个命令会死多少人" |
| 10 | 术语空转 | 术语首次出现必须给功能，不给原理 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2200—2800 |
| 对白占比（参考，不卡门） | 0.25—0.45（驾驶舱内靠通讯对话） |
| 最长纯叙述 | ≤150 字 |
| 战斗 | 段 2—4 场，每场 600—1200 字，必有整备段在前 |
| 数字 | 每场 ≤3 个（多了变参数表） |
| 新专名 | 章 ≤3（机体型号尽量少造） |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）机库里的活：擦、搬、查，手上有什么油
拍2（20—40%）一次事故：一个人被夹/被电/被烧
拍3（40—60%）众人归因于"他操作不当"，他看出是别的原因
拍4（60—80%）他说了，被一个军官听见（不是赏识，是记下）
拍5（80—100%）他被临时补位，第一次坐进驾驶舱
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《银河英雄传说》 | 战役层面的战略与人事 | 个体战斗弱 |
| 《高达》系列 | 机体重量感与战场情绪 | 少年兵设定需谨慎 |
| 《安德的游戏》 | 训练—实战的递进、指挥视角 | 篇幅短，不适合长篇连载 |

## 十、改写清单

1. **钱**：军饷/维修费/配给 → 三个数字（月饷、一次维修、一条命抚恤）。
2. **力**：机体代差 → 三代之内的差距（代差太大，战术无意义）。
3. **人**：舰—队—僚机 → 命令链（谁救谁、谁背锅）。

# 都市异能 · 主题灵感

## 母题

1. **能力即负债**——异能不是礼物，是抵押。每用一次，生活就漏一块：工作、关系、身份。
2. **隐藏的代价**——世界要求你“别让人知道”。主角要在“被看见”和“安全”之间反复选。
3. **谁在管**——如果异能真实存在，一定有人在管、在收、在卖。主角迟早要面对那个“管的人”。

## 灵感种子

| 一句钩子 | 核心冲突 | 主角要付的代价 |
|---|---|---|
| 他能听见别人对自己的真实评价，包括已死的人 | 真相与体面 | 听多了，无法再信任何关系 |
| 他每天能让一件小事“重来”一次，次数用在了同一个人身上 | 执念 | 重来一次，现实里多一道裂缝 |
| 他是异能管理局的底层档案员，负责给“意外”编理由 | 体制与良心 | 编一次，自己信一次谎 |
| 他的能力是“让别人忘记他”，包括他爱的人 | 存在 | 用一次，少一个记得他的人 |
| 全城停电那晚，只有他家亮着，因为他在“借”别人的电 | 生存与邻里 | 借一次，邻居病一场 |

## 误区

- 异能只用来打架：没有“用能力会毁掉日常生活”的压力，就没有都市感。
- 管理局/组织只做背景，不真正收税、不真正抓人。
- 主角一路藏着，从不付“藏”的代价——孤独、撒谎、失去。

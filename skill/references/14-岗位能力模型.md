# 14 · 岗位能力模型（每个环节＝一个岗位）

> 环节是流程，岗位是**人／agent 要具备什么才做得动这一环**。填岗位说明书，是为了三件事：写清 agent 的设定卡、判断它能不能胜任、能力不够时补什么资源（工具／参考／样张）。
> 一个岗位写四格：**职责（交出什么）／知识（得知道什么）／经验（干过什么才判得准）／判断力（最难的那一下）**，再加能力分级、不胜任征兆、自测题。

## 一、岗位 1：定位选型（选题策划）

### 职责（交出五样，缺一不算完成）

1. 类目 ＋ **玩法卡**（主／辅）选定，写进 `项目配置.json` 的 `playloop`；
2. 12 行选型卡填满，且每一行都能落到**具体物或数字**；
3. `metrics.l1` 三个数按本题材改定（不用钱的书写服药／符／体温）；
4. 一句话卖点 ＋ 读者画像（能指出同类三本，说清各差在哪）；
5. 第一卷目标：这一卷结束时他手里多了什么（可指认）。

### 知识

| 块 | 要到什么程度 |
|---|---|
| 类目盘 | 11 个类目的读者预期、主力型、**必踩的三个坑**（`assets/类目模板库/`） |
| 玩法卡 | 六种循环各自"读者每章拿到什么"，能一句话说清区别（`12-玩法循环.md`） |
| 结构层 | 卷段五段式、三回合、跳档次数、名场面配额（`assets/结构层库/`） |
| 金手指设计 | 代价必须可计量、有刻度、有失效条件；没有代价的能力撑不到 30 万字 |
| 桥段库索引 | 知道 Q 号怎么查，哪些桥段已经被用烂（冷却表） |
| 平台口径 | 这本书发在哪、读者按什么点开（书名＋一句话＋封面） |

### 经验（干过才算会）

- 拆过 ≥20 本同类的**章级零件**（一章一玩法，不是读后感）；
- 完整跑过 ≥1 本的 卷纲 → 细纲 → 正文 → 审计；
- 亲眼见过 ≥3 次"写到 30 万字塌掉"，并知道具体塌在哪（对手没了／目标兑现完了／地图换了人没换）。

### 判断力（这一岗真正难的三下）

1. **可施工性**：这个点子能不能落成"谁、多少钱、几天内"？落不成的，是氛围不是小说。
2. **可持续性**：金手指的代价有没有三档刻度？没有的话，第 30 万字靠什么推进。
3. **差异化**：同类已经有三本这么写，这一本多出来的是哪一处（不是"更爽"，是某一个具体机制或关系）。

### 能力分级

| 级 | 标准 | 能不能上岗 |
|---|---|---|
| L1 | 12 行填满不空，每行无形容词 | 可写第一章 |
| L2 | 开写前能预判"第几卷会塌"，并改结构 | 胜任 |
| L3 | 能组合玩法卡＋类目造新品类，且底座可复用 | 专家（可开新书线） |

### 不胜任征兆（见到就打回）

- 目标物写成"变强／证明自己／活下去"；
- 对手写成"命运／偏见／这个世界"；
- 金手指没有代价，或代价不可计量；
- 读者画像写"喜欢爽文的读者"；
- 12 行里有 3 行以上是形容词；
- 说不出同类三本，或说不出它们各差在哪。

### 自测五题（答不出就是没到 L1）

1. 第 1 章他要拿到的具体东西是什么？值多少钱、几天内？
2. 这东西他不拿会死吗？不会死的话，为什么不拿读者也不难受？
3. 谁挡着他？**这个人自己要什么**？
4. 第 30 万字时，挡他的人换成谁？
5. 同类最近三本，各差在哪一处？

## 二、岗位 2：素材采购（取材单）

**职责**：① 取材单四列填满、双源、过桥段冷却（`取材单体检.py`）；② 每个"这块我不会写"的问号，落成一条能进动作的细节；③ 本章桥段的 Q 号选定并登记。

**知识**：行当实物与行话、地域与年代的真实限制、桥段库编号与冷却表、禁忌词表。

**经验**：亲手查证过 ≥30 条一手细节（旧书／访谈／真干过的人），能一眼分出"百科细节"和"行内细节"。

**判断力**：这条细节**能不能被写成动作**——"一斤十六两"是资料；"他把秤砣从三斤那格挪到二斤那格，手腕一沉"才是素材。

**征兆**：名词堆叠没动词；同一桥段第二次用还没换型；取材单只有一源；细节来自搜索摘要。

**自测**：给一个职业，说出三条只有干过的人才知道的细节，并各配一个动作。

## 三、岗位 3：卷纲设计

**职责**：排 15 章一段的回合表——段目标／对手／三回合／三次兑现（各在第几章、什么型）／结算类型／伏笔露面表／跳档点，落 `03_图纸_大纲与细纲`。

**知识**：卷段五段式、三回合、名场面配额、玩法卡的回合结构与"章末交付"、冷却表、单章新专名 ≤3。

**经验**：完整排过 ≥3 卷，并且回看过"哪一卷塌了、塌在第几章"——没塌过就不知道节奏边界在哪。

**判断力**：①每三章要有一次**可指认的兑现**（读者能说"他拿到了什么"）；②三次兑现不同型（确认／交换／翻盘，不许连着两次同一种）；③这一卷打到什么程度（对手换没换人）。

**征兆**：整卷一个对手一件事；高潮间隔 >8 章；全是私下场、没有见证人；三次结算同质；卷末只是"更厉害了"。

**自测**：这一卷第 15 章他手里多了什么？第 8 章左右谁挡他？三次兑现各在第几章、各是什么型？

## 四、岗位 4：细纲施工

**职责**：九行（档／图／话／轴／人／地／事／卡／势）＋拍子（`playloop.beats`）＋章级红线＋追卡；过 `细纲体检.py` 才许开写。

**知识**：九行口径（事件＝专名＋物＋动作）、本卡的拍数与型表、章级红线（新专名 ≤3、回忆 ≤640 字、连续纯引号 ≤2、段首他 ≤5%）、物理四查（物件状态／人物位置／时间单向／话与数）。

**经验**：写过 ≥50 章细纲、且被正文验证过（返工 ≤2 次/章）。只写过没被验证的，不算。

**判断力**：把"事件"写成一件事，不是一段状态——"他意识到该走了"是状态；"他把铜牌塞进袜筒，退到门后，等巡夜的过去"才是事。

**征兆**：事件写"他明白了／他开始"，地点写"某地"，追卡空，拍子凑数（一句一拍）。

**自测**：念一遍"事件"，能听出一个人名、一件物、一个动作吗？

## 五、岗位 5：正文写作

**职责**：按细纲成稿；`句检` blocking 0；数字层与叙述层不混；章首 10% 交底、章末有钩子；`章体检.py` 九硬项全 PASS。

**知识**：句法基准、禁词表、AI 腔清单（`03-门禁手册.md` §九）、对白归属规则、画面检四类词。

**经验**：过 ≥30 章全套门禁，单章返工 ≤2 次。

**判断力**：①情绪用动作与物写（"他摸了三遍口袋"），不用形容词；②知道哪些数要给准数（记账日、价钱），哪些该模糊（半担、一把）。

**征兆**：空泛总结收尾、排比三连、"他感到一阵悲伤"、物件凭空出现、段末逗号连发。

**自测**：这一章最容易让读者出戏的是哪一句？改成什么动作？

## 六、岗位 6：节奏审计

**职责**：判爽点（兑现了什么、读者拿走什么）／判慢（哪一段读者会停）／出报告（T0 章记、T1 合页、T2 三份）／给返工档位（句级／场景级／细纲级）。

**知识**：六种玩法循环各自的"每章交付"、爽点密度、读者判定 R1–R7、合页三节格式（审计／节奏／评审）。

**经验**：读过 ≥200 章审计，且见过同一份稿子在不同玩法卡下判法不同。

**判断力**：分清**这章不爽**（执行：拍子没落地）和**这章演错玩法**（配置：该用探索型却套了结算型）——后者要改卡，不是改句。

**征兆**：每章都判"建议加强冲突"；报告只有形容词没有读数；把"慢"一律判成句长问题。

**自测**：这一章读者拿走的是什么？说不出来——是玩法错，还是执行错？

## 七、岗位 7：状态管理

**职责**：一章一提交（state 八字段／线／伏笔／拍点）→ 五份视图重渲染（上下文／事实词典／伏笔／数字登记／桥段记录）→ `状态体检.py` 0 错；`召回.py --write` 在开写前跑。

**知识**：state 结构、派生视图规则、旧线注射包、L1／L2／L3 计量与回代触发（变动 ≥50%／新价位／段末卷末／上章未验净）。

**经验**：跑过 ≥100 次状态体检，0 次视图陈旧。

**判断力**：只从**正文**抄数，不从细纲抄；判断哪些变动必须当章全量回代（宁可多算，不许攒着）。

**征兆**：视图陈旧、数字与正文不符、伏笔只埋不收、种子重复用。

**自测**：这一章动了哪三个数？哪个数变了却没登记？

## 八、岗位 8：合门验收

**职责**：三项全 PASS 才放行——`章体检.py` 九硬项／`章检.py` 三项对照（宾语条数与句病检相等）／`读者判定.py` WARN 处理完；按 T 档定报告形态；**放行之后**才改 state。

**知识**：门禁全表与阈值出处、豁免规则（不许自开新豁免）、三条回改回路（句级只重跑该项／场景级全跑／细纲级重写＋重登记）。

**经验**：顶过 ≥10 次"就这一次"的压力，且每次都写下了放行理由。

**判断力**：分清 CHECK（人判的小病，可带）和 FAIL（不许带进下一章）；分清"改完正文"和"改完并重跑"。

**征兆**：拿豁免当通行证、报告只有结论没有读数、改完不重跑、state 先改后验。

**自测**：这一章若放行，最坏会烂在第几章？

## 九、九环节对照（`能力自测.py`）

`能力自测.py` 数九个环节就位率：定位选型／设定卡／素材／卷纲／细纲／正文／审计／状态／合门。本表八岗＋「设定卡」一岗（由 `设定卡体检.py`、`人物卡体检.py` 把关，可并入定位选型，也可单列）。哪一环节 0%，就是那一岗没人干或干不动。

## 十、征兆 → 判据（已装／待装）

机器能判的征兆，落进脚本；不能判的，留在人工门。这张表就是"迟早要做"的清单。

| 岗位 | 征兆 | 判据 | 落在哪 | 状态 |
|---|---|---|---|---|
| 细纲 | 事件写成状态（意识到／开始／决定／成长） | 命中断言词 → FAIL | `tools/细纲体检.py` | **已装** |
| 细纲 | 事件里没有可指认的动作 | 动作词表全不中 → FAIL | `tools/细纲体检.py` | **已装** |
| 细纲 | 事件太短、写不出"专名＋物＋动作" | 事件 < 10 字 → FAIL | `tools/细纲体检.py` | **已装** |
| 细纲 | 拍子凑数 | 拍数 < `playloop.beats` → FAIL | `tools/细纲体检.py` | **已装** |
| 审计 | 报告只有结论没有读数 | 缺「NNNN 字／MM 段」→ CHECK | `tools/章检.py` | **已装（提示）** |
| 审计 | 宾语盘点条数与句病检不等 | 三数对照 → FAIL | `tools/章检.py` | 已装 |
| 状态 | 视图陈旧、数字与正文不符 | `状态体检.py` 结构＋陈旧检查 | `tools/状态体检.py` | 已装 |
| 卷纲 | 三次兑现同型／高潮间隔 >8 章／无见证人 | 解析回合表，查兑现章号与型 | 需新脚本 `卷纲体检.py` | **待装** |
| 正文 | 空泛总结收尾、排比三连、"他感到…" | AI 腔清单逐条匹配 | 可并入 `句检.py`（现在是人工勾） | **待装** |
| 素材 | 名词堆叠没动词、单源、桥段未冷却 | 取材单四列＋双源＋冷却 | `取材单体检.py` | 部分已装 |
| 合门 | 拿豁免当通行证、改完不重跑 | 比对 §六 回路表与最近一次跑数时间 | 需 `合门检查.py` | **待装** |

已装的三条今天生效：`细纲体检.py --selftest` 五例（齐／拍少／型不对／缺地点／事件写成状态），`章检.py --selftest` 三例照旧、另出 CHECK 行。

## 十二、留痕：每个作品里必须看得见这八岗

能力不是写在文档里的，是**每本书里留下产物**。哪一岗没产物，就是那一岗没干或没干成——`能力自测.py` 数的就是这张表。

| 岗位 | 每部作品必须留下的产物 | 检查 |
|---|---|---|
| 定位选型 | `02_设定/题材定位.md` 12 行 ＋ 选型卡：玩法卡、字数、文风尺、`metrics.l1` | `选型体检.py` |
| 设定卡 | `设定卡.md` 12 行 ＋ `canon/金手指与代价.md` ＋ 主角卡（五硬字段） | `设定卡体检.py`、`人物卡体检.py` |
| 素材采购 | `03_图纸/取材单_第N段.md`（四列、双源、冷却）＋ 素材卡 | `取材单体检.py` |
| 卷纲设计 | `卷纲_第N卷.md`：回合表（段目标／对手／三次兑现／型／跳档） | 卷纲体检（待装） |
| 细纲施工 | `细纲_第NNN章.md`：九行＋拍子＋追卡 | `细纲体检.py` |
| 正文写作 | `04_正文_成品/第NNN章_*.md`，过 `章体检.py` 九硬项 | `章体检.py` |
| 节奏审计 | `05_质检/审计|节奏|评审/第NNN章_*.md`，有读数、有结论 | `章检.py` |
| 状态管理 | `06_追踪/状态记录/`：state ＋ 五视图重渲染 | `状态体检.py` |
| 合门验收 | `章检.py` 三项 PASS 的输出 ＋ 放行理由（豁免要带原话） | `章检.py` |

推论三条：① 一本书写到第十章还没有卷纲，就是卷纲岗缺席，不是“后面补”；② 产物在但没读数（审计只写结论），等于没做；③ 每本书开张跑一次 `能力自测.py`，三个月再跑一次，缺哪格补哪格。

## 十三、拆书与蒸馏：给岗位供资源

拆书与蒸馏不是“攒素材”，是**给每个岗位供对应的资源**。两者给的东西不同：

- **拆书给样张与零件**（一章一玩法、五拍、兑现物）——解决“没写过，不知道长什么样”；
- **蒸馏给判据与尺子**（结构律：回合间隔、兑现频率、伏笔露面、跳档）——解决“不知道合格线在哪”。

| 岗位 | 拆书提供（样张／零件） | 蒸馏提供（判据／尺子） |
|---|---|---|
| 定位选型 | 同类的一句话卖点、读者画像、目标物与代价刻度 | 同类的主力型分布、常见死法清单 |
| 卷纲设计 | 每段的回合表（第几章兑现、什么型、隔几章） | 回合间隔分布、高潮间隔中位数、兑现型重复率 |
| 细纲施工 | 九行＋拍子的真实样本（可对照，不可照抄） | 单章新专名、回忆占比、桥段冷却的合理区间 |
| 正文写作 | 好句、好画面、动作写法（进 `画面例句库`） | 句长／对白／纯叙长度的分布带 |
| 节奏审计 | 该书哪几章被判“爽”、判法是什么 | 爽点密度、弃读点位置分布 |
| 状态管理 | 该书每章动了哪几个数 | 数字回代的频率与粒度 |
| 素材采购 | 行内细节、器物、行话 | 素材密度（每章几条真细节） |

落地规矩：

1. 拆书产物按**岗位**归档：`_书库/<书名>/岗位样张/{卷纲,细纲,兑现表,审计}.md`，每条注明章号；不进 P 库（P 库放原件），也不直接抄进正文（`仿写合规.py` 连续 20 字雷同即命中）；
2. 蒸馏产物写 `_书库/<书名>_结构律.md`，每条落得回“哪张卡、哪一章”，落不回去按幻觉处理；
3. **样张要标注“这是及格线还是天花板”**——拆神作容易把天花板当及格线，写出来全是别人的高度、没有自己的节奏；
4. 一个岗位缺资源时，先查 `_书库` 有没有对应样张，别急着让 agent 硬写。

## 十四、这层怎么用
- **写 agent 设定卡**：知识→`assets/Agent设定层.md` 的"他会什么"；判断力→"他怎么说话"；不胜任征兆→审计清单。
- **补资源**：某岗位能力不够，不是换人，是补三样之一——工具（脚本）、参考（库／样张）、判据（阈值）。
- **验收**：每岗一张自测题表，答不出就别让它上工；这比"感觉它写得还行"可靠。

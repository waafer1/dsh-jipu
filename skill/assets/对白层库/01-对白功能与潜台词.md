# 01 · 对白功能与潜台词

## 〇、总纲：把事讲清楚

对白的功能只有一个总纲：**让读者把事弄清楚**。下表六种，都是“讲清楚”的不同对象。

| 功能 | 例（中性） | 判据 |
|---|---|---|
| **送信息** | “这担炭，湿的算半担。” | 读者知道了一条规则 |
| **建冲突** | “你拿什么晾？” | 两人目标对撞 |
| **露身份** | “账上不是这么写的。” | 听得出他是账房 |
| **改关系** | “下回还有？” | 欠/怕/信变了 |
| **埋伏笔** | “三号棚空了。” | 后面要用 |
| **推节奏** | “搬吧。” | 让戏往前走 |

一句话可以兼两个功能，但**不能一个都没有**。

## 二、潜台词三法

| 法 | 做法 | 例 |
|---|---|---|
| **答非所问** | 问 A 答 B，B 才是真话 | “你怕吗？”“天黑前得卸完。” |
| **重复对方的词** | 重复一个词，态度藏在语气里 | “规矩？”“规矩。” |
| **沉默＋动作** | 不说话，只做一个动作 | 他把铜板往那边推了推。 |

潜台词不许超过两句；第三句还不说破，读者就烦了。

## 三、删句测试

删掉这句之后：

- 信息少了吗？
- 关系变了吗？
- 节奏停了吗？

三样都没变 → 删。三样只变一样 → 看它是不是本场核心；不是，压成半句。

## 四、常见病

- **说明书对白**：两个人互相介绍读者已经知道的事。
- **复读机对白**：把上一段叙述再说一遍。
- **人人一个腔**：所有角色说话一样长、一样文。
- **语气词堆砌**：“啊、呢、吧、嘛”每句都挂，读感发飘。

## 五、自检

- 这一段每句对白，功能是什么？说不出来 → 删。
- 有没有一句是“作者想说，角色不会说”的？有 → 改成动作。
- 遮住说话人，能不能猜出是谁在说？猜不出 → 身份没落地。

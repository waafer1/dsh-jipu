# 09 · 画面与文风（2026-11-03 新增）

> 唯一出处：`skills/jipu-manuscript/assets/画面例句库.md`（新项目复制到 `00_底座_语文能力/画面例句库.md`）。本文件是索引与摘要；两者打架，以例句库为准。

## 一、总判据（压倒其他一切画面规则）

**一段话，读者一看，眼前就是一幅画面——什么样的人、什么样的环境、在做什么，都表现出来了。**

每段过两关：

1. **成像关**：合上书问脑子里剩什么。剩的是**图**（位置＋动作＋光）→ 过；剩的是**状态**（"他在痛""气氛紧张"）→ 不成。状态不是画面。
2. **四要素关**：什么样的人（每人两三个视觉点）／什么样的环境（空间轮廓＋一个异常点）／在做什么（明确动作）／都表现出来了（一个要素不许靠上下文脑补）。

**宣布＋证据法则**：「容颜无双」是宣布，「黑发如瀑」是证据，连用才成立。

## 二、默认尺：通俗直给（作者 2026-11-03 定）

**读者喜欢通俗。本库只认这一把尺，判据全按它裁。**

通俗尺五条最要紧的：

| 条目 | 规矩 |
|---|---|
| **句子自足** | 每句话读者看了就明白：主语不省略、全称复现；因果说破；动作句自带结果；情绪先命名再给证据；对白单拎出来也完整。**句子零成本，画面才零成本** |
| 情绪 | 直给（"我很痛……非常痛"），递进重复是强调不是注水 |
| 对白占比 | **不设上下限，只报数**。开局章可低到 0.08 以下（全是要害钉子）；**功能密度才是标准**：送信息用讲述，碰冲突用对白 |
| 留白 | 不许——读者扫读，每段独立可懂（情绪可直说，**画面不许留白**） |
| 画面件 | 通用件可用（黑发如瀑），即时成像 |

## 三、画面的四条机制（通俗玄幻范式归纳，［推断级］）

1. **位置异常**：东西不在它该在的地方，反常的先被看见。
2. **光的动线**：画面里有一条看得见的流向（一道凉气从眉心溢出、流进头顶的殿）。
3. **构图**：谁高谁低、谁近谁远，几句话摆完一个镜头。
4. **分镜**：全景→人→切另一侧→拉回，读者在读分格。

**速度是画面的一部分**：「缓缓」和「猛地」是两张图。**动线句零件**：源头→速度→去向，动词最贵（溢出＞出来，融入＞没入）；修法是**标签删掉、骨架留着，逐词修不整句扔**。

## 四、交代段＝给画面做讲解

通俗网文标准节奏：**钩子场景 → 一个词引爆 → 交代 → 钩回现场**。三条规矩：

1. 只讲解画面里那个动作（这个人为什么这么做、赌的是什么）；与画面无关的设定＝资料卡，删。
2. **被关键词拽出来**：背景由场景里的一个词引爆（"废物"），说明文围着这个词转。
3. **一段一事实，末行钩回现场**：一行一段、零描写，末行必须是钩子，不许平着结束。

交代段允许短暂全知跳当钩子用——通俗尺容忍，可放心用。

## 五、讲述的镜头化：一行一镜

讲述不是画面的反面，讲得好的讲述本身就是剪辑：场景段＝长镜头，讲述段＝**蒙太奇一行一镜**。检验：讲述段任何一行读完脑子不出图，就是解说词；**解说词连着超过两行，读者就被请出电影院了**。修法：给解说词挂一个具体画面，或删。

## 六、冲突戏三件套（打脸六拍／收账三拍／信息差）

- **信息差＝爽点储蓄罐**：金手指先给读者，再让所有人贬低主角——骂的每句话都在存钱，巴掌全是提现。**金手指必须第一章**，没有时间差，打脸只是吵架。
- **打脸六拍**：①欺→②忍→③错估→④反转（抢定义权）→⑤加码（用对方逻辑反杀）→⑥见证（旁观者放大器）。
- **收账三拍**：压舱（更高力量一亮就走，一雷＝标价，打脸终点是认账不是尸体）→挂账（反派退场继续误判，信息差持续生息）→回流（她带走骂名他收回实物）。
- **关键词贯穿**：一个词三章三次引爆，每次加一档火力——用词的交换就是地位的交换。
- **阶梯感**：一场仗打完必须点亮天梯下一格。
- **对白密度跟回合数走，不跟章节走**。

## 七、画面八条细则（详见例句库 §五）

运镜三景＋滑轨原则（远→近或近→远，镜头不许乱跳）／五感联动但**严禁报菜名**（挑一两个感官往死里写）／微观特写（一个细节胜一百个形容词）／反常规身体反应（关键拍子加分）／情绪撕成矛盾碎片（别写"愧疚→低头"）／**滤镜词删掉**（"她看见花园荒了"→"花园荒了"）／人注意什么人就是什么（环境描写过"此人此刻会注意什么"的过滤）／选择大于堆积。

## 八、尸检四条（AI 生成病，逐词修不整句扔）

1. **工整腔**：为对仗编因果（"每走一寸，指尖麻一层"）——问：这个因果画面里看得见吗？
2. **整句否定**：删标签词时把准动词（溢出／融入）一起丢了——逐词修。
3. **拿错尺子**：拿文学腔手感改通俗文（单字回答、藏后手、留白机锋）——动笔前认准通俗直给。
4. **状态不成像**：全段写"越来越痛"没有一张图——回到总判据两关。

## 九、画面检工具（v1.1.8 增，只报数不判分）

```bash
python <技能包>/skills/jipu-manuscript/tools/画面检.py <章文件>     # --top 5 摘更多例句；--selftest 自检
```

报四类数，读数贴进审计，人工按本库判读（脚本是下限）：

| 类 | 查什么 | 判读口径 |
|---|---|---|
| 滤镜词 | 看见/看到/瞧见/望见/观察到；听到/听见/闻到/嗅到；注意到/感觉到/感到/意识到 | 删滤镜直接给事件（§五·六）。**情绪直给不算病**（"我很痛"合法），但"感到＋名词"（感到一阵寒意）多半状态不成像，人工核 |
| 宣布词 | 神秘/诡异/恐怖/可怕/美丽/漂亮/英俊/丑陋/奇怪/古怪 | 宣布必须连证据（§〇）。逐处看旁边有没有图，没有就补图或删 |
| 氛围状态词 | 气氛/氛围/显得 | 读者脑子里不成像（尸检 4）。"显得漂亮"是评价不是图 |
| 段首他她占比 | 段落以他/她开头 | 用动作、物件、对白、时间起句；>20% 先查段首 |

**起场景的落笔协议（写手侧）**：每个新场景第一行先给图——位置异常＋光源＋谁高谁低，图立住再进动作；写完一段合上问脑子剩什么，剩状态就重写。

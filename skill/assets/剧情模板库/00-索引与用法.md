# 剧情模板库 · 索引与用法

> **这库是什么**：网文常见桥段（开局、打脸、争夺、背叛、危机、感情、反转、突破、收尾）的**拍点结构**。每个模板给：前置条件、五拍、兑现物、变体、冷却、滥用信号、反套路改法。
> **姊妹库**：`../类目桥段库/`（Q 库）收**按类目**组织的桥段（Q-1xx 东方玄幻仙侠 … Q-10xx 女频现言，每条标证据等级）。细纲工序两库交叉查：先用 Q 定这道菜是哪个菜系的，再用 P 摆盘。

> **这库不是什么**：不是"照着写就行"的配方。**模板的价值在冷却与变体**——同一个模板第二次用必须换变体，第三次用必须换功能。不换就是套路，读者会在评论区提前报出下一拍。

P-<册号><序号>     例：P-203 = 第 02 册（打脸与立威）第 3 个模板

## 二、每个模板的统一格式（照这个写，照这个查）

```
### P-xxx 模板名
- 适用：类目编号（01—12）
- 前置条件：缺一不可，缺了就写不成立
- 五拍：① ② ③ ④ ⑤（每拍一句，句末标功能）
- 兑现物：读者拿到什么（必须是可数的）
- 变体：A/B/C 三种换法
- 冷却：N 章内不许再用；一段 ≤M 次
- 滥用信号：出现即改
- 反套路：两条改法
```

## 三、冷却规则（硬指标，不许口头说"注意别重复"）

| 模板级别 | 同一模板最小间隔 | 一段（15 章）上限 | 全书软上限 |
|---|---|---|---|
| **核心大模板**（P-101 退婚、P-301 拍卖会、P-701 身世揭秘） | 60 章 | 1 次 | 3 次（每次必须换变体与场） |
| **常用中模板**（P-202 当众打脸、P-401 招人、P-801 突破） | 12 章 | 2 次 | 不设（但连续三次必须换型） |
| **气氛小模板**（P-104 被逐、P-502 栽赃） | 6 章 | 3 次 | 不设 |

**冷却账本**：`06_追踪_状态账本/桥段账本.md` 记"模板号 + 章号 + 变体"。细纲阶段先查账本，同一模板在冷却期内 → 换变体或换模板。

**为什么必须记账**：作者记不住自己 40 章前用过什么，读者记得。**读者比作者更擅长发现重复**。

## 四、组合规则（三个不许）

| # | 规则 | 违反的样子 |
|---|---|---|
| **C1** | **一段只许一个核心大模板。** 拍卖会 + 秘境 + 身世揭秘挤在 15 章里，三个都塌。 | 读者记住的是"很乱"，不是任何一个名场面 |
| **C2** | **两个模板不许同一型爽点。** P-202（打脸）+ P-206（身份揭露）同段使用，必须有第三个不同型的模板夹在中间。 | 连着两章"他其实很厉害"，读者麻木 |
| **C3** | **模板必须服务于本章的位移。** 用完一个模板，主角的"钱/力/名"至少一项要变。不变 = 这个模板是填充物，删。 | 打了三章，读者不知道他赢了什么 |

## 五、怎么用（四步）

1. **查账本**：`06_追踪_状态账本/桥段账本.md` 看这个模板上次什么时候用的、用的哪个变体。
2. **对条件**：读"前置条件"。缺一条 → 要么补铺垫（3—8 章），要么换模板。**不许硬上**。
3. **选变体**：上一次用 A，这次用 B 或 C。三个都用过 → 这个模板这段停用。
4. **落细纲**：把五拍填进 `07_模板_复用件/细纲模板.md` 的八拍里，每拍填**具体物**（谁、多少、几天）。

## 六、反套路三板斧（模板用久了的三条解法）

| 斧 | 做法 | 例子（P-202 当众打脸） |
|---|---|---|
| **换视角** | 用旁观者/对手的视角写这一拍 | 全章从"踩他的人"视角写，最后一句才切回主角 |
| **换代价** | 赢了但立刻付一样东西 | 打脸成功，但那位长辈从此不再见他 |
| **换对象** | 把"打脸"换成"救人"或"认输" | 他当众认输，反而赢了人心（更高级） |

**一条铁律**：**同一个模板的第三次使用，必须是被"反着用"的那次**。正着用三次＝套路；第三次反着用＝读者以为看懂了，结果被翻了一下。

## 七、防"模板脸"自检（写完一段问五句）

1. 这一段用了几个模板？>3 个 → 太挤，删。
2. 有没有两个模板同型？有 → 违反 C2。
3. 每个模板的五拍，有没有哪一拍是空的（填不出具体物）？有 → 删这一拍。
4. 读者能不能提前说出下一拍？能 → 换变体或反着用。
5. 用完这些模板，主角的位移是什么（一句能说清）？说不清 → 这段是填充。

# 引导式选型（先问后写）

> 位置：`07_模板_复用件/00-引导式选型.md`。系统层通用件，`开项目.py` 会带到新书。
> 性质：**入口机制**，不是模板。它决定「用哪份模板」，不决定「怎么写」。
> 关系：类目模板库与剧情模板库给**下限**，本文件负责把作者的意图问成一份**可核的选型卡**，再拿卡去指认模板。
> **v2（2026-11-01）**：拿一本书跑了一遍深档十五问，改了五处——Q6 改为「举三个例子」、Q8 允许答「不设字数」、Q13 允许答「待拆」并给替代拆法、Q15 允许「未定」但上架前必须回填、深档开头声明 Q1—Q9 不重问。（试跑记录归项目层，跟着那本书走，不进通用资产。）

## 〇、为什么要有这份

**一张空白的类目模板，会被当成作品写出来。**

模板库的正确用法是「写完对照，看有没有跌破下限」；错误用法是「照着模板填内容」。两者产出完全不同的东西：前者是作者的书，后者是模板的复印件。分界线只有一条——**动笔前有没有把意图问出来**。

所以顺序钉死：

```
问意图 → 出选型卡 → 卡指认模板 → 写 → 门禁 → 回写桥段账本
```

不许倒过来。**没出卡就翻模板，等于替一个还不存在的作者写书。**

## 〇·二、五问快筛（借平台标签，30 秒定方向）

> 2026-11 新增。平台（番茄一类）的标签体系是读者真实的检索语言，先用它把方向钉住，再进 3／9／15 问深档。
> 五问只定“写哪一类、给谁看”，不定“怎么写”。

### 三条冲突检查（快筛完立刻做）

1. **“无金手指”配“无敌流/系统流”** → 自相矛盾，必改一个。
2. **“群像”配“单女主”** → 叙事重心打架，选一个当主。
3. **“苟/冷静”配“战神/杀伐果断”** → 主角行为逻辑会分裂，先定他遇事的第一反应。

### 红海提示（2026 上半年榜单口径）

- **超红海**：都市脑洞、动漫衍生（榜首在读 50 万以上）
- **红海**：玄幻脑洞、都市高武、游戏体育
- **蓝海**：都市修真、历史古代、悬疑灵异（榜首在读 20 万以下）

快筛落在红海，不劝退，但要求：**金手指必须更强、爽点必须更密**；落在蓝海，允许慢一点，但**前三章必须给一个可指认的位移**。

## 一、三档与触发

| 档 | 问题数 | 一轮问几个 | 什么时候用 | 出口 |
|---|---|---|---|---|
| **快档** | 3 | 3（一次问完） | 用户已给出类目＋主角欲望＋节奏倾向；或明说「别问了，直接给」 | 出卡（标注哪几项是默认值）→ 直接进细纲 |
| **标准档** | 9 | 3（分三轮） | **开新书的默认档** | 出卡 → 进卷纲／大纲模型 |
| **深档** | 15 | 3／3／3／6（四轮） | 要投稿或上架；或用户答话里出现**两次以上互斥要求** | 出卡 ＋ 题材体检 ＋ 对标拆解 → 进大纲模型 |

**必须触发**：

1. **开新书**（第一次对话，项目还没有 `02_设定_世界与角色/题材定位.md`，或该文件没有 `## 题材卡`）
2. **每卷开头**（`卷纲_第N卷_*.md` 没有「本卷意图」六行）—— 只问 3 问，不重走全套
3. **作者中途改主意**（换类目、换主角欲望、换爽点主型）
4. **答话与选型卡冲突**（他嘴上要的东西和卡上写的不是一回事）

**不触发**（别拿引导当拖延）：

- 写某一章、改稿、体检、跑门禁、排一段章目 —— 意图已经定了，直接干
- 用户点名要一份东西（「出第 5 章细纲」）
- 用户已经在本轮答过对应问题 —— 复述即可，不重问

## 二、问题本身（照抄可用）

**总原则：问人话，不问术语。** 不写「题材核心」「爽点主型」「位移方向」，写「读者点开是为了看什么」「第一章让他赢还是输」。每个问题给 2—4 个**能落地成不同写法**的选项，外加一句「你说了算」。

### 快档 Q1—Q3（对应题材卡第 1、2、4 项）

| # | 问法 | 选项示例 | 填到 |
|---|---|---|---|
| Q1 | 读者点开这本书，是为了看**什么发生**？ | ①一个弱者用有限的东西赢一次 ②一个人从底层爬到说话算数 ③一个秘密被一层层揭开 ④一段关系被磨出来 | 题材卡 1 |
| Q2 | 主角这一卷要**拿到什么**？拿不到会怎样？ | ①钱／资源（拿不到就活不过这个月）②一个肯替他说话的人 ③一个身份／一张凭证 ④一门手艺的下一步 | 题材卡 2 |
| Q3 | 第一章，让他**赢一次**还是**先输一次**？ | ①先输，输到见底 ②小赢，但赢的代价立刻出现 ③赢一场大的，后面全是账 | 题材卡 4 |

### 标准档 Q4—Q9

**第二轮 · 承诺**（他凭什么被看见）

| # | 问法 | 填到 |
|---|---|---|
| Q4 | 读者最想看他被**谁**看见？（对手／同行／他护着的人／不认他的那套规矩） | 题材卡 2、3 |
| Q5 | 他靠**什么**赢？只能选一个主项：算得清／打得脏／熬得住／有人肯替他 | 题材卡 4、8 |
| Q6 | **举三个例子**：最近三章里，各是哪一下最爽？（至少一个要能落到具体动作或一句台词） | 题材卡 6、7 |

**第三轮 · 约束**（他不许变成什么）

| # | 问法 | 填到 |
|---|---|---|
| Q7 | 这本书**不许出现**什么？（系统面板／商战／降智反派／主角靠嘴赢／无限开挂） | 题材卡 9、10 → 升为硬门 |
| Q8 | 一章大概多少字、一段多少章、全书写多长？（**可以答「不设字数，按戏走」**——答了就在 `length_policy` 写理由，报告里不出现"字数达标与否"） | `项目配置.json` `structure`／`targets.length_policy` |
| Q9 | 写到最后一章，他**仍然不改**的那一条是什么？ | 题材卡 10、11 |

### 深档 Q10—Q15（第二轮之后追加）

> **Q1—Q9 已有答案的直接复述核对，不重问。** 深档加的是市场侧的四问与渠道一问，不是把标准档再问一遍。

| # | 问法 | 用来定 |
|---|---|---|
| Q10 | 同类里你想站到**哪三本**旁边？（一本对手、一本气质、一本结构，各说拆什么） | 对标组，进题材定位「主对标」 |
| Q11 | 你和它们**不一样的那一句**是什么？（一句话，不许用形容词堆） | 差异点；写不出 → 回 Q1 重问 |
| Q12 | 这个类目**最常见的三种死法**，你避哪几个、认哪几个？ | 毒点清单 → 硬门 |
| Q13 | 对标那本的开篇三章，各干了什么？（**没有正文可答「待拆」**，见下） | 开篇三章范式校准 |
| Q14 | 对标一章几个爽点、几章一次大兑现？ | `coolpoint.density`／`combo_interval` |
| Q15 | 发哪儿、怎么更新？（决定段落长度与钩子强度。**现在可以答"未定"**，见下） | 节奏与钩子阈值 |

**Q13 没有一手正文怎么办**——答「待拆」，但必须按这个顺序把能拆的先拆掉，不许拿简介冒充正文拆解：

1. **拆目录与章名**（公开）：前十几章叫什么；"代价""规矩""第一桶金"这类词有没有做成结构；
2. **拆简介与标签**（公开）：它承诺什么；标签里有没有决定性的词（种田／经营／系统／同人）；
3. **拆章节长度与更新节奏**（公开）：每章多长、多久一章；
4. 正文留空，标「待拆：需购阅」。

**Q15 未定怎么办**——拆成两个时点：

- **现在**：可以答「未定」。给了就按三平台各给一句默认推演（节奏、章长、钩子强度差异），标 `默认`，**不阻塞工序**；
- **上架前**（定稿门／投稿前）：必须回填真实平台与更新节奏，回填前不许对外发布。


## 三、升降档判定（硬规则，不许凭感觉）

| 信号 | 动作 |
|---|---|
| 用户一句话里已给出**类目 ＋ 欲望 ＋ 输赢姿态** | 降到**快档**，3 问核对即可 |
| 用户说「随便」「你定」「都行」 | **不降档**。按标准档给默认值，但必须逐项写明「我按 X 走」，让他有机会否 |
| 答话互斥（既要爽又要慢／既要碾压又要真实／既要爽文又要文学） | **升一档**，并当场逼二选一：这两条只能留一条，留哪条 |
| 类目跨两个（「玄幻＋悬疑」） | **升一档**，先定**谁是皮谁是骨**（主类目写骨架，副类目只改气氛与桥段偏好） |
| 同一问题答非所问两次 | **换问法**，不重复原句；换完还答不上 → 给默认值并标 `默认` |
| 用户说「别问了」 | **立刻停**。用已答项 ＋ 默认值出卡，卡上标清哪几项是默认，一句「不同意就说」 |
| 用户中途换类目 | 回本文件 §一 第 3 条，**重出卡**，并回头标出已写章节里作废的部分（不许只改卡不改稿） |

## 四、问的五条规矩

1. **一轮最多 3 问。** 一次抛九个问题，用户会乱答，答出来的卡比空卡更坏。
2. **问句不含术语。** 出现「爽点主型」「位移」「存兑」这类词，等于让他替你干活。
3. **选项必须能落地。** 每个选项后面要能接一句「那第一章就写成……」；接不上的选项是废话。
4. **每轮末尾复述三件已确认的事**，格式：「已定：①… ②… ③…。这三条有要改的吗？」——复述是给他纠错的机会，不是礼貌。
5. **答不上来给默认值，不许空转。** 一句「这条我先按 X 走，你不同意就说」，然后往下走。

## 五、答案落哪：选型卡

选型卡固定 **12 行**，是整个机制唯一的交付物。开新书写进 `02_设定_世界与角色/题材定位.md`；每卷开头写进卷纲头部。

```markdown
## 选型卡（YYYY-MM-DD，档位：快／标准／深）

| # | 项 | 内容 | 来源 |
|---|---|---|---|
| 1 | 类目（主／副） | 主：⋯；副：⋯（只改气氛） | 作者答 Q1 ／ 默认 |
| 2 | 读者点开看什么 | ⋯ | 作者答 Q1 |
| 3 | 主角这一卷要拿到 | ⋯；拿不到就⋯ | 作者答 Q2 |
| 4 | 第一章姿态 | 先输／小赢付代价／赢大的 | 作者答 Q3 |
| 5 | 他靠什么赢（主项） | 算／打／熬／人 | 作者答 Q5 |
| 6 | 一章最爽的那一下 | ⋯ | 作者答 Q6 |
| 7 | 不许出现 | ⋯（≤5 条，逐条升硬门） | 作者答 Q7 |
| 8 | 篇幅节奏 | 单章⋯；一段⋯章；全书⋯章 | 作者答 Q8 |
| 9 | 他到最后一章仍不改 | ⋯ | 作者答 Q9 |
| 10 | 对标三本 | ⋯（只学结构，不抄桥段） | Q10 ／ 默认 |
| 11 | 差异一句 | ⋯ | Q11 |
| 12 | 本卷意图 | 这一卷他要什么／必然失去什么／卷末收在哪 | 卷头 3 问 |
```

**每一行都要能回答「所以第 N 章该怎么写」。** 答不出来的行，是一句正确的空话，划掉重写。

**卡落盘后跑一次体检，别靠眼看**：

```bash
cd <项目根> && python 08_工具_脚本/选型体检.py     # exit 0 才许进细纲；exit 1 = 卡不齐
```

它查四件：`## 选型卡` 段在不在、12 行齐不齐、有没有空项、「不许出现」有没有写。写过「未定」的项会报 NOTE —— 不算失败，但开写前要知道它是空的。

### 每卷开头只问 3 问（卷头专用）

| # | 问法 | 填到卷纲头部 |
|---|---|---|
| R1 | 这一卷结束，他手里**多了什么**？ | `卷目标` |
| R2 | 这一卷他**必然失去**什么？（说不出失去，这卷没有代价） | `卷末必然失去` |
| R3 | 卷末那一章，他**站在哪、看着什么**？ | `卷末收在哪` |

## 六、选型卡 → 模板的指认规则

| 卡上的项 | 指到哪 | 怎么用 |
|---|---|---|
| 1 类目 | `类目模板库/01`—`12` | 取它的「节奏骨架／爽点配方／毒点清单」当校验表；**开篇三章范式**当对照，不当脚本 |
| 2、3 欲望与位移 | `剧情模板库/03 资源与争夺`、`04 组织与人心`、`08 成长与突破` | 按「他要拿什么」选册，不按「哪个模板好看」选 |
| 4 第一章姿态 | `剧情模板库/01 开局与入局` | 赢／输／赢完付代价，分别对应 P-101／P-102／P-103 一类 |
| 5 主项（算／打／熬／人） | `剧情模板库/02 打脸与立威`、`05 压力与危机` | 主打「算」→ 多用信息差型；主打「人」→ 多用组织型 |
| 6 那一下 | `01_法则_章法节奏爽点/爽点宪法.md` 通用八型 | 卡上写的那一下必须能归到八型之一；归不上 → 回问 Q6 |
| 7 不许出现 | `类目模板库` 该类的毒点清单 | 卡上 5 条**升为硬门**，写进细纲卡门；没上卡的规矩，不许临时加 |
| 8 篇幅节奏 | `项目配置.json` | 只改阈值字段，不动其它 |
| 10、11 对标与差异 | 题材定位「主对标」 | 只拆结构（拍点、密度、钩子位），不搬桥段 |

**三条禁令**：

1. **不许自创第九型爽点。** 归不进通用八型的「爽」，多半是作者自己觉得爽。
2. **模板不进正文。** 五拍是骨架，落笔要拆成动作、对白、数字；照着五拍抄出来的段落读着像提纲。
3. **用完必回写。** `06_追踪_状态账本/桥段账本.md` 记「模板号 ＋ 章号 ＋ 变体」；不写，下一段查不了冷却，第三次就成了套路。

## 七、五个常见失败

| # | 失败 | 长什么样 | 怎么防 |
|---|---|---|---|
| 1 | 问了不记 | 对话里问完，卡没落盘；下一章又问一遍 | 出卡才算问完；卡必须在文件里 |
| 2 | 记了不用 | 卡上写「不许商战」，正文里还是报价谈了半章 | 卡第 7 项逐条进细纲卡门，写细纲时逐条打勾 |
| 3 | 一次问太多 | 九个问题砸过去，用户随手选，卡全是矛盾项 | 一轮 3 问，硬规矩 |
| 4 | 把选项当结论 | 用户选了「先输」，就以为全书基调定了 | 选项只是入口；每轮复述 ＋ 出卡核对 |
| 5 | 改主意不回溯 | 换了类目，卡改了，已写的章节没标作废 | 改卡必须同时标出作废章号，像 rebuild 那样留记录 |

## 八、一句话

**先问出他要什么，再决定用哪张纸；问不出来就给默认值并说明，绝不替他定，也绝不空着手翻模板。**

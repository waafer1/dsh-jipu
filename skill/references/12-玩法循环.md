# 12 · 玩法循环（先选玩法，再选爽点型）

> 本文件是**玩法卡库**，不是宪法：一张卡＝一份资源配置单（回合结构／型表／章末交付／违宪）。库里没有默认卡，哪张上场由选型环节指定，写进细纲表头与 `项目配置.json`。框架只保证"按卡演、按卡判"，不保证哪张卡是对的。

> 这一层管**读者每章拿到的那口东西是什么**。型（六型／八型）和拍子（七拍）都挂在玩法下面，不是全书通用骨架。

## 〇、卡格式

每张卡五栏，缺一不许上场：

```
玩法名 / 读者每章拿到什么 / 回合结构（几拍） / 型表（每章选一，同型≤2章） / 章末必须交付 ＋ 违宪两条
```

结算型＝卡 1，型表就是现行六型，拍子就是七拍——它是最成熟的一张，不是唯一一张。

## 一、为什么要单列一层

现在整套爽点文法只有一种循环：

```
欠 → 压 → 亮（凭证）→ 翻 → 收 → 账
```

它把任何题材都拧成债务故事：主角开局欠、每章讨、卷末清算、配角按欠条排队。不是这套不好——它只适合**结算型**题材。玩法是读者每章获得的那口东西，结算只是六种里的一种；把一种当全部，写什么都是账房。

## 二、六种循环（一本选主一辅，一段之内不换）

| # | 玩法 | 读者每章拿到什么 | 回合结构 | 章末必须交付 | 典型题材 |
|---|---|---|---|---|---|
| 1 | **结算型** | 一口"该我的回来了" | 欠→压→亮→翻→收→账 | 拿回一样具体东西（钱／情报／面子／人） | 债务、复仇、商战、宫斗、争产 |
| 2 | **探索型** | 一条"原来如此" | 异象→试探→付代价→知道 | 一个新事实 ＋ 一个更贵的疑问 | 悬疑、盗墓、灵异、无限流 |
| 3 | **经营型** | 一步"我的盘子大了" | 定目标→调度→交付→扩张 | 一个交付物（产能／人手／地盘／信誉） | 种田、宗门、商会、基建 |
| 4 | **关系型** | 一层"他对我变了" | 距离→越界→代价→靠近 | 一次可指认的态度变化（一句话／一个动作） | 言情、群像、师徒、家族 |
| 5 | **成长型** | 一档"我过线了" | 卡点→练→崩→过线 | 一次可量化的过线（能控几个／打谁／撑多久） | 修真、竞技、学院、武学 |
| 6 | **对抗型** | 一寸"我压住他了" | 试探→换招→吃亏→定胜负 | 一场明确胜负 ＋ 付出的代价 | 战争、江湖、竞技、末世 |

**选法**：看"读者追这本书图什么"。图出气→1；图解密→2；图看着长大→3；图人和人之间那点劲→4；图数值往上跳→5；图硬碰硬→6。主玩法定全书骨架，辅玩法只做换气口（一段最多两章）。

## 三、型表按玩法分（六型只是第 1 种的型表）

| 玩法 | 型（每章选一，同型连用 ≤2 章） |
|---|---|
| 结算型 | ①算死你 ②打脸 ③跳档 ④收账 ⑤起势 ⑥身份反转（现行六型，原样保留） |
| 探索型 | ①线索咬合（两条不相干的线接上了）②假解被推翻（他信的原来是别人喂的）③代价换真相（知道要付什么）④旁人证词（第三人一句话改写全部） |
| 经营型 | ①交付超预期 ②成本被砍 ③对手断供 ④意外产能（废料变原料） |
| 关系型 | ①破防一句话 ②替她挡一次 ③误会拆穿 ④立场对调 |
| 成长型 | ①卡点（怎么练都不过）②偷师（从对手身上学一记）③崩后重来（练废一次）④过线（量得出来的那一档） |
| 对抗型 | ①先手（出手前不说话）②换招（他变了打法）③吃一次亏（算漏了）④定胜负 |

## 四、拍子的地位

七拍 `弱→压→亮账→亮力→翻→收→账` 是**结算型的专用骨架**，不是全书通用。别的玩法用四拍：

| 玩法 | 四拍 |
|---|---|
| 探索型 | 起疑 → 试探 → 付代价 → 知道（留一个更贵的疑问） |
| 经营型 | 缺口 → 调度 → 交付 → 扩张 |
| 关系型 | 距离 → 越界 → 代价 → 靠近 |
| 成长型 | 卡点 → 练 → 崩 → 过线 |
| 对抗型 | 试探 → 换招 → 吃亏 → 定胜负 |

判据不变：**缺一拍，这场戏重写**；最后一拍只放最后一句或下一章开头，不许抵掉前一拍。

## 五、宪法怎么套

`爽点宪法` P1—P5 里，两条是通用的，两条是结算型专属：

- **通用**（六种玩法都过）：P1 每章一件可指认的事；P4 代价永远在赢之后付；P5 憋屈不过二。
- **结算型专属**：P2「算＋强双重兑现」、P3「章末拿回一样东西」——换成所选玩法的"章末必须交付"那一栏。

密度表同理：`全书 ≈180 次结账` 只在结算型成立；其他玩法按"交付物"计数（比如探索型 ≈180 条真相、成长型 ≈60 次过线）。

## 六、落位（改哪些格子）

1. 细纲表头「母题」一栏拆成两格：`玩法（主/辅）｜型`，先选玩法再从该玩法的型表里选一型；
2. 卷段"三回合"按所选玩法的回合结构排，不按七拍；
3. 节奏师（钟有拍）先判"这一章是不是在演它自称的玩法"，再判爽不爽——**玩法和演法对不上，比爽点弱更严重**；
4. 爽点宪法按玩法分节：通用三条 ＋ 各玩法两条专属，不再一份通吃。

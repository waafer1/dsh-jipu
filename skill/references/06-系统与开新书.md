# 06 · 系统与开新书

> 出处：`00-索引.md` §〇（九道工序＋系统与项目分离）、`08_工具_脚本/开项目.py`、`08_工具_脚本/能力自测.py`。

## 一、底座与项目是两层（这是 2026-11-01 最大的结构变化）

`00-索引.md` 原话：**本系统是通用创作系统，不绑定任何具体作品。**

| 层 | 含哪几层目录 | 换书时怎么办 |
|---|---|---|
| **系统层**（底座） | `00_底座_语文能力`、`01_法则_章法节奏爽点`、`07_模板_复用件`、`08_工具_脚本`（不含 `_` 前缀一次性脚本） | **原样复制**到新项目 |
| **项目层**（这本书自己） | `02_设定_世界与角色`、`03_图纸_大纲与细纲`、`04_正文_成品`、`05_质检_审计评审节奏`、`06_追踪_状态账本`、`项目配置.json` | **不复制**，用新书自己的资产 |
| 半通用 | `01_法则/战斗节奏表.md`、`金融案例库.md`、`00_底座/环境锚点库.md`、`02_设定/题材定位.md` | `开项目.py` **明确排除**——它们是上一本书专属 |

> 判据：一条规则若提到具体人名、地名、物名、书名，它就是**项目层**的；换书时不能带走。

## 二、开一本新书

```bash
cd <项目根>                                     # 已确认的那本书的根目录
python 08_工具_脚本/开项目.py --list                 # 先看会复制哪些底座件
python 08_工具_脚本/开项目.py <新项目名>              # 默认建到项目根的同级：<父目录>/<新项目名>
python 08_工具_脚本/开项目.py <新项目名> --root <目标根>
```

它做四件事：①建 `00`—`08` 九层目录骨架 ②复制底座文档与全部门禁脚本 ③生成 `00-索引.md`（书名换成新书名、dataview 路径同步）④生成 `项目配置.json` 模板（**阈值保留默认、词表清空、豁免清空**）。

**它不做**：不复制 canon／角色／正文／审计／追踪／战斗节奏表／金融案例库／题材定位／环境锚点库。目标目录已存在会直接退出，不覆盖。

## 三、开完新书的五步

1. 填 `项目配置.json`：题材阈值、`environment.wow_proper_nouns`（专名词表）、`local_places`（地物词表）。**不填词表，环境读数全部为 0，但不判分**——所以不填也不卡门，只是没读数。
2. 建 `02_设定_世界与角色/题材定位.md` 与 `world.md`；建 `03_图纸_大纲与细纲/总纲.md`（总纲→卷纲→章纲）。
3. 跑 `python 08_工具_脚本/召回.py --selftest` —— 索引空就说明 02/03 还没喂料。
4. 跑 `python 08_工具_脚本/能力自测.py`，把九环节达标率落到 `06_追踪_状态账本/能力自测报告.md`。
5. 写第一章，再跑 `python 08_工具_脚本/章检.py 1` 验门禁是否通。

## 四、能力自测：先看短板再动手

参考读数：某次新项目实测 **5／9（56%）**——九环节里缺的四项，通常是人物卡、桥段账本、素材底座、读者判定。

| 环节 | 判 | 短板怎么办 |
|---|---|---|
| ① 灵感 | ❌ | 学 `语文学习知识` 7.7 主题四类＋盘活三步；第八章母题识别 |
| ② 题材推荐 | ❌ | 学 `02_设定_世界与角色/题材定位.md`；第八章类型学 |
| ③ 大纲模型 | ✅ | — |
| ④ 剧情构建 | ✅ | — |
| ⑤ 内容生成 | ❌ | 学 `00_底座/句法基准.md`＋`文风基准.md`；7.1 修辞、7.4 表达方式、7.8 桥段 |
| ⑥ 章检句检 | ✅ | — |
| ⑦ 读者评价 | ✅ | — |
| ⑧ 修改 | ❌ | 学 7.2 修改思路；3.7 物理四查；第八章文体学 |
| ⑨ 定稿 | ✅ | — |

**用法**：接一个"从零起一本新书"的活时，先提醒作者这四个短板；接"照现有细纲写正文"的活，⑤⑧ 是默认风险点，落笔前先读句法基准 §八 十条。

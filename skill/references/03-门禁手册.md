# 03 · 门禁手册（脚本怎么跑、数怎么读）

> 出处：`01_法则_章法节奏爽点/流水线.md` 门禁章、`00_底座_语文能力/句法基准.md` §九「谁能查」、`项目配置.json`。所有命令在**项目根目录**下跑。

## 一、一条命令的活

```bash
python 08_工具_脚本/章体检.py NNN
```

实际输出（示例，数字按项目实测替换）：

```
== 第012章《试丹》体检
  字数 2400｜段 70｜对白 0.28｜最长纯叙 170
  PASS   章检（句检＋宾语＋审计）       通过
  PASS   对白归属 孤岛              0 处
  PASS   数字体检 待核              0 处
  PASS   章名落地                 "试丹"在正文里
  PASS   章首 10% 交底            有数＋赌注
  PASS   章末钩子                 末段有未结的事
  PASS   禁词 / 元信息词 / 占位符 / 视角情绪词   无
  CHECK  段首重复                 <主角名>×5、<称呼>×5
  CHECK  句长单调                 最长连续相近 5 句
  PASS   感官平衡                 视2／听4／嗅1／触17
  PASS   破折号密度                1.5 处/千字（4 处）
  PASS   与上一章重复句              无
  人工：
   [ ] 细纲八拍逐拍勾（拍点是否落到正文）
   [ ] 物理四查：物件状态／人物位置／时间单向／话与账
   [ ] 存兑：这一章存了什么、兑在哪一章
  结论：通过（硬项 9 项，过 9）
```

**读法**：`PASS` 是硬项，`CHECK` 是提示（人判），`人工` 三项脚本不判、必须人填。`结论` 只看硬项。

**不过的样子**（第 004 章草稿，2026-11-01 实跑）：

```
== 第004章《挂着》体检
  字数 1950｜段 58｜对白 0.1554｜最长纯叙 325
  FAIL   章检（句检＋宾语＋审计）           不通过
  ...（其余 8 项 PASS）
  结论：不通过（硬项 9 项，过 8）
```

读法：字数 1950 与对白 0.1554 **不进硬项**（本项目不设字数线；对白低要靠豁免或重排），真正卡住的是"章检"这一项——它连带三项：句检 4 处 blocking、审计文件还没写、宾语盘点得重跑。**最长纯叙 325 > 200**，是报警线，审计里要指明变化落点，指不出就删或并。

## 二、单件工具的用途与判读（表内命令全部实装，随包 tools/ 走）

> 口径一条：**表里没有的脚本就是没有**。要加命令先写脚本，再改这张表——反着来会写出一堆跑不起来的命令。
>
> 口径二条：**一律在项目根目录下运行**（表里 `08_工具_脚本/xxx.py` 是相对项目根写的）。`选型体检.py`／`能力自测.py`／`账本体检.py` 不带参数，靠当前目录向上找 `项目配置.json`；在别处跑会报"0 行""找不到"，那不是稿子的问题。要么先 `cd` 到项目根，要么显式给路径（`选型体检.py --file 02_设定_世界与角色/题材定位.md`、`能力自测.py --root .`）。

| 命令 | 报什么 | 怎么判 |
|---|---|---|
| `python 08_工具_脚本/句检.py <章>` | blocking N ／ warn M | **blocking 必须 0**（长句／引号不配对／重复字／半角标点／段末逗号／空行连发／括号）；warn 逐条看 |
| `python 08_工具_脚本/句病检.py <章>` | 把字句／被字句／对向给／是…的 四类逐条列 | **逐条判**宾语在不在、施动者有没有；末尾出「宾语盘点：N 条」，这个数进审计 |
| `python 08_工具_脚本/对白归属.py <章>` | 连续纯引号段 ≥3 的每一串＋行号 | 每串判"孤岛（改）"或"例外（独白／自言自语／街上吆喝）" |
| `python 08_工具_脚本/画面检.py <章>` | 滤镜词／宣布词／氛围词／段首他她占比 | **只报数不判分**；情绪直给不算病，"感到＋名词"多半状态不成像 |
| `python 08_工具_脚本/章指标.py <章>` | 字数／段数／对白占比／段长 mean·p90／最长纯叙／最长单句／段首他她／连续纯引号 | 对 `项目配置.json` 的阈值；`--json` 供别的脚本吃 |
| `python 08_工具_脚本/数字体检.py <章>` | 待核的"数＋单位"清单 | **0 处待核**；有就改正文或补登记。`一＋量词`默认放过（泛指） |
| `python 08_工具_脚本/章体检.py NNN` | 九硬项 PASS/FAIL ＋ 读数 | 一条命令跑完上面几件＋剧情四查（章名落地／章首交底／章末不决心／禁词） |
| `python 08_工具_脚本/章检.py NNN` | 三项对照：句检 blocking／句检盘点条数／审计写的条数 | **三项全 PASS 才算写完**；数不相等就是没写完 |
| `python 08_工具_脚本/读者判定.py NNN` | 七条 WARN（R1—R7）＋五项打分 | WARN 回改；第五项"爽点兑现"机器不填，留给人 |
| `python 08_工具_脚本/设定卡体检.py` | 12 行设定卡逐行核：缺行／空行／类目不在 12 类目 → exit 1 | 开新书、改设定后；缺行不许进检索 |
| `python 08_工具_脚本/仿写合规.py --source <来源>` | 与来源连续 N 字（默认 20）雷同的位置 | 定稿前；命中即回改 |
| `python 08_工具_脚本/召回.py NNN --write` | 旧账注射包 → `06_追踪_状态账本/召回_第NNN章.md` | 写新章前跑；包里空＝state／伏笔没喂够 |
| `python 08_工具_脚本/账本体检.py` | state 八字段／线／伏笔／拍点结构 ＋ 派生视图是否陈旧 | 结构错就改 state；视图旧了重渲染 |
| `python 08_工具_脚本/选型体检.py` | 12 行选型卡缺哪几行 | 缺行 → 不许写第一章 |
| `python 08_工具_脚本/能力自测.py` | 九环节就位率 | 新书开张跑一次，三个月再跑一次 |
| `python 08_工具_脚本/开项目.py <书名>` | 铺九层＋复制底座与工具＋生成起始文件 | 目标已存在会拒绝；开完立刻跑选型体检 |

**每个脚本都带 `--selftest`**：换机器、换 Python 版本后先跑自检，别拿坏工具判稿。

## 三、账：章级三个数，段级一次全账

> 读者不验算。他记的是三样：**手上多少钱、离死线还差多少、总债还掉几成**。逐笔算式读者不看，攒到段末算一次就够。
> 判据：项目里 `01_法则_章法节奏爽点/读者注意力.md`；阈值在 `项目配置.json` 的 `reconciliation`。

| 层 | 是什么 | 什么时候验 |
|---|---|---|
| **L1 可感数** | 现金／死线缺口／总债进度 | **每章**：`账本体检.py NNN` |
| **L2 半感数** | 单价、折耗、工钱 | **首次出现**时登记进 `facts.prices_used`；之后只查"同物两价有无交代" |
| **L3 不感数** | 逐笔算式、总额闭合 | **每 5 章**一次，段末章（015／030／045…）必做 → `05_质检_审计评审节奏/审计/账本校验_段N.md` |

**这四种情况不等段末，当章全量回代**：单笔收支 ≥ 当前现金 50%／本章新立价位或新规矩／段末卷末章／上一章账未验净。

**不许省的一条**：定稿前整章通读一遍。通读抓的不是账，是说话人标反、同句重复、倒叙回述、指代不清——脚本判不出，一读就见。

## 四、章级阈值的出处

| 项 | 阈值 | 出处 |
|---|---|---|
| 对白字数占比 | **只报数，不设上下限**（作者 2026-11-06 令） | `章指标.py`；不进任何卡门 |
| 连续纯引号段 | ≤2 | `01_法则_章法节奏爽点/流水线.md` 章级 |
| 段首"他" | ≤5% | 同上 |
| 章末钩子 | 100%（转场章 ≤2 例外） | `hook.chapter_end_required` |
| 章首交底 | 前 10% 出现赌注 | `pacing.stake_by_pct` |
| 连续纯叙述 | ≤200 字（报警线） | `pacing.max_pure_narration_run` |
| 同动作连写 | ≤3 句 | `pacing.max_same_action_run` |
| 单章新专名 | ≤3 | `节奏铁律.md` §六 |
| 单章回忆／解释 | ≤640 字 | 同上 |
| 禁用词 | 系统／面板／穿越／现代／分析师／册子／名册／户籍／籍属／上册／无籍 | `01_法则_章法节奏爽点/流水线.md` 章级 |

## 五、审计报告骨架

照 `05_质检_审计评审节奏/审计/第NNN章_审计.md`：

```
# 第NNN章《标题》· 审计

> 跑数时间 …｜全部读数取自同一次运行｜正文 …（N 字／M 段）
> 口径：字数＝去标题、去空白；段＝非空非标题行；句＝按。！？切。

## 一、门禁读数        项｜阈值｜实测｜判（句检 blocking/advisory、宾语盘点、孤岛串、章检）
## 二、章级指标        字数、段数、对白占比、对白段占比、段长、叙述句长、段首"他"、最长纯叙、问号、章首交底
## 三、账（三个数）    手头现金（章首→章末）｜离最近死线｜总债进度；另记本章新增价位条数、是否触发全量回代
## 四、时间线与章首交底
## 五、逐项处置
   1. 宾语盘点：N 条，逐条看过，改 M 处（表格：行｜词｜判｜依据）
   2. 环境读数（只报数，不进判分）
   3. 禁词与口径
   4. 物理逻辑四查
## 五之二、数字体检    命令与结果（N 处待核）
## 六、与细纲的偏差
## 七、章检            三项对照
## 八、结论            过／不过 + 一句理由 + 关键读数
```

**必须出现的那一行**（少一个字都算没做）：

```
- **宾语盘点**：N 条，逐条看过，改 M 处。
```

### 五·二、合页版（T1 标准档，一份抵三份）

T1 章不写三份报告，改一份**合页**，仍落在 `审计/第NNN章_审计.md`（`章检.py` 在这找那一行）。三节：

```
## 审计（照上面骨架，可压到二~七节）
## 节奏（3 行）  节拍：哪几拍｜读者会在哪句停｜下一章承接什么
## 评审（3 行）  打分 x/10｜弃读点：第 N 段（原因）｜最值得留的一句：…
## 返工账       回改：句级 N／场景级 M／细纲级 K
```

- **合页不是降标准**：三节节节有数，只是不写长。
- **T2 才拆三份**（`审计/`、`节奏/`、`评审/` 各一份），另加朗读标记与逐段画面核。
- **T0 只写章记 200 字**：一行读数＋一句"这章读者会记住什么"。不写节。

## 五、豁免（引用要带原话）

`项目配置.json` 的 `exemptions` 按项目实际写，引用时写明 `scope`／`field`／`reason`。示例：

| scope | field | 值 | 理由 |
|---|---|---|---|
| 第012章 | `absolute_dates` | — | 示例：正文里的记账日属账目层给准数；叙述层仍用相对时间 |

**不要自己开新豁免**——新豁免要作者点头，并落进 `项目配置.json`。

## 六、改了正文之后必做（按回路走，不按心情走）

| 回路 | 触发 | 重跑什么 |
|---|---|---|
| **1 句级** | 改一句、删一个词、错字 | **只重跑该项**（句检那条／画面检那一处），其余不重跑 |
| **2 场景级** | 改场景、增删段、换顺序、修物理四查 | `句检`＋`句病检`＋`对白归属`＋`画面检`＋`章体检` **全部重跑**（字数、占比、条数都变了） |
| **3 细纲级** | 回改细纲、重写本章 | 全部重跑＋审计整份重写＋`数字登记.md` 重登记＋桥段账本改记 |

三条都要做两件：

1. 更新审计里的读数与「与细纲的偏差」，末尾写返工账一行：`回改：句级 N／场景级 M／细纲级 K`。
2. 再跑 `章检.py`，确认宾语盘点条数与句病检输出相等。

**动了数字 → 同步 `06_追踪_状态账本/数字登记.md`；动了 state 才算提交。**

## 种子台账（排段前跑）

```bash
python 08_工具_脚本/种子台账.py --list --genre 01 --role 主线
python 08_工具_脚本/种子台账.py --check "试丹"
python 08_工具_脚本/种子台账.py --seed "他靠替人试丹活着" --chapter 012 --role 主线
```

- `--list`：按类目和主线/副线列种子，挑这一段的种子。
- `--check`：这个种子用没用过（查桥段账本，也查正文）。
- `--seed`：记进 `06_追踪_状态账本/桥段账本.md` 的「种子使用记录」；重复会拒写并返回 1。
- 一个种子全书只用一次；要用“同型不同种”，换一条，不要换皮。

## 九、AI 腔自检清单（成稿后逐条勾，命中即改）

- [ ] 空泛总结：“他终于明白了”“一切尽在不言中”
- [ ] 排比三连：三个“不是……而是……”
- [ ] “不仅仅是……更是……”
- [ ] “在这个时代”“在当今社会”
- [ ] 情绪标签：“他感到一阵悲伤”
- [ ] 比喻堆叠：一段里两个以上“像／仿佛”
- [ ] 万能转折：“然而，事情并没有那么简单”
- [ ] 总结式收尾：“这就是……的意义”

命中两条以上，整段重写，不要逐句修。

# 01 · 细纲施工（一章的施工图）

> 出处：`01_法则_章法节奏爽点/章施工标准.md`（主）、`01_法则_章法节奏爽点/爽点宪法.md`、`01_法则_章法节奏爽点/节奏铁律.md`、`07_模板_复用件/细纲模板.md`。冲突以原文为准。

## 一、一句话

**章纲是事件清单，细纲是施工图。** 清单写"他去赊了一担炭"；施工图写"他去赊炭、被雨淋了、验货的说湿的算半担、他问出一句规矩、把半担挂成三天后重验"。

换算（001 实测）：**章纲 1 字 ≈ 成稿 26 字**。要到 6000 字，"发生什么"栏得写 150—220 字、含三件事；中位 32 字的章撑不起来。

## 二、章名先行（四步，顺序不能反）

1. 先定章名——本章必须发生的那**一下**，三字说出来。
2. 章名变终点——最后一拍落在它身上。
3. 倒推对手——章名决定谁出场。
4. 写完回读——找不到那一下，改正文，**不许改章名**。

细则见 `01_法则_章法节奏爽点/章名规范.md`（2026-10-31 作者令："即章名决定剧情走向"）。

**三种合格章名，只能选一种**：动作（翻秤砣／让路）／物件（一副棺材／剑鞘）／台词（管饭吗／不短秤）。
**四类不许用**：余额（十七银半）、期限（第九日）、数量（四十副）、纯状态（夜里）。例外只有一条——**这个数字本身就是这一章的意外**（三天、三百人、哪一格）。
**四条硬约束**：≤4 字；不含"账、算、价、数、单、券"六个字根；全书不重名；必须能在正文里指出那一下。
**配比（每 15 章）**：动作 4—8、物件 3—6、台词 1—3、带数字 0—3；动作型不许超 8 个，否则这一段像一串动词。

## 三、七行施工表（空一行，不许开写）

| 栏 | 填什么 | 反例 |
|---|---|---|
| 起·缺什么 | 缺多少、几天内要 | "他很缺钱" |
| 事一·他去办 | 一个动作，一个具体的人 | "他去打听消息" |
| 事一·碰壁 | 谁挡的、他凭什么挡、他的规矩是什么 | "没人帮他" |
| 事一·他换到什么 | 可指认的一件东西（一条规矩／一个名字／一次让步／一个时辰／一条路） | "他想通了" |
| 事二·更贵的麻烦 | 换到的东西带出来的新价 | （无） |
| 事二·落在哪个动作 | 章末最后一个动作 | "他下定了决心" |
| 存／兑 | 存什么、兑在哪一章 | （空） |

## 三·二、细纲文件的结构（照 `07_模板_复用件/细纲模板.md`）

```
frontmatter: 章 / 卷 / 类型:细纲 / 状态:待铺 / 档:T1
头部四行（缺一不许出图）：
  档：T0／T1／T2（不写＝T1；卷首卷尾强制 T2）
  图：这章读者带走的那一张图——能画出来
  话：这章读者带走的那一句——台词或叙述
  轴：这章动了四轴哪一条（钱／力／路／名），动了多少
表头一行：一句话｜出｜挡（本章碰壁 2 次上下，每次换到可指认之物）｜换｜存（"…"（兑 0XX／0XX））｜母题
一、逐拍（拍 1 出 → 拍 2 挡 → 拍 3 换 → 拍 4 挡/换 → 拍 5 → 拍 6 → 拍 7 存 → 拍 8 钩子）
二、账（现金进出｜数字回代，每笔乘法回代｜生活质量线：住／吃／人／穿戴有无升级一格）
三、红线（八条，见 §八）
四、自检五问（见 §十）
```

**头部四行怎么判**（2026-11-04 增，替掉"想清楚了再写"这类空话）：

- **图写不出来** → 这章没有场景只有交代，回章纲加一场戏。
- **话写不出来** → 这章没有记忆点，至少把章末那一句定下来，定不下就别写。
- **轴写不出来** → **这章是废话章**（002 的教训：三万字的章剧情一动没动），回章纲改任务，不许下笔。
- **档不写** → 视作 T1；卷首、卷尾、大转折章强制 T2（见手册 §三 三档表）。

**母题六选一**（避免与近章重复）：①算死你 ②打脸 ③跳档 ④收账 ⑤起势 ⑥身份反转——与 `爽点宪法` 六型同名，选的是这一章的**主**型。

**存那一栏必须写成** `"存的东西"（兑 0XX／0XX）`——只写"存了规矩"不合规，要写明兑在哪一章。

## 四、一章三件事，每件两拍

| 段位 | 占字数 | 必须发生 |
|---|---|---|
| 起 | 10% | 交底：缺什么、缺多少、几天内要 |
| 事一·出 | 25% | 去办第一件事，**第一次碰壁**；挡的人要有名字、有规矩、有自己的算盘 |
| 事一·换 | 25% | 不硬碰，换到一样**能指认**的东西 |
| 事二·出 | 20% | 换到的东西**带出一个更贵的麻烦** |
| 事二·换 | 15% | 再换一次，**落在一个动作上** |
| 存 | 5% | 往账上存一笔 |

**"换"是命门**：主角不打赢，他换赢——认下这个亏，把亏变成一条规矩、一个名字、一次让步，后面兑。没有"换"，一章只剩挨打。

## 五、四笔账（每章至少走两笔）

| 账 | 走一笔是什么样 | 只走这一笔就完了 |
|---|---|---|
| 钱 | 一笔进出，具体到铜 | 他挣了一银 |
| 人 | 一个人的态度变了（不认他 → 肯替他开口） | 没人变 |
| 位置 | 他在局里挪一格（求人的 → 被求的） | 一直在求人 |
| **规矩** | 学到／用上／改掉一条本地规矩 | 整章没有一条新规矩 |

规矩账每章至少一条，全书 300 条——这是他跟"金手指碾压流"最大的不同。

## 六、存一笔（全书引擎）

- 每章必须存：**存什么、兑在哪一章**。
- 存不出来的章就是废章——后面没得兑，读者觉得他前面白干了。
- 四类：一条规矩／一个名字／一次让步／一条路。
- **兑现晚于存入 ≥3 章**（当场兑的是"换"，不是"存"）；**≤15 章内必须兑掉**。
- 开写前查 `06_追踪_状态账本/伏笔.md`，有旧账可兑就优先兑旧账。

## 七、三种撑不起来的章（见到就重排）

| 型 | 长什么样 | 怎么救 |
|---|---|---|
| 纯过程章 | 熬药、赶路、等一夜、守炉子 | 过程里必须有对手和一个岔子，对手要**有名有规矩** |
| 纯后果章 | 手抖、抽筋、断指 | 后果当场变成一次交易（他抖了，就把"熬"卖出去，自己只出方子） |
| 同型连写 | 连着两章写同一样苦 | 拆开，中间插一笔生意或一个人；同一件苦隔三章才准再用 |

## 八、红线（写进细纲第三节）

1. 前 300 字三样在场：一个气味或声音／一个具体地方／一个数。
2. 新专名 ≤3，且逐个列出。
3. 苦只当成本不当生活——每处苦当场换到东西。
4. "地位低下"只写一处（排序／价钱／说话／作证／称呼，五选一，不与近章重复）。
5. 交手过 `01_法则_章法节奏爽点/战斗节奏表.md` §〇·一七条猥琐纪律；挨打必须是算漏，不是硬扛。
6. 亲属称谓：父亲／母亲（禁爹娘）。
7. 物理逻辑四查：物件状态连续／人物位置连续／时间单向／话与账对得上。
8. 桥段冷却：查 `06_追踪_状态账本/桥段账本.md`，距上次 ≥3 章。

## 九、一票否决（细纲出现任一条，不许立项）

- 写了交手，却不分输赢。
- 没有"这章变了什么"。
- 没有"这章输了什么"（写不出 ＝ 这场戏没赌注）。
- 三个情节点是同一个对手的同一件事。
- 章尾停在"他下定了决心"。
- 整章没有一笔钱、一个人、一次伤的变化。
- 前十章没有一次赢。

## 十、自检五问

1. 碰壁几次？（只碰一次 ＝ 只有一件事 ＝ 2800 字）
2. 每次碰壁换到了什么？（换不到 ＝ 这一拍是废的）
3. 哪个人变了态度？
4. 哪条规矩被摸清或改掉？
5. 存下了什么、兑在哪一章？

## 十一、排一段（15 章）

三回合各 5 章：

| 回合 | 章位 | 干什么 | 结算 |
|---|---|---|---|
| 一·落地与翻车 | 1—5 | 落地定价 → 按旧经验出手赔一个具体数 → 第 5 章小翻盘 | 一笔小钱 + 一个位置（住处／门路／客户） |
| 二·同盟与软处 | 6—10 | 同盟成形（读者已知会叛）→ 8 章找到软处、第一次中胜 → 9—10 当着读者的面埋退路 | 打掉一个中层，拿一笔大钱或一条渠道 |
| 三·背叛与驱逐 | 11—15 | 背叛落地（最多两章）→ 退路回收、翻盘加倍（名场面 1）→ 15 章大结算并走（名场面 2） | 钱／人／名／地至少收两样，具体到数 |

- 三回合的对手必须换人：要他的钱 → 要他站队 → 要他死。
- 段前 40% 内必有一次胜。
- 每段写明"这一段谁在利用他、他为什么暂时换不掉"——写不出，这一段不许开写。
- 每段至少一次钱→力兑换，写清换成了什么。

开段四问：①他现在有多少钱、池子几成、能活几天（算到铜）？②谁打得过他、谁只是要他的钱？③靠什么换到第一笔钱——那张纸写什么、谁付钱、谁兑付？④这一段吃哪一档资源、卖生料还是成品、往上走一档要过哪道门？

## 十三、写作前参数卡（出细纲前先填）

| 项 | 填什么 | 不填的后果 |
|---|---|---|
| 读者 | 一句话，具体到处境 | 写给自己看 |
| 字数 | 目标区间，如 2200—2800 | 结构撑不住或注水 |
| 语气 | 冷／热／平，只能选一个 | 腔调来回跳 |
| 平台 | 公众号／起点／番茄 | 段落长度和钩子位置不对 |
| 一个具体物 | 本章必须出现的东西 | 全是情绪，没有实物 |

五行不齐，不许出细纲。

## 十四、大纲三版选一（防第一版将就）

同一个题，先出 A／B／C 三版骨架，每版只写 5 行：谁、要什么、谁挡、代价、章尾落点。选一版再展开成八拍。

- 三版必须换“主角的解法”，不是换措辞。
- 选不出来的题，说明冲突不够，回上一步换题，不要硬写。

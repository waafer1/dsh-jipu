# 引导式选型（谁在什么时候问、问完落哪）

> **判据唯一出处**：项目里的 `07_模板_复用件/00-引导式选型.md`（三档问卷、升降档判定、选型卡 12 行、指认规则）。本文件只写**执行细则**：谁问、问几轮、卡门怎么卡、落盘到哪个文件。两边冲突以项目文件为准。
> 项目里没有这份文件时（新书刚开、或用户机器上只有专家包），用本技能 `assets/00-引导式选型.md` 顶上，并提醒作者把它复制进项目 `07_模板_复用件/`。

## 一、这件事归谁

**主理人（程知序）亲自问。不外派。** 理由：选型决定后面所有工序的口径，问的人必须同时知道门禁和模板库；拆给世界观师问，问出来的卡会偏向设定，缺约束项。

- 主理人：主持三档问答、出选型卡、卡「有没有卡」这道门
- 世界观师（陆见微）：拿到卡后按 §六 指认规则选模板；缺项回来要，不自己补
- 其余四人：不参与选型，只按卡执行

## 二、什么时候问（三处，只三处）

| 时机 | 判定信号 | 问几问 |
|---|---|---|
| **开新书** | 没有 `02_设定_世界与角色/题材定位.md`，或该文件里没有 `## 题材卡`，或 `## 选型卡` 缺失 | 快 3 ／ 标准 9 ／ 深 15 |
| **每卷开头** | `03_图纸_大纲与细纲/卷纲_第N卷_*.md` 头部没有「本卷意图」三行（卷目标／卷末必然失去／卷末收在哪） | 3 问（R1—R3） |
| **作者改主意** | 换类目、换主角欲望、换爽点主型、卡与嘴上说的不一致 | 只问被改的那几项，然后**重出卡** |

**不问的情形**（问错地方就是拖延）：写某一章、改稿、体检、排一段章目、用户点名要某份东西、本轮已经答过的问题。

## 三、四步执行

```
① 定档   → 按信号表选快/标准/深；拿不准就用标准档
② 问     → 一轮 ≤3 问；人话提问；每轮末尾复述已确认三项让他纠错
③ 出卡   → 12 行固定格式；每行标「作者答 Qn」或「默认」
④ 落盘   → 见下表；落完报一句「选型卡已出，档位X，N 项来自作者，M 项默认」
```

**问的五条硬规矩**（不许破）：一轮 ≤3 问；问句不含术语；选项必须能接一句「那第一章就写成⋯⋯」；每轮复述；答不上来给默认值＋「不同意就说」。

**升降档**：已给类目＋欲望＋输赢姿态 → 降快档；说「随便／你定」→ **不降档**，全给默认值并逐项写明；答话互斥 → 升一档并逼二选一；类目跨两个 → 升一档，先定谁是皮谁是骨；答非所问两次 → 换问法；说「别问了」→ 立刻停，出卡标默认。

## 四、卡落哪

| 场景 | 落到 | 字段 |
|---|---|---|
| 开新书 | `02_设定_世界与角色/题材定位.md` | 末尾加 `## 选型卡（日期，档位）` 12 行表 + `## 题材卡（回答九件事）` |
| 阈值类（第 8 项、Q14、Q15） | `项目配置.json` | `structure`／`coolpoint.density`／`hook.baseline` 等，**只改这些字段，不动别的**；对白不再设阈值 |
| 每卷开头 | `03_图纸_大纲与细纲/卷纲_第N卷_*.md` 头部 | `卷目标`／`卷末必然失去`／`卷末收在哪` 三行 |
| 第 7 项「不许出现」 | 细纲卡门 ＋ 类目模板库毒点清单 | 逐条升硬门，写细纲时逐条打勾 |

**不许落到对话里。** 卡不在文件里，等于没问过。

## 五、卡门：没有卡不许翻模板

**先跑一下，别靠眼看：**

```bash
cd <项目根>
python 08_工具_脚本/选型体检.py        # exit 0 = PASS；exit 1 = 不许出细纲
```

它查四件：`## 选型卡` 段在不在、12 行齐不齐、有没有空项、「不许出现」有没有写。标了「未定」的项报 NOTE（不算失败，但要知道它是空的）。

再看四条硬项：

1. `题材定位.md` 里有没有 `## 选型卡`？没有 → **停**，先问。
2. 卡第 1 项（类目）是否指到了具体的 `类目模板库/0N`？指不到 → 回问 Q1。
3. 卡第 6 项（一章最爽的那一下）能否归入通用八型？归不上 → 回问 Q6，不许自创第九型。
4. 卡第 7 项（不许出现）是否已逐条进细纲卡门？没进 → 补上再写。
5. 本卷卷纲头部有没有「本卷意图」三行？没有 → 只问 R1—R3，问完再写。

**四道全过才允许出细纲。** 卡不过，模板一行都不许翻。

## 六、选模板（世界观师照此执行）

| 卡上项 | 指到 |
|---|---|
| 1 类目 | `assets/类目模板库/01`—`12`（或项目 `07_模板_复用件/类目模板库/`）取节奏骨架／爽点配方／毒点清单当**校验表**，开篇三章范式当**对照** |
| 2、3 欲望与位移 | `剧情模板库/03`、`04`、`08` 按「他要拿什么」选册 |
| 4 第一章姿态 | `剧情模板库/01` |
| 5 主项（算／打／熬／人） | 算 → 信息差型；打 → `02`、`05`；人 → `04` |
| 6 那一下 | `01_法则_章法节奏爽点/爽点宪法.md` 通用八型 |
| 10、11 对标与差异 | 只拆结构（拍点、密度、钩子位），不搬桥段、不搬人名地名 |

**三条禁令**：不自创第九型；模板不进正文（五拍是骨架，落笔要拆成动作、对白、数字）；用完必回写 `06_追踪_状态账本/桥段账本.md`（模板号＋章号＋变体），否则下段查不了冷却。

## 七、三种容易犯的错

| 错 | 症状 | 纠正 |
|---|---|---|
| 替作者定 | 用户没答，主理人自己选了一个，卡上标「作者答」 | 默认值必须**明标「默认」**，并说一句「不同意就说」 |
| 一次问完 | 九个问题一条消息发出去 | 拆三轮；已问过的轮次不重问 |
| 卡与稿打架 | 卡写「不许商战」，正文里谈了半章价 | 卡第 7 项进细纲卡门；打架时以**卡**为准（卡是作者意图，稿是执行） |

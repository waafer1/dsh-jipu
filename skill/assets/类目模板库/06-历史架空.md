# 06 · 历史架空

> **一句话公式**：一个带着后世常识的人落到某位人物手边，用一条当时没人想到的办法立功，然后发现立功比活命容易。
> **读者买的是"我知道结局，所以看你怎么改"**——历史文的最大爽点是**改**，最大风险是"改得太容易"。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①时代细节真实（吃什么、穿什么、官称、钱怎么算）②现代知识**有限度**地起作用 ③每改一处，历史的惯性会反噬 |
| 核心循环（一段 15 章） | 落到某位 → 献策/办事 → 立功受赏 → 得罪既得利益 → 被反扑 → 再献策站得更稳 |
| 周期 | 小循环 3—5 章（一策一事），中循环 15 章（一场战/一桩案/一次党争） |
| 硬约束 | **历史惯性**：改了 A 必出 B。每改一处，必须写清"因为这一改，谁受损了" |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①落到什么地方、什么年份、正赶上什么大事（战、灾、案）②他的身份是一个**低位但能进言**的人 ③一次生死关头（不是他死，是他眼看别人死） | 历史年表、制度讲义、主角背诵千年大势 | 他发现一个"现在做还来得及"的时机 |
| **第 2 章** | ①他说出一件"当时没人知道但马上会应验"的事（用后世常识）②有人将信将疑，给了他一个小权 ③办成一件小事 | 一开口就被奉为上宾 | 应验了，但有人开始怀疑他从哪知道的 |
| **第 3 章** | ①第一次献策成事，赏赐具体（官、田、钱、随从）②得罪一个具体的人（有权、有名、有靠山）③他必须站队 | 皇帝当场封侯 | 站队的那一方，正在准备牺牲他 |

## 三、知识使用权（这类目的核心机制）

| 知识类型 | 能做什么 | 限制（必须写） |
|---|---|---|
| 制度/组织 | 改税制、改编制、改考核 | 要人执行，执行的人会走形；动了谁的饭碗 |
| 技术 | 水泥、冶铁、农具、医药 | 缺材料、缺工匠、缺时间；三个月起步 |
| 军事 | 阵法、后勤、情报 | 兵不听他的；粮不够；天时不对 |
| 人心 | 舆论、谶纬、谣言 | 反噬极快，用一次被记一辈子 |
| 经济 | 发债、专卖、期货 | 需要信用；一次挤兑全崩 |

**铁律**：一项知识只能解决**一个问题**，且必须付出**一个成本**（时间、钱、人命、名声）。一次解决三个问题的，是神仙不是人。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—4 | 落地、立身份、第一次应验 | 有了一个小权与一个靠山 |
| 5—9 | 办成一件实事（治灾/练兵/查案），得罪人 | 有了第一批自己的人 |
| 10—15 | 反扑、下狱或贬官、翻盘；段末换地方或换主 | 他有了名，也有了敌人名单 |

## 五、爽点配方

**主力型**：①算死你、⑧掌控。辅助：②打脸、⑦获得。

**历史文专属爽点：应验**。构造：他提前说出一个结果（在众人不信的场合） → 有人拿这个攻击他 → 结果应验 → 攻击他的人必须当众改口。**这类爽点一段只能用两次**，多了像预言家。

**打脸的克制**：对手必须是有真实权力的士大夫/宗室/武将，赢他靠**事**，不靠嘴。让对手输在他自己维护的规矩上。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 古人集体降智 | 给对手一个符合时代的正确判断，让他输在信息差而非智商 |
| 2 | 技术无成本、无失败 | 每项技术写"材料、工匠、失败次数、工期" |
| 3 | 制度一改就灵 | 写执行层的走形：加派、贪墨、阳奉阴违 |
| 4 | 主角道德完美 | 给一次必须牺牲某人的选择 |
| 5 | 现代词硬塞 | 用当时官称与口语，注释另放 |
| 6 | 靠背诵历史预知一切 | 只预知大事，小事一概不知；且他一改，大事就不准了 |
| 7 | 战争写成数据推演 | 写地形、粮道、士气、伤兵 |
| 8 | 皇帝无条件信任 | 信任必须有交换与期限 |
| 9 | 后宫/感情线失重 | 婚姻是政治，写清利益 |
| 10 | 地图与地理含糊 | 至少三条真实路线（几天、多少里、哪条河） |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2400—3000 |
| 对白占比 | 0.30—0.50（朝堂戏可到 0.65） |
| 最长纯叙述 | ≤180 字（制度说明必须切碎到对白里） |
| 应验型爽点 | 段 ≤2 次 |
| 时代细节 | 章 ≥2 个（物价、官称、器物、礼制） |
| 新专名 | 章 ≤4（人名多，必须带身份标签） |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）他睁眼在哪、身上有什么、外面在闹什么
拍2（20—40%）一场灾/战/案的边角照到他（他看见一具尸体/一张告示）
拍3（40—60%）他判断出"三天后会怎样"，说给一个能进言的人听
拍4（60—80%）没人信，但有人抱着试试给了他一件小事办
拍5（80—100%）他办成一半，另一半出事，被记了一笔
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《新宋》 | 制度改造的真实阻力 | 议论过多，节奏慢 |
| 《宰执天下》 | 党争与法理，人物立场清晰 | 门槛高 |
| 《明朝那些事儿》 | 讲史的节奏与人物趣味 | 非小说结构 |

## 十、改写清单

1. **钱**：贯/石/两 → 当时的真实购买力（一石米几钱、一个兵一年几贯）。
2. **力**：权力来源 → 谁给他权、权能管到几品、什么时候收回。
3. **人**：座主—同年—部曲 → 当时的真实关系网。

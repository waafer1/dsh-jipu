# 09 · 悬疑 / 灵异 / 推理

> **一句话公式**：他看见一件不该发生的事，追下去，每解开一层，代价就落到他自己身上一层。
> **读者买的是"我比叙事者多知道一点"的快感**——所以线索必须公平，作弊一次，全书信任崩塌。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①悬念有答案，且答案在之前出现过 ②每章解开一个小谜，同时开一个新谜 ③真相有代价（他不只是"知道了"，他失去了一样东西） |
| 核心循环（一段 15 章） | 异象 → 查证（问人、找物、试错） → 反转（我原先想错了） → 逼近真相 → 付代价 |
| 周期 | 小谜 2—3 章（一个疑点），中谜 15 章（一桩事），大谜 40—60 章（全书主线） |
| 硬约束 | **公平线索**：解答用到的信息，读者在解答前必须见过至少一次 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①他是什么人（职业、为什么能查事）②一件具体的异常（气味、声音、少了一样东西）③一个正常人会忽略、他注意到了的细节 | 大段世界观、灵异体系分级 | 他去确认，发现比想的严重 |
| **第 2 章** | ①第一次查证，得到两条线索，一条是假的 ②有人劝他别查，理由正当 ③他付出第一次代价（时间、钱、关系） | 撞鬼即开挂、突然觉醒 | 假线索指向一个不该被怀疑的人 |
| **第 3 章** | ①第一次小解答（解开一个，但不是核心）②核心疑问变大 ③代价升级：有人因此受伤或死 | 一次解开全部 | 那个人的死，和他查的事有关 |

**三章铁律**：第 2 章必须给一条**假线索**。没有假线索的悬疑＝一路直推，读者不参与。

## 三、线索设计（三种，缺一不可）

| 类型 | 作用 | 写法 |
|---|---|---|
| **真线索** | 指向答案 | 用具体物：一张票据、一道划痕、一句说漏的话 |
| **假线索** | 让读者误判 | 必须能自圆其说，不能是作者故意骗 |
| **反线索** | 证明"某人不可能" | 事后必须解释得通（他有同谋/时间被改了） |

**公平三问**（写解答前自查）：①这条信息读者见过吗？②见过的读者能推出来吗？③推不出，是因为缺信息还是因为作者藏了？

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—3 | 异象、查证、第一个小解答 | 他知道这事不干净 |
| 4—8 | 第二层：旧案/旧人/同类型的事 | 他发现有人在掩盖 |
| 9—12 | 反转：他之前的判断错了，且错得有代价 | 他成了目标 |
| 13—15 | 摊牌；部分真相；段末留一个更大的疑问 | 他决定继续 |

## 五、爽点配方

**主力型**：⑦揭秘（本期新增口径）、①算死你。辅助：⑧掌控。

**⑦揭秘的写法**：解答必须让读者**回头翻书**——"原来第三章那句轻描淡写的话是这个意思"。构造：一个早出现的细节 + 一个新信息 + 一次重新解释。

**恐惧的写法**：不写怪物长什么样，写**不该有的细节**——多了一双鞋、饭少了一碗、狗不叫了。每次只加一个异常，加三个就成闹剧。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | **隐瞒信息作弊**（关键线索在解答时才出现） | 补到前文，哪怕只一句 |
| 2 | 靠巧合破案 | 每次推进必须靠他的行动 |
| 3 | 反派自曝（最后自己讲全部计划） | 让主角用证据逼出其中一环 |
| 4 | 灵异无规则（想怎样就怎样） | 给三条硬规则（时间、地点、条件） |
| 5 | 每章都惊吓，没有推理 | 惊吓与推理交替，比例 1:2 |
| 6 | 警察/官方完全不存在 | 写清官方为什么进不来（管辖、不信、被收买） |
| 7 | 主角零代价 | 每次逼近真相，付一样东西 |
| 8 | 解答过于复杂 | 解答能三句话说清，讲不清就是没想清 |
| 9 | 配角只负责死 | 每个死者有一件未完成的事 |
| 10 | 灵异与推理混着写，两头不靠 | 二选一为主：要么规则恐怖，要么本格推理 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2200—2800 |
| 对白占比（参考，不卡门） | 0.35—0.55（问询戏为主） |
| 最长纯叙述 | ≤150 字（气氛描写最忌长） |
| 谜 | 章 1 小疑点；3 章 1 解答；15 章 1 大反转 |
| 异常细节 | 章 1—2 个（多了变闹剧） |
| 新专名 | 章 ≤2 |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）他在干什么（职业动作：验、修、送、巡）
拍2（20—35%）一个不该有的细节（多/少/错位），他停了一下
拍3（35—55%）他确认了一次，发现别人都说"一直这样"
拍4（55—75%）他找到一个物证（很小），带走
拍5（75—100%）有人来找他，说"别查了"，理由正当
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《默读》 | 案件与社会结构咬合，人物动机扎实 | 篇幅长，节奏需耐心 |
| 《鬼吹灯》 | 规则型恐怖、地域细节 | 中后期重复探险结构 |
| 本格推理短篇 | 公平线索的技术 | 长篇易散 |

## 十、改写清单

1. **钱**：谁付钱查事 → 委托关系（警方/家属/自己贴钱），写清报酬。
2. **力**：能查什么 → 他的权限与工具（证件、人脉、设备）。
3. **人**：警察—线人—当事人 → 三方的利益。

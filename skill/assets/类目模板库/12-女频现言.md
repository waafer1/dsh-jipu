# 12 · 女频现言（甜宠 / 虐恋 / 都市情感）

> **一句话公式**：她被人准确地看见了一次，然后花很长时间确认那一次不是错觉。
> **读者买的不是甜，是"被看见"**——甜是糖衣，糖衣下面必须是"这个人懂我哪里疼"。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①男主的"看见"是**具体的**（记得她怕什么、不吃什么、为什么不回家）②阻力真实（家庭、前任、职业、自卑）③每次靠近都伴随一次退 |
| 核心循环（一段 12 章） | 相遇（误判） → 靠近（一件小事） → 退（旧伤被触发） → 更近一步 → 阻力加码 |
| 周期 | 小事件 2—3 章（一次接送/一次生病），中段 12 章（一个家庭事件/一次职业危机） |
| 硬约束 | **每次甜必须有代价**（她的自卑、他的旧事、外人的眼光）。没有代价的甜＝工业糖精 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①她的日常与一个具体的窘境（房租、加班、被催婚）②一次不太体面的相遇（不是浪漫初见）③他看见了她一个别人不注意的细节 | 一见钟情、车祸、壁咚 | 他记住了那个细节，并做了一件事 |
| **第 2 章** | ①第二次接触，她误判他（以为他别有目的）②她拒绝一次帮助 ③他退一步，但留了一个东西（药、伞、一句话） | 强行同居、家族安排 | 她用了那个东西，被他知道了 |
| **第 3 章** | ①第三次接触，她主动一次（很小的主动）②甜一次（具体、小）③她旧伤被碰到，立刻退 | 表白成功、见家长 | 他说了一句只有她知道意思的话 |

## 三、两个人必须写清的东西

| 项 | 她 | 他 |
|---|---|---|
| 缺什么（童年/创伤） | 具体一件事（不是"缺爱"） | 具体一件事 |
| 怎么防（行为习惯） | 一个反复出现的动作 | 一个反复出现的动作 |
| 什么能破防 | 一件具体的小事 | 一件具体的小事 |
| 不能接受什么（红线） | 一条，且她真的会走 | 一条，且他真的会炸 |

**写法**：这八格填不出来，感情线就是空的。填出来之后，**每次互动都从这八格里挑一格来撞**。

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—3 | 相遇、误判、第一颗糖 | 她开始在意 |
| 4—7 | 靠近（共同处理一件事）；旧伤第一次被看见 | 她退一次，退得有理 |
| 8—10 | 阻力（家庭/前任/职业），他被逼做选择 | 两人隔开 |
| 11—12 | 他自己走过来（不是她求）；一次大的确认 | 关系确立，新阻力埋下 |

## 五、爽点配方

**主力型**：⑥身份反转（他/她的真面目被看见）、⑦获得（被确定地选择）。辅助：⑤起势（有人站她这边）。

**⑥身份反转的言情版**：不是"他其实是总裁"，是"他一直知道那件事，只是没说"。构造：她以为没人知道她的旧事 → 他做了一件只有知情者才会做的事 → 她惊 → 他说一句极轻的话。

**⑦获得的言情版**：一次"确定的选择"——在众人面前选她、在利益前选她、在旧人面前选她。**必须有人在场看见**，无人见证的偏爱不算兑现。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 只撒糖不给阻力 | 每段设一个真实阻力（家境、职业、旧伤） |
| 2 | 男主无边界（强制、跟踪、控制） | 每次越界必须被明确指出，且他改 |
| 3 | 女主只会哭与等 | 她有自己的目标与一次主动选择 |
| 4 | 误会靠不说清推动 | 误会必须有正当理由（保护、承诺、羞耻） |
| 5 | 配角只做工具（恶毒女配/助攻闺蜜） | 配角有自己的利益与难处 |
| 6 | 甜靠物质堆（包、车、房） | 甜靠"记得"与"做到"，钱只做背景 |
| 7 | 吵架后立刻和好 | 每次冲突要留一个后果（一句话、一个习惯改了） |
| 8 | 全员祝福 | 至少一方家长真心反对，且理由成立 |
| 9 | 虐靠生病/车祸 | 虐靠"选择"与"不得不" |
| 10 | 结局只写"在一起" | 写清他们解决了哪个具体问题才在一起 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2500—3200 |
| 对白占比（参考，不卡门） | 0.45—0.65 |
| 最长纯叙述 | ≤150 字（心理描写最忌长段） |
| 甜点 | 章 1 个小的；3 章 1 个中的；12 章 1 个大的 |
| 阻力 | 段 1 个主阻力，不许中途换 |
| 新专名 | 章 ≤2 |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）她的日常：几点起、挤什么车、被谁催
拍2（20—40%）一个窘境落地（差 300 块/被放鸽子/被甩锅）
拍3（40—60%）相遇，不体面（她撞了他/她认错人/她在哭）
拍4（60—80%）他做一件小事（递纸/挡了一下/替她说了句话）
拍5（80—100%）他注意到她的一个细节（她不吃某样东西/她手在抖）
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《何以笙箫默》 | 等待的重量、克制的对白 | 节奏慢，男主人设偏理想化 |
| 《亲爱的，热爱的》 | 甜与事业线并行 | 配角单薄 |
| 《欢乐颂》 | 群像与现实困境 | 感情线分散 |

## 十、改写清单

1. **钱**：房租/工资/彩礼 → 三个数字，写清她的经济处境。
2. **力**：她的能力 → 一份能养活自己的手艺（必须具体）。
3. **人**：家人/前任/同事 → 写清"谁能让她的生活立刻变糟"。

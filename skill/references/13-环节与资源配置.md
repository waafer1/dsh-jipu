# 13 · 环节与资源配置

> 框架通用，内容靠配。每个环节只固定四件事：**输入资源、判据、产物、回写**。写什么题材、用哪套拍子、判多严，全部来自配置与资源包；换题材＝换资源包，不改流程。

## 一、四件套

| 槽 | 含义 | 不合格的样子 |
|---|---|---|
| 输入资源 | 这一环节**必须**先读到的东西（库里的卡、上一环节的产物） | 空手开写，凭记忆补设定 |
| 判据 | 拿什么尺子量（阈值／型表／口径／违禁单） | 尺子写在指令里，换书改不动 |
| 产物 | 落盘到哪个文件、什么格式 | 只存在于对话里 |
| 回写 | 这一环节的结果写回哪张表（状态／登记／配置） | 写完不回写，下一章重问一遍 |

判据分两种：**工序判据**（门禁、句检、章检——跟题材无关，写死在工具里）与**内容判据**（爽点型、密度、节奏、违禁词——跟书走，必须从配置或资源卡读）。

## 四、加一种题材怎么做（不动流程）

1. 写一张**玩法卡**（回合结构、型表、章末交付、违宪）放进玩法卡库；
2. 写一张**类目卡**（主力型、典型桥段、违禁）放进类目模板库；
3. 选型时指定：主玩法／辅玩法、类目、字数、文风尺、L1 三个数；
4. 其余七个环节读配置，自动换尺子。每个环节"要什么水平的 agent 才干得动"，见 `14-岗位能力模型.md`：环节的**判据该长什么样**，由那一岗的"判断力"决定；判据配错，多半是那岗的能力不够，而不是阈值调得不对。

**验证办法**：同一个细纲骨架，换两张玩法卡，写两章出来——拍子不同、章末交付物不同、审计判据不同，但工具一行不改，才叫配置化。

## 五、外部资源从哪来：拆书与蒸馏

底座自带的库（桥段／类目／人物／素材）是**通用资源**；某一本具体的书要写得像那一类，还得有**同类样本**。这两类资源由两条流水线供：

| 流水线 | 产出 | 喂给哪个环节 |
|---|---|---|
| 拆书（一章一零件） | 样张：回合表、九行细纲、动作写法、审计判法 | 卷纲、细纲、正文、审计 |
| 蒸馏（15—20 万字一段） | 尺子：回合间隔、兑现频率、密度带、冷却区间 | 定位、卷纲、审计、素材 |

产物落 `_书库/<书名>/岗位样张/` 与 `_书库/<书名>_结构律.md`，不进 P 库、不直接抄进正文（20 字雷同即命中）。哪个环节"写不出来"，先查样张，再谈加人。岗位与资源的对应见 `14-岗位能力模型.md` §十三。

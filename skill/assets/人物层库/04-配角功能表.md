# 04 · 配角功能表

> 配角不是“人”，是**功能**。每个配角进场时，先定他替这本书干哪件事；功能完成就退场，不许常驻当背景。

## 一、七种功能

| 功能 | 干什么 | 典型退场 |
|---|---|---|
| **引路人** | 给方法、给第一份资源 | 被主角超过，或为救主角死 |
| **对手** | 挡目标、逼升级 | 被打败，或变成盟友 |
| **镜子** | 走另一条路，照出主角的代价 | 与主角分道 |
| **拖累** | 让主角不能只算最优解 | 被救、被放弃、或自己走 |
| **见证者** | 替读者反应、报数、传话 | 一直在，但不占主线 |
| **资源持有者** | 给钱、给活、给门路 | 交易完成即淡出 |
| **规则解释者** | 把世界的规矩说人话 | 说完就退，别复读 |

一个配角可以兼两种功能，但**主功能只能一个**；主功能不写清，他就会变成“话多的路人”。

## 二、进场三件套

每个有名有姓的配角，进场时必须给三样：

1. **要什么**（一句，具体）
2. **一个可见件**（担子、疤、戒指、口头禅）
3. **一句会说的话**（能听出身份）

三样缺一，读者记不住；三样全给，他下次出场不用重新介绍。

## 三、关系三线

| 线 | 记什么 | 怎么用 |
|---|---|---|
| **欠** | 谁欠谁、欠多少 | 逼主角做不情愿的选择 |
| **怕** | 谁怕谁、怕什么 | 决定谁先眨眼 |
| **信** | 谁信谁、信到什么程度 | 决定背叛的杀伤力 |

关系变化必须落在**具体事**上：借了钱、挡了刀、传了话。空写“关系变好”，读者无感。

## 四、退场规则

- 功能完成 → 退场或降为背景；**不许占着位置反复解释同一件事**。
- 退场要有代价：死、走、变、欠。无声消失是最差处理。
- 一个配角第二次出场，必须带来**新信息或新麻烦**；只来打招呼的，删。

## 五、自检

1. 这个配角替书干了哪件事？说不出来 → 删。
2. 他的三件套齐吗？
3. 他和主角的关系，最近一次变化是哪一章、因为什么事？
4. 他退场时，读者会不会记得他？不会 → 退场方式要改。

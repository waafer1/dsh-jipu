# 03 · 职业与行当细节

> 写职业只写三样：**钱从哪来、一天怎么过、行话三句**。三样齐了，人物就站得住；不齐，写多少形容词都是空的。

## 一、选职业三问

1. **钱从哪来**：按件、按月、还是按趟？谁付、什么时候付、拖不拖？
2. **一天怎么过**：天亮前干什么、晌午在哪、天黑后收什么？
3. **行话三句**：这行的人怎么称呼活、怎么称呼钱、怎么骂人？

## 二、行当速查表

| 行当 | 收入形态 | 常见风险 | 一句行话 |
|---|---|---|---|
| 学徒 | 管饭、月钱极少 | 挨打、背锅、学不到真东西 | “先看三年，再动手。” |
| 掌柜 | 抽成、差价 | 压货、坏账、官府 | “这价，你担不走。” |
| 账房 | 月钱、暗股 | 算错、做假、被灭口 | “账上不是这么写的。” |
| 脚夫 | 按趟、按件 | 摔货、抽成、抢道 | “这趟，我担。” |
| 矿工 | 按筐、按层 | 塌方、欠薪、肺病 | “这一层，吃人。” |
| 猎户 | 按皮、按肉 | 兽、伤、禁猎 | “脚印是新的。” |
| 药铺 | 按副、按方 | 抓错、赊账、医闹 | “先付，再抓。” |
| 铁匠 | 按件、按火 | 烫伤、矿料断供 | “火候不到，别开锤。” |
| 船工 | 按趟、按货 | 沉船、水匪、滞期 | “等潮，不等你。” |
| 更夫 | 月钱 | 撞鬼、误点、被打 | “三更了，收灯。” |

## 三、写职业的三条纪律

1. **一件工具**：他吃饭的家伙，写清磨损和用法。
2. **一个动作**：只有这行的人会做的动作（账房拨珠、铁匠看火色、船工试水）。
3. **一句价钱**：他这行当天的一个价，让读者知道行情。

## 四、查不到怎么办

- **视角遮挡**：只写他看见的部分（“布包硬邦邦的”），不写不懂的。
- **行家免谈**：让行家做动作、说半句，主角听不懂，读者也不用懂。
- **比附**：用读者已知的东西比（“闻着像烧焦的头发”）。

## 五、自检

- 这个职业的“一天”能写出来吗？
- 他今天挣了多少、花在哪？
- 有没有一句只有这行会说的话？

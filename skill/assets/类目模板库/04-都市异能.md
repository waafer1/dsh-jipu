# 04 · 都市异能

> **一句话公式**：一个能碾压一切的人，必须每天装作不能，直到不得不露一手。
> **读者买的是"隐藏—暴露"的张力**，不是超能力本身。这类目唯一的稀缺资源是**秘密**。

## 一、读者承诺与核心循环

| 项 | 内容 |
|---|---|
| 承诺 | ①日常场景里的降维碾压（地铁、公司、饭局、医院）②身份差带来的错位喜感 ③露一手必然惹出更大的麻烦 |
| 核心循环（一段 15 章） | 低调生活 → 被欺/被卷入 → 只露三分 → 收场并抹平痕迹 → 抹不干净 |
| 周期 | 小循环 2—3 章（一个日常冲突），中循环 10—15 章（一个组织/一个案子） |
| 硬约束 | **每次动手都要有"暴露风险"**，没有风险＝没有张力 |

## 二、开篇三章范式

| 章 | 必须发生 | 不许发生 | 章末钩子 |
|---|---|---|---|
| **第 1 章** | ①他有异能，且**已经在用**（用于生活小事）②他有一个必须隐藏的理由（家人、身份、旧仇）③一次被欺，他忍了 | 异能来历大段解释、组织介绍 | 忍的代价出现了（别人替他受罪） |
| **第 2 章** | ①他第一次出手，用最小剂量 ②被一个人看见，那个人不说 ③日常继续，假装无事 | 当街屠人、媒体轰动 | 看见他的人来找他 |
| **第 3 章** | ①为救人/自保，第二次出手，规模更大 ②有具体收益（钱、人情、一个资格）③暴露风险升级（有人开始查） | 全市直播、官府通缉 | 查他的人有官方背景 |

## 三、异能设计（关键：限制度，不限强度）

| 维度 | 必须写清 | 为什么 |
|---|---|---|
| 触发 | 什么条件下能用（体力、情绪、时间、地点） | 无限制＝无张力 |
| 上限 | 一次能做到什么程度（具体：能举 300 斤、能读 3 秒内的念头） | 上限决定读者预期 |
| 代价 | 用完怎样（累、痛、失忆、寿命、被反向追踪） | 代价是张力的来源 |
| 破绽 | 什么情况下会失效（水、铁、心率、说谎的人） | 破绽是反派的机会 |

## 四、节奏骨架

| 章段 | 任务 | 结束状态 |
|---|---|---|
| 1—3 | 立秘密、立生活、第一次小暴露 | 有人知道他不普通 |
| 4—8 | 被卷入一件事（不是他要管，是躲不开） | 有了一个必须保护的人 |
| 9—15 | 打掉一个小组织；秘密半公开；段末换生活场（换城市/换工作） | 他需要一个合法身份 |

## 五、爽点配方

**主力型**：②打脸、⑥身份反转。辅助：①算死你、⑧掌控。

**打脸的都市版三件套**：①一个有社会身份的人（经理、主任、富二代）当众轻视 ②围观者里有他需要维持关系的人 ③打完脸，**他的生活反而更麻烦**（被记恨、被调查）。

**⑥身份反转换法**：让"他们求的那个人"和"他们踩的那个人"是同一个人，且**读者早就知道**（读者知道、角色不知道＝最爽的结构）。

## 六、毒点清单

| # | 毒点 | 改法 |
|---|---|---|
| 1 | 异能无限制、无代价 | 补触发条件+上限+代价+破绽四项 |
| 2 | 每次都能抹平痕迹 | 留一条抹不掉的（监控、目击者、伤） |
| 3 | 装逼无风险 | 每次装逼前先算"被谁看见" |
| 4 | 官方永远不存在/永远无能 | 至少写一次"正规力量到场，且比他克制" |
| 5 | 女主只负责惊叹 | 给她一个自己的目标和一次反对 |
| 6 | 打脸对象全是蠢货 | 对手要有一个正确判断，只是不知道他是谁 |
| 7 | 日常写成流水账 | 每章日常必须挂一个具体麻烦（房租、考核、亲戚） |
| 8 | 秘密守了 100 章没人发现 | 秘密必须不断漏，漏给不同的人 |
| 9 | 用超能力解决感情问题 | 感情问题必须用人的方式解决 |
| 10 | 一开口就报身世 | 身份只在被逼到墙角时露出一角 |

## 七、可核数据（经验值）

| 项 | 基准 |
|---|---|
| 单章字数 | 2200—2600 |
| 对白占比（参考，不卡门） | 0.40—0.60（这类目靠对话推进） |
| 最长纯叙述 | ≤150 字 |
| 出手频率 | 段 3—5 次，每次规模递增，每次都有目击者 |
| 日常场景 | 段 ≥3 个真实场景（公司/医院/学校/家），且写到具体流程 |
| 新专名 | 章 ≤2（这类目专名越少越好） |

## 八、样章骨架（第 1 章，五拍）

```
拍1（0—20%）一个具体日常麻烦（迟到/催租/被扣工资），他用异能悄悄解决
拍2（20—40%）他为什么必须藏（一句带过，不解释来历）
拍3（40—60%）有人当众踩他，踩得有社会依据（他是临时工/没背景）
拍4（60—85%）他忍，但有人替他出头并被牵连受伤
拍5（85—100%）他出手一次，很小，只有一个人看见
```

## 九、对标与可学之处

| 作品 | 可学 | 不可学 |
|---|---|---|
| 《我当上帝那些年》类 | 能力规则的巧思 | 后期规则膨胀 |
| 《陈二狗的妖孽人生》 | 底层视角与狠劲 | 价值取向偏激 |
| 都市兵王流 | 隐藏身份的错位喜感 | 脸谱化反派、无成本装逼 |

## 十、改写清单

1. **钱**：工资/房租/医药费 → 你的三笔固定支出，写清数字。
2. **力**：异能 → 触发/上限/代价/破绽四项。
3. **人**：公司/家族/旧部队 → 你的社会关系网，写清"谁有权力处置他"。

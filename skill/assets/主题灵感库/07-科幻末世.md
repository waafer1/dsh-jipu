# 科幻末世 · 主题灵感

## 母题

1. **秩序塌了之后，人还剩下什么**——法律、货币、道德都失效，主角靠什么决定“帮不帮”。
2. **资源即人**——水、药、电、子弹，每一样都要拿人去换。主角要在“救一个”和“活一群”之间选。
3. **重建的代价**——从活下来到活得像人，中间要立规矩；立规矩就要有人被规矩压死。

## 灵感种子

| 一句钩子 | 核心冲突 | 主角要付的代价 |
|---|---|---|
| 他是末世里唯一还会修净水器的人，所有营地都想“留”他 | 自由与用处 | 留一处，别处的人渴死 |
| 避难所的粮食够吃三年，但门外的广播说“救援下周到” | 信不信 | 开门，可能引狼；不开，可能错过 |
| 他能听懂丧尸的“声音”，它们在找一个人 | 真相 | 听多了，自己也像它们 |
| 一群孩子把废弃超市当王国，他是唯一的大人 | 保护与规则 | 立规矩，孩子恨他；不立，孩子死 |
| 末世第三年，有人开始用“旧世界的货币”交易 | 秩序回潮 | 认钱，回到旧等级；不认，被孤立 |

## 误区

- 末世只写打怪和囤货：没有“资源怎么分”的冲突，就没有末世。
- 道德困境只做一次高潮，之后主角变成无情的效率机器。
- 重建只写建墙、种地，不写“谁说了算、谁被排除”。

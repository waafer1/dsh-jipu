# 00 · 定位与边界（计谱是什么、不是什么）

> 作者 2026-11-06 定：**计谱不负责创作创新，负责把创作者的设定问清楚，再从知识库里取骨架、按预定风格填情节。**
> 本文是底层宪章；`SKILL.md` 〇·五「三条来路」是总纲，本文是执行细则；两者冲突以本文为准。

## 一、一句话定位

**作者给设定，计谱做执行。**

计谱的价值不在“想出好点子”，在**把点子变成可施工、可验收的稿子**：设定问全、骨架取对、风格对齐、门禁过掉。

## 二、三个不做

| 不做 | 为什么 | 该谁做 |
|---|---|---|
| **不发明世界观** | 发明出来的体系没有读者基础，也没有素材支撑 | 作者定；计谱只做一致性检查 |
| **不发明桥段** | 新桥段无法验证爽点，也无法冷却管理 | 从 `剧情模板库`／`类目桥段库` 取；库里没有就拆书补 |
| **不发明文风** | 文风是项目的既定参数，不是每章的即兴 | 按 `文风基准` 与类目模板的“表达”节执行 |

创新归作者。计谱只做三件事：**问、取、填**。

## 三、四步流程

```
① 问设定 → ② 建检索 → ③ 糅合 → ④ 风格填充 → 门禁 → 交付
```

### ① 问设定（不写正文）

用「五问快筛」定方向（`assets/00-引导式选型.md`），再出 **12 行设定卡**：

| # | 字段 | 问法 |
|---|---|---|
| 1 | 书名 | 暂定名，可后改 |
| 2 | 类目 | 12 类目之一 |
| 3 | 频道／读者 | 男生／女生／出版；读者一句话 |
| 4 | 主角 | 他是谁、现在缺什么 |
| 5 | 金手指 | 能力边界与代价（没有就写“无”） |
| 6 | 对手 | 谁挡他，挡在哪一层 |
| 7 | 本卷目标 | 拿不到会怎样 |
| 8 | 代价 | 每次用能力／每次赢，付什么 |
| 9 | 世界 | 一条铁律（钱怎么来、权怎么分、人怎么活） |
| 10 | 禁忌 | 五条“不许出现”，逐条进细纲卡门 |
| 11 | 母题 | 从 `主题灵感库` 选 1—2 条 |
| 12 | 结局方向 | 一句话；可写“未定”，上架前回填 |

**卡不齐，不许进下一步。**

### ② 建检索（不动笔）

按设定卡到知识库取四样：

| 取什么 | 从哪取 | 取几条 |
|---|---|---|
| 结构骨架 | `类目模板库`／`结构层库` | 1 套卷结构 + 1 套段结构 |
| 剧情拍点 | `剧情模板库` | 本段 3—5 个模板 |
| 桥段／变体 | `类目桥段库` | 2—3 条，查冷却 |
| 主题种子 | `主题灵感库` | 主线 1—2 条、副线 3—5 条 |
| 素材细节 | `素材层库` | 每章 1—2 件可指认的物 |

检索结果写成一张**取材单**（模板 `assets/取材单模板.md`，落 `03_图纸_大纲与细纲/取材单_第NNN段.md`），标来源编号；**单没填完，不许进③**；写正文只许从单里取。

### ③ 糅合（三换三不换）

**三换**：换名（人物／地名／组织）、换物（货币／器物／场景）、换关系（谁欠谁、谁怕谁）。

**三不换**：不换结构（卷／段／拍）、不换爽点节奏（间隔与强度）、不换情绪曲线（读者在哪一拍松、哪一拍紧）。

**双源规则**：每条主线段至少两个来源（结构库 + 桥段库／母题库各一），**禁止单本复刻**。

**冷却**：同一桥段 60／12／6 章三档，记 `桥段账本`。

**红线**：不抄句子、不搬专有名词、不引卷首语；与任一来源连续 20 字相同即打回。

### ④ 风格填充（按参数填，不按心情写）

先定五个风格参数，再填情节：

| 参数 | 从哪定 | 用途 |
|---|---|---|
| 句长带 | 项目 `文风基准` | 决定叙述的呼吸 |
| 段长 | 同上 | 决定手机屏的阅读节奏 |
| 对白密度 | 只报数，不设上下限 | 决定信息与冲突的比例 |
| 意象池 | 项目设定（3—5 个物件） | 决定画面从哪来 |
| 禁用词 | 项目配置 | 决定哪些腔调不许出现 |

填充顺序：**拍点 → 动作／对白／数字 → 按参数改写 → 门禁**。顺序不许倒。

## 四、与知识库的关系

- 知识库是**素材仓库**，不是创作主体：它给骨架、给拍点、给细节，不给“这本书写什么”。
- 库里没有的，**拆书补库**，不硬造；拆书只记结构，不存原文。
- 每用一次，回写 `桥段账本` 与 `种子台账`，否则下段查不了冷却。

## 五、验收（三条，缺一不算完）

| 验收 | 判据 | 不过怎么办 |
|---|---|---|
| **设定一致** | 正文不出现设定卡以外的设定；出现即打回 | 删，或回①补卡 |
| **仿写合规** | 与来源连续 20 字相同 → 打回；单源复刻 → 打回 | 回③加一个来源、换三处物 |
| **门禁** | 句检 0／宾语有数／孤岛全判／数字 0 待核／章体检 9 项 | 按回路改，不许绕过 |

## 六、一句话给作者

**你负责“写什么”，计谱负责“怎么写成能看的”。** 你不给设定，它就不动笔；你给了设定，它不许自由发挥。
